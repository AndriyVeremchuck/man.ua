# 📖 localectl(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `systemd`  
> **Оригінальний виклик**: `man 1 localectl`

---

## 🎯 НАЗВА (NAME)
**`localectl`** — Керування системними налаштуваннями локалі (мови), розкладки клавіатури для віртуальної консолі (TTY) та графічного середовища X11/Wayland.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
localectl [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`status (поточна локаль), set-locale <LANG=...>, list-locales, set-keymap <map> (розкладка для TTY), list-keymaps`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `localectl` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 localectl` або аліас `uman localectl`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ localectl status  # Перегляд активної мови системи та налаштувань клавіатури
$ sudo localectl set-locale LANG=uk_UA.UTF-8  # Встановлення української системної локалі за замовчуванням
```
