# 📖 pdftk(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `pdftk`  
> **Оригінальний виклик**: `man 1 pdftk`

---

## 🎯 НАЗВА (NAME)
**`pdftk`** — PDF Toolkit — потужний інструмент для об'єднання (merge), розділення (split), обертання сторінок, шифрування та заповнення форм у PDF.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pdftk [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`cat (об'єднання сторінок), burst (розбиття на окремі сторінки), rotate, output <вихідний_файл>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pdftk` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pdftk` або аліас `uman pdftk`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ pdftk doc1.pdf doc2.pdf cat output combined.pdf  # Об'єднання двох PDF файлів в один документ
$ pdftk input.pdf burst  # Розбиття багатосторінкового PDF на окремі сторінки pg_0001.pdf...
```
