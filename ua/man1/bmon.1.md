# 📖 bmon(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `bmon`  
> **Оригінальний виклик**: `man 1 bmon`

---

## 🎯 НАЗВА (NAME)
**`bmon`** — Інтуїтивний TUI-монітор мережевої смуги пропускання з побудовою графіків швидкості вхідного та вихідного трафіку в реальному часі.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
bmon [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-p <інтерфейси> (конкретні карти), -r <інтервал> (період оновлення), -o <формат>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `bmon` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 bmon` або аліас `uman bmon`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ bmon  # Запуск інтерактивного моніторингу мережевих графіків
$ bmon -p eth0,wlan0  # Відстеження швидкості виключно для Ethernet та Wi-Fi адаптерів
```
