# 📖 chage(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `shadow`  
> **Оригінальний виклик**: `man 1 chage`

---

## 🎯 НАЗВА (NAME)
**`chage`** — Керування політиками безпеки облікових записів: зміна терміну дії пароля, блокування акаунту та інтервалів попередження.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
chage [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-l <користувач> (перегляд поточної політики), -M <дні> (макс. вік пароля), -m <дні> (мін. вік пароля), -W <дні> (попередження), -E <дата> (дата блокування)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `chage` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 chage` або аліас `uman chage`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo chage -l dusha  # Перегляд повної інформації про термін дії пароля користувача
$ sudo chage -M 90 -W 7 username  # Вимога змінювати пароль кожні 90 днів з попередженням за 7 днів
```
