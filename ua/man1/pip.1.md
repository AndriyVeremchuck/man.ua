# 📖 pip(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `python-pip`  
> **Оригінальний виклик**: `man 1 pip`

---

## 🎯 НАЗВА (NAME)
**`pip`** — Стандартний менеджер пакетів для мови Python для пошуку, завантаження та встановлення сторонніх бібліотек з офіційного індексу PyPI.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pip [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`install <пакет>, uninstall <пакет>, list (список встановлених), freeze (генерація requirements.txt), -r <файл>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pip` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pip` або аліас `uman pip`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ pip install -r requirements.txt  # Встановлення всіх залежностей проєкту зі списку
$ pip list --outdated  # Перегляд списку застарілих бібліотек Python
```
