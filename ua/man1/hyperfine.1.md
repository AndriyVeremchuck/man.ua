# 📖 hyperfine(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `hyperfine`  
> **Оригінальний виклик**: `man 1 hyperfine`

---

## 🎯 НАЗВА (NAME)
**`hyperfine`** — Інструмент статистичного бенчмаркінгу для командного рядка на Rust. Виконує автоматичний прогрів кешу, багаторазові прогони та порівняння швидкості.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
hyperfine [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-w <N> (warmup прогони), -m <N> (мін. запусків), --export-markdown <файл>, --parameter-scan <var> <min> <max>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `hyperfine` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 hyperfine` або аліас `uman hyperfine`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ hyperfine "fd pattern" "find . -name pattern"  # Порівняння швидкості пошуку між fd та find
$ hyperfine --warmup 3 "tar -I zstd -cf test.tar.zst folder"  # Бенчмарк швидкості архівації з 3 прогрівочними прогонами
```
