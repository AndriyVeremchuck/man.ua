# 📖 pipe-viewer(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `pipe-viewer`  
> **Оригінальний виклик**: `man 1 pipe-viewer`

---

## 🎯 НАЗВА (NAME)
**`pipe-viewer`** — Легкий клієнт YouTube для командного рядка без реклами та відстеження з підтримкою пошуку, підписок та відтворення через mpv.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pipe-viewer [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-s / --search "<запит>", --resolution=1080, --downloads-dir=<папка>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pipe-viewer` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pipe-viewer` або аліас `uman pipe-viewer`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ pipe-viewer "CachyOS Linux Review"  # Пошук та вибір відео для відтворення у вікні MPV
$ pipe-viewer  # Запуск інтерактивного меню YouTube
```
