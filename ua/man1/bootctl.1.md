# 📖 bootctl(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `systemd`  
> **Оригінальний виклик**: `man 1 bootctl`

---

## 🎯 НАЗВА (NAME)
**`bootctl`** — Керування завантажувачем systemd-boot, перевірка статусу прошивки EFI, огляд записів завантаження та оновлення завантажувальних бінарників.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
bootctl [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`status (поточний стан завантажувача), list (список записів ядер), install (встановлення), update (оновлення EFI бінарників)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `bootctl` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 bootctl` або аліас `uman bootctl`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ bootctl status  # Перегляд версії systemd-boot, шляху до ESP та активних записів ядер
$ bootctl list  # Список усіх доступних варіантів завантаження ядер CachyOS
```
