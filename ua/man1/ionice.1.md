# 📖 ionice(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `util-linux`  
> **Оригінальний виклик**: `man 1 ionice`

---

## 🎯 НАЗВА (NAME)
**`ionice`** — Встановлення або зміна класу та рівня пріоритету планувальника дискового вводу-виводу (I/O scheduling class) для процесів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ionice [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-c <клас> (1=Realtime, 2=Best-effort, 3=Idle), -n <рівень> (0-7, де 0 найвищий), -p <PID> (для активного процесу)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ionice` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ionice` або аліас `uman ionice`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ionice -c 3 tar -cf backup.tar /large_dir  # Запуск фонового бекапу з класом Idle (не навантажує диск для інших програм)
$ ionice -c 2 -n 0 ./database_server  # Надання найвищого пріоритету I/O операціям бази даних
```
