# 📖 difft(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `difftastic`  
> **Оригінальний виклик**: `man 1 difft`

---

## 🎯 НАЗВА (NAME)
**`difft`** — Структурний диффер вихідного коду на Rust, що порівнює синтаксичні дерева (AST) замість простої побудови рядкових відмінностей.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
difft [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--display <side-by-side/inline>, --color <always/auto>, --syntax-highlight <on/off>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `difft` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 difft` або аліас `uman difft`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ difft old_file.rs new_file.rs  # Семантичне порівняння двох версій коду з урахуванням синтаксису
$ git difftool  # Використання Difftastic як стандартного інструменту git diff
```
