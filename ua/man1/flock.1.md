# 📖 flock(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `util-linux`  
> **Оригінальний виклик**: `man 1 flock`

---

## 🎯 НАЗВА (NAME)
**`flock`** — Керування консультативними файловими блокуваннями (advisory file locks) у shell-скриптах для гарантії виконання єдиного екземпляра задачі.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
flock [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-n (не блокувати, завершити з помилкою якщо зайнято), -s (спільне блокування), -x (ексклюзивне блокування), -u (зняти блокування), -w <секунди> (таймаут)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `flock` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 flock` або аліас `uman flock`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ flock -n /tmp/backup.lock -c "/usr/local/bin/backup.sh"  # Запуск бекапу з гарантією, що попередній екземпляр уже не виконується
$ flock -w 10 /tmp/task.lock -c "make deploy"  # Очікування звільнення блокування до 10 секунд перед запуском
```
