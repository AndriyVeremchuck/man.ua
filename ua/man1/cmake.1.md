# 📖 cmake(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `cmake`  
> **Оригінальний виклик**: `man 1 cmake`

---

## 🎯 НАЗВА (NAME)
**`cmake`** — Міжплатформна система генерації файлів збірки (Makefiles, Ninja) з конфігурацій CMakeLists.txt для мов C, C++, Rust та Fortran.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
cmake [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-B <папка_збірки>, -S <папка_сирців>, -G <генератор: Ninja/Unix Makefiles>, -DCMAKE_BUILD_TYPE=Release, --build <папка>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `cmake` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 cmake` або аліас `uman cmake`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release  # Генерація конфігурації збірки Ninja у релізному режимі
$ cmake --build build -j$(nproc)  # Запуск паралельної збірки проєкту
```
