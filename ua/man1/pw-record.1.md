# 📖 pw-record(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `pipewire`  
> **Оригінальний виклик**: `man 1 pw-record`

---

## 🎯 НАЗВА (NAME)
**`pw-record`** — Прямий запис аудіопотоків високої роздільної здатності з будь-якого мікрофона або звукового пристрою через мультимедійний сервер PipeWire.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pw-record [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--target <вузол> (вибір джерела), --format <формат: s16, f32>, --rate <частота: 48000, 96000>, --channels <канали>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pw-record` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pw-record` або аліас `uman pw-record`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ pw-record --rate 48000 recording.wav  # Запис звуку з системного мікрофона у форматі студійної якості 48kHz WAV
$ pw-record --help  # Перегляд опцій запису PipeWire
```
