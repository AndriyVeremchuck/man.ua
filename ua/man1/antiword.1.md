# 📖 antiword(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `antiword`  
> **Оригінальний виклик**: `man 1 antiword`

---

## 🎯 НАЗВА (NAME)
**`antiword`** — Консольний читач документів MS Word (.doc): перетворення у звичайний текст, структуру PostScript або PDF зі збереженням таблиць.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
antiword [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-p <формат_паперу: a4/letter>, -m <мапінг_кодування>, -w <ширина_тексту>, -a <a4/ps>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `antiword` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 antiword` або аліас `uman antiword`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ antiword document.doc  # Перегляд вмісту документа Word у терміналі зі збереженням структури таблиць
$ antiword -a a4 document.doc > document.ps  # Конвертація документа Word у формат PostScript A4
```
