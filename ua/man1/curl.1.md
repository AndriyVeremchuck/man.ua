# 📖 curl(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Оригінальний виклик**: `man 1 curl`

---

## 🎯 НАЗВА (NAME)
**`curl`** — Утиліта для передачі даних за мережевими протоколами (HTTP, HTTPS, FTP)

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
curl [OPTIONS...] <url>
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `curl` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 curl` або аліас `uman curl`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ curl -fsSL https://get.url | bash
$ curl -I https://example.com
```
