# 📖 ltrace(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `ltrace`  
> **Оригінальний виклик**: `man 1 ltrace`

---

## 🎯 НАЗВА (NAME)
**`ltrace`** — Інструмент налагодження для перехоплення та протоколювання викликів динамічних спільних бібліотек (.so) виконуваної програми.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ltrace [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-p <PID> (підключення), -e <функція> (фільтр), -c (статистика викликів), -f (дочірні процеси), -S (показувати системні виклики)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ltrace` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ltrace` або аліас `uman ltrace`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ltrace -c ls  # Зведена статистика викликів бібліотечних функцій для ls
$ ltrace -e malloc+free ./my_program  # Відстеження виділення та звільнення динамічної пам'яті
```
