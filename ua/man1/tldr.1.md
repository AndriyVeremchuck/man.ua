# 📖 tldr(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `tealdeer`  
> **Оригінальний виклик**: `man 1 tldr`

---

## 🎯 НАЗВА (NAME)
**`tldr`** — Ультрашвидкий клієнт на Rust для спільнотної бази спрощених практичних посібників TLDR Pages (швидка альтернатива man).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
tldr [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-u / --update (оновити кеш), -l / --list (список сторінок), -p / --platform <linux/osx>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `tldr` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 tldr` або аліас `uman tldr`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ tldr ffmpeg  # Короткі та наочні приклади конвертації відео без вичитування сотень сторінок man
$ tldr --update  # Оновлення локальної бази практичних шпаргалок
```
