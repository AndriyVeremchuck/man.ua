# 📖 jobs(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `shell builtin`  
> **Оригінальний виклик**: `man 1 jobs`

---

## 🎯 НАЗВА (NAME)
**`jobs`** — Перегляд списку фонових та зупинених завдань у поточній термінальній сесії.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
jobs [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-l (показувати числові PID), -p (лише PID), -r (лише працюючі), -s (лише зупинені)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `jobs` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 jobs` або аліас `uman jobs`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ jobs -l  # Список фонових задач із номерами завдань та PID
```
