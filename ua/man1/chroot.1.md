# 📖 chroot(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 chroot`

---

## 🎯 НАЗВА (NAME)
**`chroot`** — Запуск оболонки або програми з ізольованим кореневим каталогом. Стандартний інструмент для аварійного відновлення та встановлення системи.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
chroot [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--userspec=<user:group> (запуск від імені користувача), --groups=<g1,g2> (додаткові групи)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `chroot` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 chroot` або аліас `uman chroot`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo chroot /mnt /bin/bash  # Вхід у змонтовану на /mnt систему для оновлення ядра або Grub
$ sudo arch-chroot /mnt  # Автоматичний chroot із монтуванням /proc, /sys, /dev у CachyOS/Arch
```
