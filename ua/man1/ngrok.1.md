# 📖 ngrok(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `ngrok (~/.local/bin)`  
> **Оригінальний виклик**: `man 1 ngrok`

---

## 🎯 НАЗВА (NAME)
**`ngrok`** — Створення безпечних публічних тунелів до локальних серверів розробки для зовнішнього тестування та вебхуків.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ngrok [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`http <порт>, tcp <порт>, --domain <домен>, --authtoken <токен>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ngrok` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ngrok` або аліас `uman ngrok`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ngrok http 8080  # Відкрити локальний порт 8080 у публічний HTTPS-доступ
$ ngrok tcp 22  # Публічний тунель для SSH-підключення
```
