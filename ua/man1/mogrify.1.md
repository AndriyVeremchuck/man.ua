# 📖 mogrify(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `imagemagick`  
> **Оригінальний виклик**: `man 1 mogrify`

---

## 🎯 НАЗВА (NAME)
**`mogrify`** — Утиліта ImageMagick для масової пакетної модифікації, зміни формату та оптимізації групи зображень на місці (in-place).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
mogrify [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-format <webp/png/jpg>, -resize <розмір>, -quality <число>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `mogrify` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 mogrify` або аліас `uman mogrify`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ mogrify -format webp -quality 80 *.png  # Пакетна конвертація всіх PNG у поточній папці у формат WebP
$ mogrify -resize 1920x1080\> *.jpg  # Зменшення всіх фото, розмір яких перевищує Full HD
```
