# 📖 oxlint(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `oxlint`  
> **Оригінальний виклик**: `man 1 oxlint`

---

## 🎯 НАЗВА (NAME)
**`oxlint`** — Ультрашвидкий (у 50-100 разів швидший за ESLint) статичний аналізатор коду JavaScript та TypeScript, написаний на Rust.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
oxlint [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-c <конфіг>, --deny-warnings, --fix (автовиправлення), -D (суворий режим)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `oxlint` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 oxlint` або аліас `uman oxlint`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ oxlint src/  # Миттєвий пошук синтаксичних та логічних помилок у директорії src/
$ oxlint --fix .  # Автоматичне виправлення типових помилок коду
```
