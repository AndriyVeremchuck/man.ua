# 📖 wc(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 wc`

---

## 🎯 НАЗВА (NAME)
**`wc`** — Підрахунок кількості рядків, слів, символів та байтів у файлах чи вхідному потоці.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
wc [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-l (лише рядки), -w (лише слова), -c (лише байти), -m (лише символи)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `wc` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 wc` або аліас `uman wc`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ wc -l apps-catalog.py  # Підрахувати точну кількість рядків у файлі коду
$ cat data.csv | wc -l  # Підрахунок рядків із конвеєра
```
