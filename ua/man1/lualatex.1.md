# 📖 lualatex(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `texlive-core`  
> **Оригінальний виклик**: `man 1 lualatex`

---

## 🎯 НАЗВА (NAME)
**`lualatex`** — Новітнє покоління рушія TeX з інтегрованою мовою скриптів Lua для гнучкої алгоритмічної верстки та генерації складних звітів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
lualatex [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-interaction=nonstopmode, --synctex=1, <документ.tex>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `lualatex` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 lualatex` або аліас `uman lualatex`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ lualatex report.tex  # Генерація поліграфічного звіту PDF за допомогою LuaLaTeX
$ lualatex --synctex=1 paper.tex  # Компіляція з підтримкою SyncTeX для синхронізації з редактором коду
```
