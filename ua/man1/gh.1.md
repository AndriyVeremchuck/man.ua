# 📖 gh(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `github-cli`  
> **Оригінальний виклик**: `man 1 gh`

---

## 🎯 НАЗВА (NAME)
**`gh`** — Офіційний командний інтерфейс GitHub для керування Pull Request, Issue, репозиторіями та релізами.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
gh [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`pr list, pr checkout <номер>, repo view, auth status, issue list`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `gh` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 gh` або аліас `uman gh`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ gh pr list  # Список відкритих Pull Request репозиторію
$ gh auth status  # Перевірити статус підключення до акаунту GitHub
```
