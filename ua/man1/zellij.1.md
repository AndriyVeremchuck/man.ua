# 📖 zellij(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `zellij`  
> **Оригінальний виклик**: `man 1 zellij`

---

## 🎯 НАЗВА (NAME)
**`zellij`** — Нове покоління термінальних мультиплексорів на Rust: плагінна система WebAssembly, готові макети (layouts), плаваючі панелі та вбудовані підказки клавіш.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
zellij [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--layout <макет>, attach <сесія>, list-sessions, action <дія>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `zellij` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 zellij` або аліас `uman zellij`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ zellij  # Запуск сучасного термінального робочого простору Zellij із підказками гарячих клавіш
$ zellij --layout compact  # Запуск у компактному режимі без зайвих рамок
```
