# 📖 buildah(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `buildah`  
> **Оригінальний виклик**: `man 1 buildah`

---

## 🎯 НАЗВА (NAME)
**`buildah`** — Інструмент створення та модифікації контейнерних образів стандарту OCI безпосередньо зі скриптів Shell без запуску контейнерного демона.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
buildah [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`from <базовий_образ>, run <контейнер> <команда>, commit <контейнер> <тег>, bud (збірка з Dockerfile)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `buildah` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 buildah` або аліас `uman buildah`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ buildah bud -t my_app:latest .  # Збірка контейнерного образу з Dockerfile за допомогою Buildah
$ buildah images  # Перегляд локальних контейнерних образів
```
