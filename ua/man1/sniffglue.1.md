# 📖 sniffglue(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `sniffglue`  
> **Оригінальний виклик**: `man 1 sniffglue`

---

## 🎯 НАЗВА (NAME)
**`sniffglue`** — Безпечний багатопотоковий аналізатор мережевих пакетів на Rust із пісочницею Seccomp для безпечного парсингу недовіреного трафіку.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
sniffglue [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-p (режим promisc), -d (детальний вивід протоколів), <інтерфейс>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `sniffglue` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 sniffglue` або аліас `uman sniffglue`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo sniffglue eth0  # Безпечний аналіз пакетів на інтерфейсі eth0
$ sudo sniffglue -d any  # Докладне декодування протоколів на всіх інтерфейсах
```
