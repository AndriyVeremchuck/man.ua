# 📖 hexdump(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `util-linux`  
> **Оригінальний виклик**: `man 1 hexdump`

---

## 🎯 НАЗВА (NAME)
**`hexdump`** — Класична утиліта з пакету util-linux для відображення даних файлу у шістнадцятковому, десятковому, вісімковому або символьному форматі.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
hexdump [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-C (канонічний hex+ASCII вивід), -n <довжина> (обсяг байт), -s <зміщення> (пропустити байти), -v (показувати всі дублікати рядків)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `hexdump` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 hexdump` або аліас `uman hexdump`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ hexdump -C -n 128 /dev/urandom  # Канонічний вивід 128 випадкових байт у шістнадцятковому форматі
$ hexdump -C firmware.bin | head -n 30  # Перегляд структури заголовка прошивки
```
