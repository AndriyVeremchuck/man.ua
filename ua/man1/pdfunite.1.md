# 📖 pdfunite(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `poppler`  
> **Оригінальний виклик**: `man 1 pdfunite`

---

## 🎯 НАЗВА (NAME)
**`pdfunite`** — Блискавичне об'єднання кількох файлів PDF в один суцільний документ за допомогою бібліотеки Poppler.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pdfunite [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`<файл1.pdf> <файл2.pdf> ... <вихідний.pdf>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pdfunite` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pdfunite` або аліас `uman pdfunite`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ pdfunite cover.pdf body.pdf appendix.pdf final_book.pdf  # Об'єднання обкладинки, основного блоку та додатків в один PDF
$ pdfunite *.pdf merged_all.pdf  # Злиття всіх PDF-файлів у поточному каталозі в єдиний файл
```
