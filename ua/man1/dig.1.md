# 📖 dig(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `bind`  
> **Оригінальний виклик**: `man 1 dig`

---

## 🎯 НАЗВА (NAME)
**`dig`** — Гнучкий інструмент надсилання прямих запитів до DNS-серверів (A, AAAA, MX, NS, TXT, ANY) з детальним аналізом.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
dig [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`+short (лише відповідь), +trace (повне трасування делегування DNS), MX, TXT, @<сервер>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `dig` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 dig` або аліас `uman dig`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ dig +short google.com  # Швидко отримати IP-адресу домену
$ dig MX github.com  # Показати поштові сервери домену
```
