# 📖 powertop(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `powertop`  
> **Оригінальний виклик**: `man 1 powertop`

---

## 🎯 НАЗВА (NAME)
**`powertop`** — Діагностичний інструмент Intel для аналізу енергоспоживання компонентів, процесів і переривань із функцією автоналаштування живлення.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
powertop [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--auto-tune (автоматична оптимізація енергоспоживання), --calibrate, --csv=<файл>, --html=<файл>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `powertop` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 powertop` або аліас `uman powertop`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo powertop  # Інтерактивний TUI огляд споживання енергії процесором, драйверами та додатками
$ sudo powertop --auto-tune  # Автоматичне увімкнення всіх енергоощадних режимів компонентів
```
