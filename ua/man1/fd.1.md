# 📖 fd(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `fd`  
> **Оригінальний виклик**: `man 1 fd`

---

## 🎯 НАЗВА (NAME)
**`fd`** — Блискавична, проста та інтуїтивна альтернатива find на мові Rust з кольоровим виводом.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
fd [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-e <розширення>, -H (приховані), -t f/d (тип), -x <команда>, -E <виключити>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `fd` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 fd` або аліас `uman fd`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ fd -e py  # Швидкий пошук усіх Python-файлів у дереві
$ fd -H config  # Пошук файлів конфігурації включно з прихованими
```
