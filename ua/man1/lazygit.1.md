# 📖 lazygit(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `lazygit`  
> **Оригінальний виклик**: `man 1 lazygit`

---

## 🎯 НАЗВА (NAME)
**`lazygit`** — Найзручніший термінальний інтерфейс для Git на Go: візуальне керування гілками, хуками, stash, розв'язання конфліктів merge та інтерактивний rebase.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
lazygit [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-p <шлях> (шлях до репозиторію), -ucd (налаштування), --git-dir, --work-tree`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `lazygit` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 lazygit` або аліас `uman lazygit`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ lazygit  # Відкрити інтерактивну TUI-панель керування поточним Git-репозиторієм
$ lazygit -p /home/dusha/Шаблони/APP  # Відкрити керування конкретним репозиторієм
```
