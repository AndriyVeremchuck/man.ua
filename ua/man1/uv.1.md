# 📖 uv(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `uv`  
> **Оригінальний виклик**: `man 1 uv`

---

## 🎯 НАЗВА (NAME)
**`uv`** — Ультрашвидкий (у 10-100 разів швидший за pip) пакетний менеджер та резолвер залежностей Python, написаний на Rust компанією Astral.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
uv [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`pip install <пакет>, venv (створення venv за мілісекунди), pip compile <req.in>, pip sync, python install <версія>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `uv` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 uv` або аліас `uman uv`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ uv venv  # Миттєве створення віртуального середовища Python
$ uv pip install -r requirements.txt  # Ультрашвидке паралельне встановлення залежностей проєкту
```
