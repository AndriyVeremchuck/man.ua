# 📖 xfs_repair(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `xfsprogs`  
> **Оригінальний виклик**: `man 1 xfs_repair`

---

## 🎯 НАЗВА (NAME)
**`xfs_repair`** — Високоефективне відновлення та усунення пошкоджень файлової системи XFS.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
xfs_repair [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-n (лише перевірка без внесення змін dry-run), -v (детально)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `xfs_repair` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 xfs_repair` або аліас `uman xfs_repair`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo xfs_repair -n /dev/sdb1  # Тестова перевірка XFS без запису на диск
```
