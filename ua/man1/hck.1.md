# 📖 hck(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `hck`  
> **Оригінальний виклик**: `man 1 hck`

---

## 🎯 НАЗВА (NAME)
**`hck`** — Ультрашвидкий синтаксичний парсер колонок та текстових файлів CSV/TSV на Rust (у 5-10 разів швидший за cut).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
hck [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-d <роздільник>, -f <поля: 1,3-5>, -r (регулярний вираз як роздільник)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `hck` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 hck` або аліас `uman hck`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ hck -d "," -f 1-3 data.csv  # Витяг перших трьох стовпців із великого файлу CSV
$ hck -d " " -f 1 data.log  # Швидке вилучення IP-адрес із гігабайтних логів
```
