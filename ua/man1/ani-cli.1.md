# 📖 ani-cli(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `ani-cli`  
> **Оригінальний виклик**: `man 1 ani-cli`

---

## 🎯 НАЗВА (NAME)
**`ani-cli`** — Утиліта командного рядка для миттєвого пошуку та стримінгового перегляду аніме через відеоплеєр mpv без відкриття браузера.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ani-cli [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-q <якість: 720p, 1080p>, -d (завантажити замість перегляду), -e <серія>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ani-cli` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ani-cli` або аліас `uman ani-cli`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ani-cli  # Інтерактивний пошук та перегляд аніме в терміналі
$ ani-cli -q 1080p -d "Attack on Titan"  # Завантаження серій у високій якості 1080p
```
