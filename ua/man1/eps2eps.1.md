# 📖 eps2eps(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `ghostscript`  
> **Оригінальний виклик**: `man 1 eps2eps`

---

## 🎯 НАЗВА (NAME)
**`eps2eps`** — Очищення, стандартизація та перерахунок складних Encapsulated PostScript (EPS) файлів для максимальної сумісності з верстальними пакетами.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
eps2eps [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`<вхідний.eps> <вихідний.eps>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `eps2eps` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 eps2eps` або аліас `uman eps2eps`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ eps2eps complex_logo.eps clean_logo.eps  # Очищення та спрощення внутрішньої векторної структури EPS
$ eps2eps figure1.eps figure1_fixed.eps  # Виправлення некоректних обмежувальних рамок BoundingBox
```
