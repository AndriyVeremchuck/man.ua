# 📖 realpath(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 realpath`

---

## 🎯 НАЗВА (NAME)
**`realpath`** — Отримання повного канонічного абсолютного шляху до файлу з розкриттям усіх символьних посилань.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
realpath [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-m (не вимагати існування), -q (тихий), --relative-to=<шлях>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `realpath` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 realpath` або аліас `uman realpath`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ realpath ~/.bashrc  # Показати повний абсолютний шлях до файлу
$ realpath /usr/bin/python  # Розкрити символьні посилання на реальний бінарник Python
```
