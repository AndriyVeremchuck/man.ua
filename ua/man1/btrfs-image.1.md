# 📖 btrfs-image(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `btrfs-progs`  
> **Оригінальний виклик**: `man 1 btrfs-image`

---

## 🎯 НАЗВА (NAME)
**`btrfs-image`** — Створення та відновлення компактного дампа метаданих файлової системи Btrfs без самих даних користувача (для діагностики та дебагу).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
btrfs-image [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-c <рівень_стиснення: 0-9>, -t <потоки>, -r (відновлення з образу)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `btrfs-image` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 btrfs-image` або аліас `uman btrfs-image`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo btrfs-image -c 9 /dev/nvme0n1p2 btrfs_meta.img  # Створення стисненого образу структури метаданих розділу
$ btrfs-image -r btrfs_meta.img restored.raw  # Розгортання метаданих у файл для аналізу
```
