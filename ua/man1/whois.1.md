# 📖 whois(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `whois`  
> **Оригінальний виклик**: `man 1 whois`

---

## 🎯 НАЗВА (NAME)
**`whois`** — Клієнт протоколу WHOIS (RFC 3912) для отримання інформації про власника доменного імені, реєстратора, автономні системи (ASN) та IP-діапазони.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
whois [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-h <сервер> (вибір сервера WHOIS), -p <порт>, -I (первинне джерело)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `whois` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 whois` або аліас `uman whois`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ whois archlinux.org  # Перегляд реєстратора, дати створення та серверів імен домену archlinux.org
$ whois 1.1.1.1  # Отримання інформації про власника IP-адреси та номер автономної системи ASN
```
