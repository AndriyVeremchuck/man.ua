# 📖 uname(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 uname`

---

## 🎯 НАЗВА (NAME)
**`uname`** — Виведення інформації про операційну систему, реліз ядра Linux (CachyOS) та архітектуру процесора.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
uname [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-a (всі параметри), -r (реліз ядра), -m (архітектура), -s (назва ОС)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `uname` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 uname` або аліас `uman uname`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ uname -a  # Показати версію ядра Linux, дату збірки та архітектуру x86_64
```
