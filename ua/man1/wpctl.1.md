# 📖 wpctl(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `wireplumber`  
> **Оригінальний виклик**: `man 1 wpctl`

---

## 🎯 НАЗВА (NAME)
**`wpctl`** — Керування сесійним менеджером WirePlumber для аудіосервера PipeWire: налаштування гучності, перемикання аудіокарт, мікрофонів та звукових профілів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
wpctl [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`status (дерево пристроїв), set-volume <ID> <рівень>, set-mute <ID> <0/1/toggle>, set-default <ID>, inspect <ID>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `wpctl` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 wpctl` або аліас `uman wpctl`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ wpctl status  # Огляд усіх аудіопристроїв, входів, виходів та відеопотоків PipeWire
$ wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%+  # Збільшити гучність системного аудіовиходу на 5%
$ wpctl set-mute @DEFAULT_AUDIO_SOURCE@ toggle  # Перемкнути стан мікрофона (Mute / Unmute)
```
