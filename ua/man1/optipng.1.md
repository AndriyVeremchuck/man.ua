## 🎯 НАЗВА (NAME)
**`optipng`** — Оптимізатор файлів PNG, що перестискає зображення без жодних візуальних втрат якості (lossless compression).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
optipng [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-o<1-7> (рівень оптимізації, де 7 найглибший), -strip all (видалити всі метадані), -quiet`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `optipng` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 optipng` або аліас `uman optipng`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ optipng -o7 screenshot.png  # Максимальне стиснення PNG файлу без втрати якості
$ optipng -strip all icons/*.png  # Пакетна оптимізація іконок для веб-додатку
```
