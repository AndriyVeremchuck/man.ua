# 📖 nft(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `nftables`  
> **Оригінальний виклик**: `man 1 nft`

---

## 🎯 НАЗВА (NAME)
**`nft`** — Сучасний інструмент керування файрволом nftables ядра Linux, який замінив iptables, ip6tables, arptables та ebtables.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
nft [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`list ruleset (показати всі правила), flush ruleset (очистити таблиці), -f <файл> (завантажити правила), -c (перевірка синтаксису без застосування)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `nft` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 nft` або аліас `uman nft`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo nft list ruleset  # Виведення повної поточної конфігурації таблиць та ланцюжків файрвола
$ sudo nft add table inet my_filter  # Створення нової комбінованої таблиці фільтрації IPv4/IPv6
```
