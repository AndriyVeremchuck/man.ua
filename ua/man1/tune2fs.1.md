# 📖 tune2fs(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `e2fsprogs`  
> **Оригінальний виклик**: `man 1 tune2fs`

---

## 🎯 НАЗВА (NAME)
**`tune2fs`** — Налаштування параметрів суперблоку, резерву місця для root та періодичності перевірок Ext2/3/4.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
tune2fs [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-l (показати всі параметри суперблоку), -m <відсоток_резерву>, -L <нова_мітка>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `tune2fs` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 tune2fs` або аліас `uman tune2fs`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo tune2fs -l /dev/sda1  # Переглянути параметри суперблоку Ext4
```
