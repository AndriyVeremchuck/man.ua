# 📖 micro(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `micro`  
> **Оригінальний виклик**: `man 1 micro`

---

## 🎯 НАЗВА (NAME)
**`micro`** — Сучасний та інтуїтивно зрозумілий консольний текстовий редактор на Go з підтримкою миші, вкладок, плагінів та звичних гарячих клавіш Ctrl+C/Ctrl+V.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
micro [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-plugin install <плагін>, +<номер_рядка>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `micro` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 micro` або аліас `uman micro`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ micro main.py  # Зручне редагування коду з підтримкою стандартних комбінацій клавіш
$ micro -plugin list  # Список встановлених розширень та тем
```
