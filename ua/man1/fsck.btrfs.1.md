# 📖 fsck.btrfs(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `btrfs-progs`  
> **Оригінальний виклик**: `man 1 fsck.btrfs`

---

## 🎯 НАЗВА (NAME)
**`fsck.btrfs`** — Утиліта перевірки стану файлової системи Btrfs (зазвичай викликає btrfs check для верифікації дерев метаданих та контрольних сум).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
fsck.btrfs [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--readonly, --repair (увага: використовувати тільки за крайньої потреби)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `fsck.btrfs` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 fsck.btrfs` або аліас `uman fsck.btrfs`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo btrfs check --readonly /dev/nvme0n1p2  # Безпечна перевірка цілісності дерева метаданих Btrfs у режимі лише читання
$ sudo btrfs check /dev/sdb1  # Діагностика помилок файлової системи
```
