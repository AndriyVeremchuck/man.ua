# 📖 lshw(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `lshw`  
> **Оригінальний виклик**: `man 1 lshw`

---

## 🎯 НАЗВА (NAME)
**`lshw`** — Генератор детального дерева апаратного забезпечення ПК: точні моделі планок пам'яті, таймінги, материнська плата, контролери та шини.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
lshw [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-short (стислий огляд компонентів), -html (генерація красивого HTML звіту), -json, -C <клас: memory, display, network, disk>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `lshw` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 lshw` або аліас `uman lshw`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo lshw -short  # Короткий табличний огляд усіх апаратних вузлів комп'ютера
$ sudo lshw -C memory  # Детальна інформація про встановлені планки оперативної пам'яті, частоту та слоти
```
