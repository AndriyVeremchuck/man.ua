# 📖 mycli(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `mycli`  
> **Оригінальний виклик**: `man 1 mycli`

---

## 🎯 НАЗВА (NAME)
**`mycli`** — Термінальний клієнт для баз даних MySQL та MariaDB з контекстним автодоповненням запитів та форматованими таблицями.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
mycli [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-u <користувач>, -p <пароль>, -h <хост>, -P <порт>, <база_даних>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `mycli` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 mycli` або аліас `uman mycli`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ mycli -u root -h localhost my_database  # Підключення до MySQL з автодоповненням синтаксису
$ mycli --help  # Перегляд опцій підключення mycli
```
