# 📖 ocrmypdf(1) — Українська системна документація

---

## 🎯 НАЗВА (NAME)
**`ocrmypdf`** — Додавання шару оптичного розпізнавання тексту (OCR) на основі Tesseract до відсканованих PDF документів для можливості пошуку та копіювання.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ocrmypdf [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-l <мова: ukr+eng>, --deskew (вирівнювання сторінок), --clean, --optimize <1-3>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ocrmypdf` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ocrmypdf` або аліас `uman ocrmypdf`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ocrmypdf -l ukr+eng --deskew scan.pdf searchable.pdf  # Розпізнавання тексту українською та англійською мовами у сканованому PDF
$ ocrmypdf --optimize 3 input.pdf compressed_searchable.pdf  # OCR розпізнавання з одночасною максимальною компресією файлу
```
