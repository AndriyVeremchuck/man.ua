## 🎯 НАЗВА (NAME)
**`btrfs-convert`** — Утиліта конвертації існуючих файлових систем ext2/ext3/ext4 або reiserfs у Btrfs на місці (in-place) зі збереженням можливості відкату.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
btrfs-convert [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-r / --rollback (відкат назад до ext4), -p (прогрес-бар), -L <нова_мітка>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `btrfs-convert` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 btrfs-convert` або аліас `uman btrfs-convert`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo btrfs-convert -p /dev/sdb1  # Конвертація розділу ext4 у Btrfs без втрати існуючих файлів
$ sudo btrfs-convert -r /dev/sdb1  # Повний відкат змін назад до вихідного стану ext4
```
