# 📖 litecli(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `litecli`  
> **Оригінальний виклик**: `man 1 litecli`

---

## 🎯 НАЗВА (NAME)
**`litecli`** — Зручний термінальний інтерфейс для файлів баз даних SQLite з підсвічуванням синтаксису, автодоповненням та історією команд.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
litecli [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`<файл.db>, --auto-vertical-output`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `litecli` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 litecli` або аліас `uman litecli`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ litecli app_database.sqlite  # Відкриття локальної бази даних SQLite в інтерактивному інтерфейсі
$ litecli -e "SELECT count(*) FROM users;" db.sqlite  # Швидке виконання запиту з консолі
```
