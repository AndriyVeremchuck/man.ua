## 🎯 НАЗВА (NAME)
**`nslookup`** — Інтерактивні та разові запити до DNS-серверів для зіставлення доменних імен та IP-адрес.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
nslookup [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-type=<тип_запису>, <домен> <dns_сервер>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `nslookup` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 nslookup` або аліас `uman nslookup`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ nslookup github.com  # Дізнатися IP-адресу сервера GitHub через системний DNS
```
