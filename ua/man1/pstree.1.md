# 📖 pstree(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `psmisc`  
> **Оригінальний виклик**: `man 1 pstree`

---

## 🎯 НАЗВА (NAME)
**`pstree`** — Наочне відображення запущених процесів у вигляді дерева ієрархічних зв'язків батьківських та дочірніх процесів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pstree [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-p (показувати PID кожного процесу), -u (показувати власника/користувача), -a (повні аргументи команд), -h (підсвітити поточний процес)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pstree` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pstree` або аліас `uman pstree`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ pstree -p  # Виведення дерева всіх запущених процесів системи з їхніми PID
$ pstree -p $(pgrep plasmashell)  # Перегляд дочірніх процесів стільниці KDE Plasma
```
