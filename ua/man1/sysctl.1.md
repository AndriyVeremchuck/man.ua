# 📖 sysctl(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `procps-ng`  
> **Оригінальний виклик**: `man 1 sysctl`

---

## 🎯 НАЗВА (NAME)
**`sysctl`** — Читання та модифікація внутрішніх параметрів ядра Linux (віртуальна пам'ять, мережевий стек, безпека) під час роботи (/proc/sys/).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
sysctl [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-a (вивести всі активні параметри), -w <ключ=значення> (зміна значення), -p [файл] (завантаження з /etc/sysctl.conf), -n (виводити тільки значення)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `sysctl` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 sysctl` або аліас `uman sysctl`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo sysctl -w vm.swappiness=10  # Зниження агресивності використання swap-пам'яті на користь RAM
$ sysctl net.ipv4.ip_forward  # Перевірка статусу маршрутизації IPv4 пакетів у системі
```
