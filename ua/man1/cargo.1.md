# 📖 cargo(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `rust`  
> **Оригінальний виклик**: `man 1 cargo`

---

## 🎯 НАЗВА (NAME)
**`cargo`** — Офіційний менеджер пакетів та система збірки для екосистеми Rust: завантаження залежностей, компіляція, тестування та публікація на crates.io.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
cargo [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`build [--release] (компіляція), run [--release] (запуск), test (тести), check (швидка перевірка синтаксису), clippy (лінтинг)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `cargo` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 cargo` або аліас `uman cargo`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ cargo build --release  # Максимально оптимізована релізна компіляція Rust-проєкту
$ cargo clippy  # Глибокий статичний аналіз та лінтинг вихідного коду
```
