# 📖 sops(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `sops`  
> **Оригінальний виклик**: `man 1 sops`

---

## 🎯 НАЗВА (NAME)
**`sops`** — Редактор та шифратор файлів конфігурації (YAML, JSON, ENV, INI) для безпечного збереження паролів та секретів у Git (GitOps).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
sops [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-e (зашифрувати файл), -d (розшифрувати), --age <ключі>, --in-place`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `sops` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 sops` або аліас `uman sops`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sops secrets.yaml  # Інтерактивне редагування зашифрованого файлу конфігурації у текстовому редакторі
$ sops -d config.enc.yaml > config.yaml  # Розшифрування значень конфігурації для деплою
```
