# 📖 groups(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 groups`

---

## 🎯 НАЗВА (NAME)
**`groups`** — Виведення списку всіх груп, членом яких є вказаний або поточний користувач.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
groups [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`<ім'я_користувача>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `groups` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 groups` або аліас `uman groups`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ groups  # Показати групи поточного користувача
$ groups dusha  # Показати всі групи користувача dusha
```
