## 🎯 НАЗВА (NAME)
**`mkfs.exfat`** — Створення та форматування розділів у файлову систему exFAT для роботи з великими файлами (>4GB) та кросплатформної сумісності з Windows/macOS.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
mkfs.exfat [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-L <мітка> (назва тому), -c <розмір_кластера>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `mkfs.exfat` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 mkfs.exfat` або аліас `uman mkfs.exfat`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo mkfs.exfat -L "ExtremeSSD" /dev/sdb1  # Форматування зовнішнього портативного SSD в exFAT
$ sudo mkfs.exfat /dev/sdc1  # Швидке створення exFAT розділу на карті пам'яті SD
```
