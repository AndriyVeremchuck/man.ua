# 📖 flutter(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `Flutter SDK (/opt/flutter/bin/flutter)`  
> **Оригінальний виклик**: `man 1 flutter`

---

## 🎯 НАЗВА (NAME)
**`flutter`** — Головний CLI інструмент фреймворка Flutter від Google для збірки нативних додатків під Linux, Android, iOS, Web та Desktop.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
flutter [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`doctor, run -d linux, build linux --release, pub get, analyze, test`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `flutter` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 flutter` або аліас `uman flutter`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ flutter doctor -v  # Повна перевірка працездатності оточення Flutter та інструментів
$ flutter analyze  # Статичний аналіз коду проекту на наявність помилок
```
