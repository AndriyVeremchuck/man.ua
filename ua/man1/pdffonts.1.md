# 📖 pdffonts(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `poppler`  
> **Оригінальний виклик**: `man 1 pdffonts`

---

## 🎯 НАЗВА (NAME)
**`pdffonts`** — Аналіз та перевірка шрифтового складу PDF: список усіх шрифтів, типи (TrueType, Type 1, CID, Type 3), статус вбудовування (embedded/subset).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pdffonts [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-f <перша_сторінка>, -l <остання_сторінка>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pdffonts` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pdffonts` або аліас `uman pdffonts`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ pdffonts publication.pdf  # Перевірка чи всі шрифти коректно вбудовані у PDF перед здачею у типографію
$ pdffonts -f 1 -l 3 doc.pdf  # Шрифтовий аудит перших трьох сторінок
```
