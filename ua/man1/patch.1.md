# 📖 patch(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `patch`  
> **Оригінальний виклик**: `man 1 patch`

---

## 🎯 НАЗВА (NAME)
**`patch`** — Застосування файлу різниць (патча) до оригінального вихідного коду або конфігурації.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
patch [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-p<рівень_вкладеності>, -R (скасувати патч reverse), --dry-run (тестовий прогін)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `patch` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 patch` або аліас `uman patch`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ patch -p1 < update.patch  # Застосувати патч до поточної директорії проекту
```
