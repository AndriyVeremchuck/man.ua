# 📖 trivy(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `trivy`  
> **Оригінальний виклик**: `man 1 trivy`

---

## 🎯 НАЗВА (NAME)
**`trivy`** — Комплексний сканер безпеки для виявлення CVE-вразливостей, секретів та помилок конфігурації в контейнерах, репозиторіях та K8s.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
trivy [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`image <образ>, fs <папка> (сканування файлів), repo <url>, --severity HIGH,CRITICAL`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `trivy` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 trivy` або аліас `uman trivy`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ trivy image archlinux:latest  # Сканування контейнерного образу на наявність відомих вразливостей
$ trivy fs --severity HIGH,CRITICAL .  # Перевірка вихідного коду та залежностей поточного проєкту
```
