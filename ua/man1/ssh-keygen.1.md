# 📖 ssh-keygen(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `openssh`  
> **Оригінальний виклик**: `man 1 ssh-keygen`

---

## 🎯 НАЗВА (NAME)
**`ssh-keygen`** — Генерація та керування парами криптографічних ключів SSH для безпечної автентифікації на віддалених серверах (Ed25519, RSA, ECDSA).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ssh-keygen [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-t <тип> (ed25519, rsa, ecdsa), -C <коментар>, -b <біти> (розмір ключа), -f <шлях_до_файлу>, -p (зміна пароля ключа)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ssh-keygen` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ssh-keygen` або аліас `uman ssh-keygen`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ssh-keygen -t ed25519 -C "dusha@workstation"  # Генерація сучасного та надстійкого ключа стандарту Ed25519
$ ssh-keygen -l -f ~/.ssh/id_ed25519.pub  # Перегляд цифрового відбитка (fingerprint) публічного ключа
```
