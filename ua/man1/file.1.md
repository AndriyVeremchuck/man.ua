# 📖 file(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `file`  
> **Оригінальний виклик**: `man 1 file`

---

## 🎯 НАЗВА (NAME)
**`file`** — Визначення точного типу файлу (MIME-тип, кодування, архітектура бінарника) за сигнатурою заголовка.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
file [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-b (короткий вивід без імені), -i (MIME-тип та кодування), -z (заглядати всередину стиснених файлів)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `file` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 file` або аліас `uman file`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ file /usr/bin/fish  # Визначити тип виконуваного ELF-бінарника та архітектуру
$ file -i photo.png  # Визначити точний MIME-тип файлу
```
