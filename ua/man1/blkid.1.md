# 📖 blkid(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `util-linux`  
> **Оригінальний виклик**: `man 1 blkid`

---

## 🎯 НАЗВА (NAME)
**`blkid`** — Визначення та виведення унікальних UUID ідентифікаторів, міток та типів файлових систем блочних пристроїв.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
blkid [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-o list (табличний вивід), -s UUID, -p (низькорівневий аналіз)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `blkid` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 blkid` або аліас `uman blkid`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo blkid  # Показати UUID та типи ФС усіх підключених дисків
```
