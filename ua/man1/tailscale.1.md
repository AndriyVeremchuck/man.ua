# 📖 tailscale(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `tailscale`  
> **Оригінальний виклик**: `man 1 tailscale`

---

## 🎯 НАЗВА (NAME)
**`tailscale`** — Клієнт сервісу Tailscale для миттєвого об'єднання комп'ютерів, серверів та мобільних пристроїв у захищену mesh-мережу на базі WireGuard.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
tailscale [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`up (підключення до мережі), down (відключення), status (стан пірів), ip (перегляд призначеного IP), ping <хост>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `tailscale` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 tailscale` або аліас `uman tailscale`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ tailscale status  # Перегляд списку підключених пристроїв у приватній мережі Tailscale
$ sudo tailscale up --accept-routes  # Підключення до mesh-мережі з підтримкою маршрутизації підмереж
```
