# 📖 doggo(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `doggo`  
> **Оригінальний виклик**: `man 1 doggo`

---

## 🎯 НАЗВА (NAME)
**`doggo`** — Сучасний клієнт DNS на мові Go з кольоровим табличним виводом, підтримкою DoH (DNS-over-HTTPS), DoT (DNS-over-TLS) та JSON.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
doggo [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--doh <провайдер: cloudflare/google>, --json, -t <тип: A, AAAA, MX, TXT>, @<сервер>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `doggo` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 doggo` або аліас `uman doggo`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ doggo google.com --doh cloudflare  # Захищений DNS-запит через DNS-over-HTTPS до Cloudflare
$ doggo MX github.com  # Перегляд поштових MX серверів домену
```
