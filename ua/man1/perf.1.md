# 📖 perf(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `perf`  
> **Оригінальний виклик**: `man 1 perf`

---

## 🎯 НАЗВА (NAME)
**`perf`** — Офіційний високопродуктивний профілювальник підсистеми Performance Counters for Linux ядра для аналізу CPU, кеш-промахів та інструкцій.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
perf [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`top (моніторинг функцій у реальному часі), record -g (запис стеку викликів), report (візуалізація профілю), stat (апаратні лічильники CPU)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `perf` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 perf` або аліас `uman perf`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ perf top  # Інтерактивний перегляд функцій, що найбільше навантажують процесор
$ perf stat -d ./my_benchmark  # Збір детальної статистики CPU: інструкції за такт (IPC), кеш L1/L3
```
