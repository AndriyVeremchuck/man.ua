# 📖 resolvectl(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `systemd`  
> **Оригінальний виклик**: `man 1 resolvectl`

---

## 🎯 НАЗВА (NAME)
**`resolvectl`** — Інструмент діагностики та керування системним DNS-резолвером systemd-resolved та очищення DNS-кешу.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
resolvectl [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`status, query <домен>, flush-caches, dns <адаптер> <сервери>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `resolvectl` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 resolvectl` або аліас `uman resolvectl`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ resolvectl status  # Перевірити активні DNS-сервери та статус протоколу DNSSEC
$ resolvectl flush-caches  # Очистити локальний кеш DNS
```
