# 📖 cpupower(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `cpupower`  
> **Оригінальний виклик**: `man 1 cpupower`

---

## 🎯 НАЗВА (NAME)
**`cpupower`** — Офіційний інструмент ядра Linux для моніторингу та конфігурації частотних регуляторів (governors), Turbo Boost та енергетичних станів CPU.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
cpupower [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`frequency-info (поточні частоти й регулятори), frequency-set -g <gov> (встановлення performance/powersave), idle-info (перегляд C-states), set -b <0-15> (енергобаланс)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `cpupower` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 cpupower` або аліас `uman cpupower`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo cpupower frequency-set -g performance  # Увімкнення максимальної продуктивності для всіх ядер CPU
$ cpupower frequency-info  # Перегляд реальних частот ядер, регуляторів та статусу Turbo Boost
```
