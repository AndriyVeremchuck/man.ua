# 📖 piper(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `piper-tts (Python ~/.local/bin)`  
> **Оригінальний виклик**: `man 1 piper`

---

## 🎯 НАЗВА (NAME)
**`piper`** — Блискавичний автономний нейромережевий синтезатор мовлення для Linux, оптимізований для локальної роботи без інтернету.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
piper [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--model <onnx_модель>, --output_file <файл.wav>, --cuda`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `piper` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 piper` або аліас `uman piper`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ echo 'Привіт' | piper --model uk_UA.onnx --output_file test.wav  # Швидка офлайн-генерація українського звукового файлу WAV
```
