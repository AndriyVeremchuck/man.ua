# 📖 unoconv(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `unoconv`  
> **Оригінальний виклик**: `man 1 unoconv`

---

## 🎯 НАЗВА (NAME)
**`unoconv`** — Інструмент автоматизації перетворення документів між усіма форматами, що підтримуються LibreOffice через інтерфейс UNO-протоколу.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
unoconv [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-f <формат: pdf, docx, odt, html, txt>, -o <вихідний_файл>, --server <хост>, --port <порт>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `unoconv` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 unoconv` або аліас `uman unoconv`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ unoconv -f pdf presentation.pptx  # Конвертація презентації PowerPoint у PDF через UNO-демон
$ unoconv -f txt spreadsheet.ods  # Експорт текстових даних із таблиці LibreOffice Calc ODS
```
