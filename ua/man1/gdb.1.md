# 📖 gdb(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `gdb`  
> **Оригінальний виклик**: `man 1 gdb`

---

## 🎯 НАЗВА (NAME)
**`gdb`** — Еталонний інтерактивний відлагоджувач коду GNU Debugger для мов C, C++, Rust, Go та Fortran з підтримкою точок зупинки та аналізу пам'яті.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
gdb [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-p <PID> (налагодження процесу), -c <core> (аналіз дампа), --args <програма> <арг>, -tui (графічний TUI інтерфейс), -q (тихий режим)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `gdb` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 gdb` або аліас `uman gdb`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ gdb -tui ./my_app  # Запуск програми у візуальному термінальному інтерфейсі GDB TUI
$ gdb -c /var/lib/systemd/coredump/core.1234 ./my_app  # Аналіз аварійного дампу пам'яті (core dump) після сегфолту
```
