# 📖 bore(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `bore (~/.local/bin)`  
> **Оригінальний виклик**: `man 1 bore`

---

## 🎯 НАЗВА (NAME)
**`bore`** — Сучасний надлегкий TCP-тунель на Rust без конфігурацій для прокидання портів назовні.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
bore [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`local <порт> --to <сервер>, server`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `bore` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 bore` або аліас `uman bore`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ bore local 3000 --to bore.pub  # Миттєве створення публічного тунелю на тестовий сервер
```
