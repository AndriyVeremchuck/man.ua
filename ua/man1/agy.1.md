# 📖 agy(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `Google DeepMind Antigravity (~/.local/bin/agy)`  
> **Оригінальний виклик**: `man 1 agy`

---

## 🎯 НАЗВА (NAME)
**`agy`** — Google DeepMind Antigravity CLI — передовий автономний агентний AI-асистент для парного програмування, автоматизації, написання та рефакторингу коду.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
agy [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--help, --version, --model <модель>, --resume, --workspace <шлях>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `agy` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 agy` або аліас `uman agy`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ agy  # Запуск інтерактивної сесії AI-асистента Antigravity
$ agy --help  # Довідка щодо налаштувань, моделей та опцій
```
