# 📖 clinfo(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `clinfo`  
> **Оригінальний виклик**: `man 1 clinfo`

---

## 🎯 НАЗВА (NAME)
**`clinfo`** — Виведення повної вичерпної інформації про доступні апаратні платформи, обчислювальні пристрої GPU/CPU та розширення OpenCL.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
clinfo [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-l (короткий список платформ та пристроїв), -s (короткий підсумок)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `clinfo` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 clinfo` або аліас `uman clinfo`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ clinfo -l  # Перегляд знайдених пристроїв OpenCL (Nvidia CUDA OpenCL / Intel / AMD)
$ clinfo | grep -E "Platform Name|Device Name|Global memory"  # Швидка перевірка відеокарти та обсягу пам'яті для OpenCL обчислень
```
