# 📖 paru(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `paru`  
> **Оригінальний виклик**: `man 1 paru`

---

## 🎯 НАЗВА (NAME)
**`paru`** — Сучасний швидкий AUR-хелпер нового покоління на мові Rust з інтерактивним переглядом PKGBUILD.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
paru [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-Syu, -S <пакет>, --bottomup (вивід знизу вгору), --noconfirm`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `paru` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 paru` або аліас `uman paru`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ paru -Syu  # Оновлення системи та AUR-репозиторіїв через Paru
```
