# 📖 cpdf(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `cpdf`  
> **Оригінальний виклик**: `man 1 cpdf`

---

## 🎯 НАЗВА (NAME)
**`cpdf`** — Професійний інструмент поліграфічної підготовки PDF: наскрізна нумерація сторінок (Bates numbering), накладання колонтитулів, шифрування та масштабування.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
cpdf [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-add-text "<текст>", -topleft / -bottomright, -scale-to-fit <формат>, -encrypt AES256`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `cpdf` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 cpdf` або аліас `uman cpdf`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ cpdf -add-text "Сторінка %Page з %Pages" -bottomright 20 in.pdf -o numbered.pdf  # Автоматичне додавання номерів сторінок у правому нижньому кутку
$ cpdf -scale-to-fit "a4portrait" in.pdf -o a4_scaled.pdf  # Масштабування вмісту документа точно під стандартний формат A4
```
