# 📖 gunzip(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `gzip`  
> **Оригінальний виклик**: `man 1 gunzip`

---

## 🎯 НАЗВА (NAME)
**`gunzip`** — Розпакування файлів формату .gz (еквівалент gzip -d).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
gunzip [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-k (зберегти .gz архів), -v (детально)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `gunzip` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 gunzip` або аліас `uman gunzip`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ gunzip -k access.log.gz  # Розпакувати .gz файл зі збереженням архіву
```
