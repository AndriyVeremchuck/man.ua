# 📖 poetry(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `python-poetry`  
> **Оригінальний виклик**: `man 1 poetry`

---

## 🎯 НАЗВА (NAME)
**`poetry`** — Повнофункціональний інструмент керування залежностями, віртуальними середовищами та пакуванням бібліотек Python за стандартом pyproject.toml.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
poetry [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`install (встановлення залежностей), add <пакет>, run <команда>, shell (активація venv), build (збірка whl)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `poetry` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 poetry` або аліас `uman poetry`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ poetry install  # Детерміноване встановлення всіх залежностей із файлу poetry.lock
$ poetry run python main.py  # Виконання скрипту в ізольованому оточенні Poetry
```
