# 📖 broot(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `broot`  
> **Оригінальний виклик**: `man 1 broot`

---

## 🎯 НАЗВА (NAME)
**`broot`** — Інноваційна деревоподібна навігація файловою системою на Rust: показує вміст папок так, щоб дерево завжди вміщувалося на одному екрані.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
broot [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-h / --hidden (показувати приховані), -s / --sizes (розміри), -c <команда>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `broot` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 broot` або аліас `uman broot`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ broot  # Запуск інтерактивного розумного дерева каталогів
$ broot --sizes  # Деревоподібний огляд із точним підрахунком розміру кожної папки
```
