# 📖 ldd(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `glibc`  
> **Оригінальний виклик**: `man 1 ldd`

---

## 🎯 НАЗВА (NAME)
**`ldd`** — Утиліта аналізу залежностей бінарних файлів від динамічних бібліотек (.so) та пошуку відсутніх модулів лінкування.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ldd [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-v (детальна версійність бібліотек), -u (невикористовувані залежності), -d (перевірка переміщень даних), -r (перевірка переміщень коду)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ldd` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ldd` або аліас `uman ldd`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ldd /usr/bin/ffmpeg  # Перевірка всіх спільних бібліотек .so для утиліти FFmpeg
$ ldd -v /usr/bin/python3  # Детальний перегляд версій залежностей інтерпретатора Python
```
