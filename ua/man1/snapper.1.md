---

## 🎯 НАЗВА (NAME)
**`snapper`** — Інструмент для автоматичного створення, відкату та керування знімками (snapshots) файлової системи Btrfs або Thin-LVM у CachyOS.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
snapper [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`list (список усіх знімків), create -d <опис> (створення знімка), undochange <num1>..<num2> (відкат змін), diff <num1>..<num2> (порівняння)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `snapper` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 snapper` або аліас `uman snapper`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ snapper list  # Перегляд усіх автоматичних та ручних знімків Btrfs
$ sudo snapper create -d "Перед великим оновленням системи"  # Створення ручного знімка системи
```
