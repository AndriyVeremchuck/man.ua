# 📖 amixer(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `alsa-utils`  
> **Оригінальний виклик**: `man 1 amixer`

---

## 🎯 НАЗВА (NAME)
**`amixer`** — Командний інтерфейс налаштування гучності, вимкнення звуку (mute) та конфігурації мікшерів звукових карт ALSA без GUI.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
amixer [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`set <елемент> <значення> (Master 50%+, Master toggle), sget <елемент>, scontrols (список мікшерів)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `amixer` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 amixer` або аліас `uman amixer`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ amixer set Master 5%+  # Збільшення загальної системної гучності на 5%
$ amixer set Master toggle  # Миттєве вимкнення або увімкнення звуку (Mute/Unmute)
```
