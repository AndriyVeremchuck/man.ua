# 📖 iw(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `iw`  
> **Оригінальний виклик**: `man 1 iw`

---

## 🎯 НАЗВА (NAME)
**`iw`** — Сучасна стандартна утиліта ядра Linux для конфігурації та діагностики бездротових пристроїв Wi-Fi на базі підсистеми nl80211.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
iw [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`dev (список Wi-Fi інтерфейсів), scan (сканування ефіру), link (статус поточного з'єднання), info (характеристики адаптера)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `iw` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 iw` або аліас `uman iw`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ iw dev  # Перегляд активних бездротових інтерфейсів та номерів каналів
$ sudo iw dev wlan0 scan | grep SSID  # Сканування ефіру на наявність Wi-Fi точок доступу
```
