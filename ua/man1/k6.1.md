# 📖 k6(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `k6`  
> **Оригінальний виклик**: `man 1 k6`

---

## 🎯 НАЗВА (NAME)
**`k6`** — Сучасний інструмент тестування навантаження та продуктивності API від Grafana Labs із написанням сценаріїв на JavaScript.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
k6 [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`run <скрипт.js>, --vus <кількість_користувачів>, --duration <тривалість: 30s, 5m>, --out <influxdb/csv>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `k6` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 k6` або аліас `uman k6`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ k6 run --vus 50 --duration 30s load_test.js  # Імітація 50 одночасних користувачів протягом 30 секунд
$ k6 run script.js  # Виконання сценарію тестування продуктивності API
```
