# 📖 dvips(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `texlive-core`  
> **Оригінальний виклик**: `man 1 dvips`

---

## 🎯 НАЗВА (NAME)
**`dvips`** — Перетворення незалежних від пристроїв файлів виводу TeX DVI (.dvi) у високоякісний поліграфічний PostScript.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
dvips [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-o <вихідний.ps>, -t <формат_паперу: a4/letter>, -P<профіль_принтера>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `dvips` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 dvips` або аліас `uman dvips`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ dvips -t a4 document.dvi -o document.ps  # Конвертація DVI файлу TeX у формат PostScript формату A4
$ dvips -Ppdf math_paper.dvi  # Створення PostScript, оптимізованого для подальшого створення PDF
```
