# 📖 type(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `shell builtin`  
> **Оригінальний виклик**: `man 1 type`

---

## 🎯 НАЗВА (NAME)
**`type`** — Визначення типу команди (чи є вона вбудованою функцією, аліасом або бінарним виконуваним файлом).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
type [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-a (показати всі можливі розташування та типи), -t (лише тип: builtin, alias, file)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `type` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 type` або аліас `uman type`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ type -a fish git ls  # Визначити типи команд та шляхи до них
```
