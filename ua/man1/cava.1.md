# 📖 cava(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `cava`  
> **Оригінальний виклик**: `man 1 cava`

---

## 🎯 НАЗВА (NAME)
**`cava`** — Консольний аудіовізуалізатор спектра звуку (Console-based Audio Visualizer for ALSA/PipeWire/PulseAudio) з плавною анімацією стовпчиків.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
cava [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-p <шлях_до_конфігу>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `cava` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 cava` або аліас `uman cava`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ cava  # Запуск спектрального аудіовізуалізатора під музику
$ cava -p ~/.config/cava/config  # Запуск із персональною колірною схемою
```
