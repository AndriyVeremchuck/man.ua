# 📖 lzma(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `xz`  
> **Оригінальний виклик**: `man 1 lzma`

---

## 🎯 НАЗВА (NAME)
**`lzma`** — Класичний алгоритм стиснення Lempel-Ziv-Markov chain (.lzma).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
lzma [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-k (зберегти), -d (декомпресія), -9`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `lzma` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 lzma` або аліас `uman lzma`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ lzma -k file.txt  # Стиснути файл алгоритмом LZMA
```
