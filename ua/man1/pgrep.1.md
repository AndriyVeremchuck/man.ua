# 📖 pgrep(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `procps-ng`  
> **Оригінальний виклик**: `man 1 pgrep`

---

## 🎯 НАЗВА (NAME)
**`pgrep`** — Швидкий пошук ідентифікаторів процесів (PID) на основі їхнього імені або шаблону регулярного виразу.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pgrep [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-l (виводити ім'я разом з PID), -a (повний командний рядок), -u <користувач>, -f (шукати у всіх аргументах)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pgrep` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pgrep` або аліас `uman pgrep`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ pgrep -l -u dusha  # Список усіх PID та назв процесів поточного користувача
$ pgrep -fa "python3 apps-catalog.py"  # Пошук PID конкретного запущеного скрипту
```
