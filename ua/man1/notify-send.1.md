# 📖 notify-send(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `libnotify`  
> **Оригінальний виклик**: `man 1 notify-send`

---

## 🎯 НАЗВА (NAME)
**`notify-send`** — Надсилання нативних спливаючих сповіщень на робочий стіл через протокол Desktop Notifications Specification (libnotify / KDE Plasma).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
notify-send [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-u <low/normal/critical> (важливість), -i <іконка>, -t <мс> (тривалість), -a <додаток>, -c <категорія>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `notify-send` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 notify-send` або аліас `uman notify-send`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ notify-send -u normal -i dialog-information "Збірка завершена" "Всі тести пройдено успішно!"  # Показ системного сповіщення на стільниці
$ notify-send -u critical -i dialog-warning "Увага" "Резервне копіювання потребує уваги"  # Надсилання критичного попередження
```
