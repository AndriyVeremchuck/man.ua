# 📖 paccache(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `pacman-contrib`  
> **Оригінальний виклик**: `man 1 paccache`

---

## 🎯 НАЗВА (NAME)
**`paccache`** — Утиліта очищення застарілого кешу пакунків Pacman для звільнення десятків гігабайтів на диску.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
paccache [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-r (залишити 3 останні версії), -rk1 (залишити лише 1), -ruk0 (видалити кеш видалених програм), -d (тестовий прогін dry-run)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `paccache` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 paccache` або аліас `uman paccache`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo paccache -r  # Безпечне очищення старого кешу з залишенням 3 резервних версій
$ sudo paccache -ruk0  # Повне видалення кешу програм, які більше не встановлені в системі
```
