# 📖 base64(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 base64`

---

## 🎯 НАЗВА (NAME)
**`base64`** — Кодування та декодування файлів або стандартного вводу за алгоритмом Base64 (RFC 4648) для безпечної передачі бінарних даних у тексті.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
base64 [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-d / --decode (декодування даних), -w <N> (перенос рядків після N символів, 0=без переносу), -i (ігнорувати невалідні символи)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `base64` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 base64` або аліас `uman base64`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ base64 -w 0 image.png > image.b64  # Кодування зображення в один суцільний рядок Base64 (Data URI)
$ base64 -d auth_token.b64  # Декодування рядка Base64 у початковий бінарний/текстовий формат
```
