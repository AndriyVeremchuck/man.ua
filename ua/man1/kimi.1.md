# 📖 kimi(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `@moonshot-ai/kimi-code (NPM Global)`  
> **Оригінальний виклик**: `man 1 kimi`

---

## 🎯 НАЗВА (NAME)
**`kimi`** — Консольний агент розробки від Moonshot AI з підтримкою величезного контексту та глибокого аналізу великих репозиторіїв.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
kimi [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--chat, --workspace <каталог>, --model <kimi-k1.5>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `kimi` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 kimi` або аліас `uman kimi`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ kimi  # Запуск інтерактивного термінального чату Kimi Code
```
