# 📖 ffplay(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `ffmpeg`  
> **Оригінальний виклик**: `man 1 ffplay`

---

## 🎯 НАЗВА (NAME)
**`ffplay`** — Компактний та швидкий медіаплеєр на базі бібліотек FFmpeg та рушія SDL для тестування кодеків, потоків та аудіо/відео фільтрів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ffplay [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-nodisp (лише звук без вікна), -autoexit (вихід після завершення), -vf <фільтр> (відеофільтри), -loop <N>, -ss <час>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ffplay` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ffplay` або аліас `uman ffplay`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ffplay -nodisp -autoexit sound.wav  # Швидке програвання звукового файлу без відкриття вікна
$ ffplay -vf "eq=brightness=0.1:contrast=1.3" video.mp4  # Відтворення відео з корекцією яскравості та контрасту на льоту
```
