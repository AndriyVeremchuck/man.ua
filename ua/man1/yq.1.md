# 📖 yq(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `yq`  
> **Оригінальний виклик**: `man 1 yq`

---

## 🎯 НАЗВА (NAME)
**`yq`** — Потужний портативний процесор структурованих даних для фільтрації, редагування та взаємної конвертації між YAML, JSON, XML та CSV.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
yq [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-o=json (конвертація в JSON), -p=yaml (парсер YAML), -i (редагування файлу на місці), -P (гарне форматування pretty print)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `yq` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 yq` або аліас `uman yq`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ yq '.database.host' config.yaml  # Видобування значення поля хоста з файлу конфігурації YAML
$ yq -o=json config.yaml > config.json  # Миттєве перетворення структури YAML у валідний JSON
```
