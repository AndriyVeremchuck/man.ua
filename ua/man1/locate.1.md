# 📖 locate(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `mlocate / plocate`  
> **Оригінальний виклик**: `man 1 locate`

---

## 🎯 НАЗВА (NAME)
**`locate`** — Блискавичний пошук файлів за проіндексованою системною базою даних mlocate.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
locate [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-i (ігнорувати регістр), -c (лише кількість), -r (регулярний вираз)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `locate` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 locate` або аліас `uman locate`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ locate -i config.fish  # Миттєво знайти розташування конфігураційного файлу
$ locate -c *.png  # Підрахувати кількість знайдених PNG зображень у системі
```
