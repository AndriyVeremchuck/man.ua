# 📖 nnn(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `nnn`  
> **Оригінальний виклик**: `man 1 nnn`

---

## 🎯 НАЗВА (NAME)
**`nnn`** — Ультралегкий, швидкий та ресурсноефективний термінальний файловий менеджер із підтримкою вкладок, пошуку та плагінів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
nnn [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-e (відкривати текстові файли в редакторі), -H (показувати приховані файли), -d (детальний режим)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `nnn` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 nnn` або аліас `uman nnn`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ nnn -e -H  # Запуск швидкого файлового навігатора з відображенням прихованих файлів
$ nnn -d  # Запуск у детальному режимі з розмірами файлів та правами
```
