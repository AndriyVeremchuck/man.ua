# 📖 bash(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Оригінальний виклик**: `man 1 bash`

---

## 🎯 НАЗВА (NAME)
**`bash`** — Командний інтерпретатор та мова сценаріїв GNU Bourne Again Shell

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
bash [OPTIONS] [FILE [ARGUMENTS...]]
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `bash` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 bash` або аліас `uman bash`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ bash script.sh
$ bash -x debug_script.sh
```
