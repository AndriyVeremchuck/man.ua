# 📖 ln(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 ln`

---

## 🎯 НАЗВА (NAME)
**`ln`** — Створення жорстких (hard link) та символьних (ln -s) посилань на файли та директорії.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ln [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-s (символьне посилання), -f (перезаписати існуюче), -v (детально)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ln` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ln` або аліас `uman ln`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ln -s /opt/my_app/bin/app ~/.local/bin/my_app  # Створити символьне посилання на програму в $PATH
$ ln file.txt hardlink.txt  # Створити жорстке посилання на файл
```
