# 📖 sudo(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `sudo`  
> **Оригінальний виклик**: `man 1 sudo`

---

## 🎯 НАЗВА (NAME)
**`sudo`** — Виконання адміністративних команд від імені суперкористувача (root) або іншого користувача.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
sudo [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-i (інтерактивна root оболонка), -u <користувач>, -E (зберегти змінні оточення), -l (список привілеїв)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `sudo` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 sudo` або аліас `uman sudo`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo -i  # Вхід в інтерактивну оболонку root
$ sudo -l  # Перевірити дозволені команди для поточного користувача
```
