# 📖 arecord(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `alsa-utils`  
> **Оригінальний виклик**: `man 1 arecord`

---

## 🎯 НАЗВА (NAME)
**`arecord`** — Консольна утиліта запису аудіо з мікрофона у нестиснений формат WAV через низькорівневий інтерфейс ядра ALSA.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
arecord [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-l (список пристроїв захоплення), -f <формат: cd, dat, S16_LE>, -d <тривалість_у_сек>, -r <частота>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `arecord` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 arecord` або аліас `uman arecord`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ arecord -l  # Список доступних мікрофонів та пристроїв запису
$ arecord -f cd -d 5 test_mic.wav  # Запис 5 секунд аудіо в CD-якості (44.1kHz 16bit stereo)
```
