# 📖 mpstat(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `sysstat`  
> **Оригінальний виклик**: `man 1 mpstat`

---

## 🎯 НАЗВА (NAME)
**`mpstat`** — Моніторинг продуктивності та навантаження кожного окремого процесорного ядра (Core/Thread) у багатоядерних процесорах.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
mpstat [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-P ALL (статистика по кожному окремому ядру), -u (завантаження CPU), <інтервал> <кількість>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `mpstat` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 mpstat` або аліас `uman mpstat`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ mpstat -P ALL 1 3  # Перегляд розподілу навантаження по всіх ядрах CPU щосекунди
$ mpstat 1  # Безперервний моніторинг сумарного завантаження CPU
```
