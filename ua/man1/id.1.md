# 📖 id(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 id`

---

## 🎯 НАЗВА (NAME)
**`id`** — Відображення цифрових ідентифікаторів UID, GID та повного переліку груп користувача.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
id [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-u (лише UID), -g (лише основний GID), -G (усі додаткові групи), -un (ім'я користувача)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `id` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 id` або аліас `uman id`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ id  # Показати UID, GID та всі активні групи поточного користувача
```
