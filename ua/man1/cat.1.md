# 📖 cat(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 cat`

---

## 🎯 НАЗВА (NAME)
**`cat`** — Виведення та послідовне об'єднання вмісту файлів у стандартний потік виводу.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
cat [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-n (номери всіх рядків), -b (номери непорожніх рядків), -A (показати всі спецсимволи та кінці рядків)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `cat` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 cat` або аліас `uman cat`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ cat /etc/os-release  # Вивести вміст інформаційного файлу ОС
$ cat -n script.sh  # Вивести код із нумерацією рядків
```
