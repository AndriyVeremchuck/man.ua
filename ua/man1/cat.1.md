# 📖 cat(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Оригінальний виклик**: `man 1 cat`

---

## 🎯 НАЗВА (NAME)
**`cat`** — Об'єднання та виведення вмісту файлів у стандартний потік виводу

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
cat [OPTIONS] [FILE...]
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `cat` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 cat` або аліас `uman cat`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ cat /etc/os-release
$ cat -n script.sh
```
