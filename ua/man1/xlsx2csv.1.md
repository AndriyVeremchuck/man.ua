# 📖 xlsx2csv(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `xlsx2csv`  
> **Оригінальний виклик**: `man 1 xlsx2csv`

---

## 🎯 НАЗВА (NAME)
**`xlsx2csv`** — Швидке перетворення сучасних таблиць Excel (.xlsx) у формат CSV з можливістю вибору окремого аркуша або експорту всіх сторінок.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
xlsx2csv [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-a / --all (експортувати всі аркуші), -s <номер_або_назва_аркуша>, -d <роздільник>, -i (ігнорувати порожні рядки)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `xlsx2csv` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 xlsx2csv` або аліас `uman xlsx2csv`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ xlsx2csv workbook.xlsx sheet1.csv  # Експорт першого аркуша таблиці Excel XLSX у формат CSV
$ xlsx2csv -a workbook.xlsx ./sheets_folder/  # Пакетний експорт усіх аркушів книги у окремі CSV файли
```
