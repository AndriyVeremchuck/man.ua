# 📖 pnpm(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `pnpm`  
> **Оригінальний виклик**: `man 1 pnpm`

---

## 🎯 НАЗВА (NAME)
**`pnpm`** — Швидкий та високоефективний менеджер пакетів для JavaScript, що використовує жорсткі посилання (hard links) для збереження дискового простору.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pnpm [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`install / i, add <пакет>, run <скрипт>, update, audit`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pnpm` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pnpm` або аліас `uman pnpm`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ pnpm install  # Ультрашвидке встановлення залежностей без дублювання файлів node_modules на диску
$ pnpm dev  # Запуск режиму розробки проєкту
```
