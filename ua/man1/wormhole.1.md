# 📖 wormhole(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `magic-wormhole`  
> **Оригінальний виклик**: `man 1 wormhole`

---

## 🎯 НАЗВА (NAME)
**`wormhole`** — Безпечна передача файлів та тексту від людини до людини через захищений P2P тунель за коротким одноразовим кодом.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
wormhole [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`send <файл>, receive <код>, --text "<повідомлення>"`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `wormhole` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 wormhole` або аліас `uman wormhole`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ wormhole send archive.tar.zst  # Безпечна передача архіву за захищеним кодом
$ wormhole receive 4-purple-crystal  # Отримання даних за кодом вормхолу
```
