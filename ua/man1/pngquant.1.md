## 🎯 НАЗВА (NAME)
**`pngquant`** — Командна утиліта для зменшення розміру зображень PNG на 60-80% шляхом квантування у 8-бітну RGBA палітру зі збереженням альфа-прозорості.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pngquant [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--quality=<min-max> (наприклад 65-80), --speed=<1-11>, --ext <розширення>, --force (перезапис)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pngquant` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pngquant` або аліас `uman pngquant`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ pngquant --quality=65-80 --ext .png --force icon.png  # Ефективне стиснення PNG зі збереженням плавної напівпрозорості
$ pngquant 256 photo.png  # Квантування кольорів у палітру з 256 відтінків
```
