# 📖 wget(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `wget`  
> **Оригінальний виклик**: `man 1 wget`

---

## 🎯 НАЗВА (NAME)
**`wget`** — Неінтерактивний завантажувач файлів з мережі з можливістю докачування та рекурсивного викачування сайтів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
wget [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-c (докачати перерваний файл), -r (рекурсивно), -np (не підніматися вище), -b (фоновий режим)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `wget` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 wget` або аліас `uman wget`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ wget -c https://example.com/huge.iso  # Докачати перерване завантаження великого ISO-файлу
```
