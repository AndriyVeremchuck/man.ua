# 📖 shred(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 shred`

---

## 🎯 НАЗВА (NAME)
**`shred`** — Безпечне та незворотне знищення вмісту файлів багаторазовим перезаписом псевдовипадковими послідовностями.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
shred [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-u (видалити файл після затирання), -z (фінальний перезапис нулями для маскування), -n <кількість_проходів>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `shred` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 shred` або аліас `uman shred`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ shred -u -z -n 3 private_key.pem  # Гарантоване знищення приватного ключа без можливості відновлення
```
