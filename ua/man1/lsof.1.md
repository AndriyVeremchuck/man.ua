# 📖 lsof(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `lsof`  
> **Оригінальний виклик**: `man 1 lsof`

---

## 🎯 НАЗВА (NAME)
**`lsof`** — List Open Files — виведення інформації про всі відкриті файли, мережеві сокети, канали пайпів та пристрої, що використовуються процесами в системі.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
lsof [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-i :<порт> (пошук за мережевим портом), -p <PID> (всі файли процесу), -u <user> (файли користувача), +D <каталог> (хто використовує папку)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `lsof` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 lsof` або аліас `uman lsof`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo lsof -i :8080  # Пошук процесу, який зайняв мережевий порт 8080
$ sudo lsof +D /media/usb  # Пошук процесів, які блокують відмонтування USB-диска
```
