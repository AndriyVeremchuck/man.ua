# 📖 cachyos-kernel-manager(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `cachyos-kernel-manager`  
> **Оригінальний виклик**: `man 1 cachyos-kernel-manager`

---

## 🎯 НАЗВА (NAME)
**`cachyos-kernel-manager`** — Керування, встановлення та конфігурація оптимізованих ядер CachyOS (BORE, LTO, RT, EEVDF).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
cachyos-kernel-manager [OPTIONS] [ARGUMENTS...]
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `cachyos-kernel-manager` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 cachyos-kernel-manager` або аліас `uman cachyos-kernel-manager`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ cachyos-kernel-manager  # Запуск менеджера високопродуктивних ядер Linux
```
