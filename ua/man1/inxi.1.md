# 📖 inxi(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `inxi`  
> **Оригінальний виклик**: `man 1 inxi`

---

## 🎯 НАЗВА (NAME)
**`inxi`** — Вичерпний звіт про апаратне забезпечення станції: процесор, GPU NVIDIA RTX 3060, оперативну пам'ять, диски, звук, ядро CachyOS та драйвери.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
inxi [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-Fz (повний звіт без приватних даних), -G (відеокарта), -C (процесор), -D (накопичувачі), -m (пам'ять)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `inxi` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 inxi` або аліас `uman inxi`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ inxi -Fz  # Вивести детальний структурований звіт про всю робочу станцію
$ inxi -G  # Показати статус відеокарти NVIDIA, версію драйвера та Vulkan
```
