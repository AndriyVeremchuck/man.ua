# 📖 borg(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `borg`  
> **Оригінальний виклик**: `man 1 borg`

---

## 🎯 НАЗВА (NAME)
**`borg`** — BorgBackup — дедуплікований архіватор та бекап-сервіс із криптографічною автентифікацією, компресією zstd та інкрементним оновленням.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
borg [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`create <репо::знімок> <шляхи>, list <репо>, extract <репо::знімок>, info <репо::знімок>, prune (видалення старих)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `borg` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 borg` або аліас `uman borg`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ borg create --progress --compression zstd /backup::"{now}" ~/Документи  # Створення стисненого бекапу документів
$ borg list /backup  # Перегляд списку архівів у сховищі Borg
```
