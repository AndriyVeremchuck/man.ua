# 📖 typst(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `typst`  
> **Оригінальний виклик**: `man 1 typst`

---

## 🎯 НАЗВА (NAME)
**`typst`** — Сучасна, легка та блискавична альтернатива LaTeX на мові Rust для верстки наукових статей, книг, звітів та презентацій у PDF.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
typst [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`compile <файл.typ> [вихід.pdf], watch <файл.typ> (автооновлення PDF), fonts (список шрифтів)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `typst` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 typst` або аліас `uman typst`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ typst compile document.typ report.pdf  # Миттєва компіляція документа у високоякісний векторний PDF
$ typst watch document.typ  # Автоматична регенерація PDF на льоту при кожному збереженні
```
