# 📖 mv(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 mv`

---

## 🎯 НАЗВА (NAME)
**`mv`** — Переміщення та перейменування файлів і каталогів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
mv [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-v (детально), -i (запит підтвердження перезапису), -n (не перезаписувати)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `mv` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 mv` або аліас `uman mv`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ mv old_name.txt new_name.txt  # Перейменувати файл
$ mv *.log /var/log/archive/  # Перемістити всі логи в архівний каталог
```
