# 📖 comm(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 comm`

---

## 🎯 НАЗВА (NAME)
**`comm`** — Порядкове порівняння двох відсортованих файлів з розділенням на три колонки: унікальні рядки 1-го файлу, 2-го файлу та спільні рядки.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
comm [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-1 (приховати унікальні для 1-го файлу), -2 (приховати унікальні для 2-го файлу), -3 (приховати спільні рядки), --check-order`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `comm` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 comm` або аліас `uman comm`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ comm -12 <(sort list_a.txt) <(sort list_b.txt)  # Виведення тільки спільних рядків, присутніх в обох списках
$ comm -23 <(sort all_packages.txt) <(sort installed.txt)  # Пошук пакетів, які ще не встановлені в системі
```
