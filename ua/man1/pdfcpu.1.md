# 📖 pdfcpu(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `pdfcpu`  
> **Оригінальний виклик**: `man 1 pdfcpu`

---

## 🎯 НАЗВА (NAME)
**`pdfcpu`** — Сучасний швидкий PDF процесор на Go: сувора валідація стандарту ISO 32000-1, додавання водяних знаків, нарізка буклетів та оптимізація.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pdfcpu [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`validate (перевірка стандарту), watermark add (водяний знак), stamp add (штамп), nup (розміщення на аркуші), trim`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pdfcpu` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pdfcpu` або аліас `uman pdfcpu`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ pdfcpu validate document.pdf  # Сувора перевірка відповідності файлу офіційній специфікації PDF
$ pdfcpu watermark add -m text -- "КОНФІДЕНЦІЙНО" "font:Helvetica, scale:0.7, rot:45, op:0.3" in.pdf out.pdf  # Накладання напівпрозорого водяного знака на сторінки PDF
```
