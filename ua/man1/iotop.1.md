# 📖 iotop(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `iotop`  
> **Оригінальний виклик**: `man 1 iotop`

---

## 🎯 НАЗВА (NAME)
**`iotop`** — TUI-монітор у реальному часі для виявлення процесів і потоків, які створюють найбільше навантаження на підсистему дискового вводу-виводу (I/O).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
iotop [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-o / --only (показувати тільки процеси, які реально пишуть/читають), -b (пакетний режим), -d <сек>, -p <PID>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `iotop` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 iotop` або аліас `uman iotop`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo iotop -o  # Відображення виключно тих процесів, що активно навантажують диск прямо зараз
$ sudo iotop -a  # Накопичувальний підрахунок зчитаних та записаних гігабайт кожним процесом
```
