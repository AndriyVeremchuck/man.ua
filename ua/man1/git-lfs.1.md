# 📖 git-lfs(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `git-lfs`  
> **Оригінальний виклик**: `man 1 git-lfs`

---

## 🎯 НАЗВА (NAME)
**`git-lfs`** — Git Large File Storage — розширення Git для ефективного версіонування важких бінарних файлів (моделі ШІ, 3D-ассети, відео, архіви).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
git-lfs [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`install (ініціалізація в системі), track "<маска>" (відстеження файлів), ls-files (список LFS файлів), pull (завантаження LFS даних)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `git-lfs` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 git-lfs` або аліас `uman git-lfs`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ git lfs track "*.psd *.blend *.tar.zst"  # Додавання масок великих файлів під керування Git LFS
$ git lfs pull  # Завантаження реального вмісту LFS-файлів для поточної гілки
```
