# 📖 glxinfo(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `mesa-utils`  
> **Оригінальний виклик**: `man 1 glxinfo`

---

## 🎯 НАЗВА (NAME)
**`glxinfo`** — Діагностична утиліта для перевірки статусу прямого рендерингу (Direct Rendering), версій OpenGL, драйверів Mesa/NVIDIA та підтримуваних розширень GLX.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
glxinfo [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-B (коротка вибірка: GPU, драйвер, версія OpenGL), -l (список підтримуваних розширень OpenGL)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `glxinfo` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 glxinfo` або аліас `uman glxinfo`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ glxinfo -B  # Швидка перевірка активної відеокарти, драйвера та версії OpenGL/GLSL
$ glxinfo | grep -i "direct rendering"  # Перевірка апаратного 3D-прискорення (Direct Rendering: Yes)
```
