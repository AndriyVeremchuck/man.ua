# 📖 wg(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `wireguard-tools`  
> **Оригінальний виклик**: `man 1 wg`

---

## 🎯 НАЗВА (NAME)
**`wg`** — Офіційна утиліта керування та діагностики сучасного надшвидкого криптографічного протоколу VPN WireGuard у ядрі Linux.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
wg [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`show (поточні з'єднання та трафік), genkey (генерація приватного ключа), pubkey (отримання публічного ключа), set <інтерфейс>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `wg` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 wg` або аліас `uman wg`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo wg show  # Перегляд активних WireGuard тунелів, пірів, переданого трафіку та handshake
$ wg genkey | tee privatekey | wg pubkey > publickey  # Швидка генерація пари ключів WireGuard
```
