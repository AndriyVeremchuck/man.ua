## 🎯 НАЗВА (NAME)
**`mkfs.btrfs`** — Створення сучасної файлової системи Btrfs із підтримкою Copy-on-Write (CoW), снапшотів, прозорого стиснення zstd та вбудованого RAID.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
mkfs.btrfs [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-L <мітка>, -d <raid0/raid1/single> (профіль даних), -m <raid0/raid1/single> (метадані), -f (примусово)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `mkfs.btrfs` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 mkfs.btrfs` або аліас `uman mkfs.btrfs`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo mkfs.btrfs -L "CachyRoot" /dev/nvme0n1p2  # Створення файлової системи Btrfs для кореневого розділу CachyOS
$ sudo mkfs.btrfs -m raid1 -d raid0 /dev/sdb /dev/sdc  # Створення пулу Btrfs на двох дисках із дзеркалом метаданих
```
