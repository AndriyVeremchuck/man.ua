# 📖 mpv(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `mpv`  
> **Оригінальний виклик**: `man 1 mpv`

---

## 🎯 НАЗВА (NAME)
**`mpv`** — Легкий та потужний медіаплеєр для консолі, скриптів, швидкого виводу веб-камер без затримок та потоків YouTube.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
mpv [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--hwdec=auto (апаратне прискорення), --vo=gpu, --no-video (лише звук), --profile=low-latency`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `mpv` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 mpv` або аліас `uman mpv`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ mpv av://v4l2:/dev/video0 --profile=low-latency --untimed  # Миттєвий вивід зображення з вебкамери без затримок
$ mpv --no-video audio.mp3  # Відтворення аудіо виключно у консолі
```
