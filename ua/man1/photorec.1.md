# 📖 photorec(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `testdisk`  
> **Оригінальний виклик**: `man 1 photorec`

---

## 🎯 НАЗВА (NAME)
**`photorec`** — Утиліта поглибленого відновлення видалених файлів (фотографії, відео, документи, архіви) за їхніми сигнатурами (File Carving) навіть із відформатованих дисків.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
photorec [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`/d <папка_збереження>, /cmd <пристрій> <опція>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `photorec` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 photorec` або аліас `uman photorec`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo photorec  # Запуск інтерактивного майстра пошуку та відновлення видалених файлів
$ sudo photorec /dev/sdb1  # Сканування та вилучення видалених фотографій із карти пам'яті
```
