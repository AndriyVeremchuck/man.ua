# 📖 weasyprint(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `weasyprint`  
> **Оригінальний виклик**: `man 1 weasyprint`

---

## 🎯 НАЗВА (NAME)
**`weasyprint`** — Візуальний видавничий рушій для бездоганного створення PDF документів із веб-сторінок HTML5, шаблонів та таблиць стилів CSS3.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
weasyprint [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-s <файл.css>, --presentational-hints, <вхідний.html> <вихідний.pdf>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `weasyprint` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 weasyprint` або аліас `uman weasyprint`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ weasyprint report.html final_report.pdf  # Рендеринг красивого звіту з HTML/CSS у поліграфічний PDF
$ weasyprint -s custom_print.css template.html output.pdf  # Генерація документа із застосуванням спеціального CSS для друку
```
