# 📖 ninja(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `ninja`  
> **Оригінальний виклик**: `man 1 ninja`

---

## 🎯 НАЗВА (NAME)
**`ninja`** — Високооптимізована система складання коду, створена спеціально для максимальної швидкості паралельної компіляції великих проєктів (LLVM, Chromium).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ninja [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-C <директорія>, -j <потоки>, -v (докладні команди компілятора)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ninja` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ninja` або аліас `uman ninja`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ninja -C build  # Швидка збірка проєкту в папці build
$ ninja -C build clean  # Очищення артефактів збірки
```
