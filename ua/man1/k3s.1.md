# 📖 k3s(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `k3s-bin`  
> **Оригінальний виклик**: `man 1 k3s`

---

## 🎯 НАЗВА (NAME)
**`k3s`** — Легковаговий, оптимізований та сертифікований дистрибутив Kubernetes від Rancher, що споживає менше 512 МБ пам'яті.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
k3s [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`server (запуск майстер-ноди), agent (підключення робочої ноди), kubectl <команда>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `k3s` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 k3s` або аліас `uman k3s`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo k3s server &  # Запуск легкого повнофункціонального кластера Kubernetes у фоні
$ sudo k3s kubectl get nodes  # Перегляд активних нод кластера K3s
```
