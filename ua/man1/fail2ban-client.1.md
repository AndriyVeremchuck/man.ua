## 🎯 НАЗВА (NAME)
**`fail2ban-client`** — Командний інтерфейс керування сервісом Fail2ban, що аналізує системні логи та автоматично блокує IP-адреси зловмисників у файрволі.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
fail2ban-client [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`status (загальний статус), status <jail> (статус ізолятора, наприклад sshd), set <jail> unbanip <IP>, reload`

---

Посібник `fail2ban-client` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo fail2ban-client status  # Перегляд активних захисних ізоляторів (jails)
$ sudo fail2ban-client status sshd  # Список заблокованих IP-адрес для служби SSH
```
