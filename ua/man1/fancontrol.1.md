# 📖 fancontrol(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `lm_sensors`  
> **Оригінальний виклик**: `man 1 fancontrol`

---

## 🎯 НАЗВА (NAME)
**`fancontrol`** — Системний сервіс та демон для автоматичного динамічного регулювання швидкості обертання кулерів (PWM) на основі датчиків температури.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
fancontrol [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`<шлях_до_конфігурації: /etc/fancontrol>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `fancontrol` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 fancontrol` або аліас `uman fancontrol`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo pwmconfig  # Інтерактивний майстер калібрування швидкості вентиляторів та створення конфігурації
$ sudo systemctl status fancontrol  # Перевірка статусу демона автоматичного охолодження
```
