# 📖 ufw(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `ufw`  
> **Оригінальний виклик**: `man 1 ufw`

---

## 🎯 НАЗВА (NAME)
**`ufw`** — Зручний міжмережевий екран (Uncomplicated Firewall) для контролю мережевих правил та портів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ufw [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`status verbose, enable/disable, allow <порт/протокол>, deny <порт>, delete <номер>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ufw` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ufw` або аліас `uman ufw`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo ufw status verbose  # Показати статус файрвола та активні правила
$ sudo ufw allow 22/tcp  # Дозволити вхідний SSH трафік
```
