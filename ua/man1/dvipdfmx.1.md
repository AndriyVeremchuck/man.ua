# 📖 dvipdfmx(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `texlive-core`  
> **Оригінальний виклик**: `man 1 dvipdfmx`

---

## 🎯 НАЗВА (NAME)
**`dvipdfmx`** — Прямий драйвер та компілятор файлів DVI та XDV у PDF із підтримкою сучасних шрифтів OpenType/TrueType, кольору та гіперпосилань.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
dvipdfmx [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-o <вихідний.pdf>, -p <розмір_паперу>, -V <версія_pdf: 1.4-1.7>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `dvipdfmx` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 dvipdfmx` або аліас `uman dvipdfmx`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ dvipdfmx -p a4 article.dvi  # Пряма високошвидкісна компіляція DVI у PDF документ A4
$ dvipdfmx -o book.pdf book.xdv  # Трансляція XeTeX XDV файлу у фінальний PDF
```
