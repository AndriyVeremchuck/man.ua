# 📖 mongosh(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `mongodb-sh`  
> **Оригінальний виклик**: `man 1 mongosh`

---

## 🎯 НАЗВА (NAME)
**`mongosh`** — Офіційна сучасна інтерактивна командна оболонка MongoDB Shell для керування документами, агрегаціями та індексами NoSQL.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
mongosh [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`<URI_підключення>, --eval "<код_JS>", --quiet`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `mongosh` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 mongosh` або аліас `uman mongosh`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ mongosh "mongodb://localhost:27017/my_db"  # Підключення до бази даних MongoDB
$ mongosh --eval "db.users.countDocuments()"  # Швидкий підрахунок документів у колекції
```
