# 📖 genfstab(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `arch-install-scripts`  
> **Оригінальний виклик**: `man 1 genfstab`

---

## 🎯 НАЗВА (NAME)
**`genfstab`** — Автоматична генерація записів /etc/fstab на основі поточної конфігурації змонтованих дисків та розділів із використанням стійких UUID.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
genfstab [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-U (використовувати UUID дисків), -L (використовувати мітки дисків), -p (не виводити псевдо-файлові системи)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `genfstab` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 genfstab` або аліас `uman genfstab`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ genfstab -U /mnt  # Перегляд згенерованої таблиці fstab для змонтованої системи
$ genfstab -U /mnt | sudo tee -a /mnt/etc/fstab  # Запис згенерованого fstab у конфігурацію нової системи
```
