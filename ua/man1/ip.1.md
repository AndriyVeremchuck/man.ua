# 📖 ip(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `iproute2`  
> **Оригінальний виклик**: `man 1 ip`

---

## 🎯 НАЗВА (NAME)
**`ip`** — Сучасний інструмент керування мережевими адаптерами, IP-адресами, маршрутами та ARP-сусідством.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ip [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`a/addr (адреси), r/route (маршрути), link (інтерфейси), neigh (ARP таблиця), -br (компактний формат)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ip` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ip` або аліас `uman ip`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ip -br a  # Компактний список активних мережевих інтерфейсів та їхніх IP-адрес
$ ip route show  # Переглянути таблицю маршрутизації та основний шлюз
```
