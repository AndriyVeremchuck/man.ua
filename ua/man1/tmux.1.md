# 📖 tmux(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `tmux`  
> **Оригінальний виклик**: `man 1 tmux`

---

## 🎯 НАЗВА (NAME)
**`tmux`** — Термінальний мультиплексор для розділення вікон на панелі та збереження сесій у фоні.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
tmux [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`new -s <сесія>, attach -t <сесія>, ls (список), kill-session -t <сесія>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `tmux` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 tmux` або аліас `uman tmux`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ tmux new -s main_work  # Створити нову сесію tmux для довготривалої роботи
$ tmux attach -t main_work  # Підключитися до активної сесії tmux
```
