# 📖 inlyne(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `inlyne`  
> **Оригінальний виклик**: `man 1 inlyne`

---

## 🎯 НАЗВА (NAME)
**`inlyne`** — GPU-прискорений автономний переглядач Markdown файлів на Rust із підтримкою темної теми, формул LaTeX та миттєвого рендерингу.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
inlyne [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--theme <dark/light>, --page-width <px>, <файл.md>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `inlyne` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 inlyne` або аліас `uman inlyne`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ inlyne README.md  # Швидке відкриття Markdown у плавному вікні з апаратним прискоренням
$ inlyne --theme dark notes.md  # Перегляд конспектів у темній темі
```
