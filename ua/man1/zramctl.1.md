# 📖 zramctl(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `util-linux`  
> **Оригінальний виклик**: `man 1 zramctl`

---

## 🎯 НАЗВА (NAME)
**`zramctl`** — Перегляд статусу, об'єму, зайнятого простору та коефіцієнта компресії дисків динамічного Swap у RAM (ZRAM).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
zramctl [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-s (підсумковий статус), --output-all (всі колонки), --raw`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `zramctl` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 zramctl` або аліас `uman zramctl`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ zramctl  # Показати статус пристрою /dev/zram0, алгоритм zstd та ступінь стиснення
```
