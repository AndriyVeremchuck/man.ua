# 📖 traceroute(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `traceroute`  
> **Оригінальний виклик**: `man 1 traceroute`

---

## 🎯 НАЗВА (NAME)
**`traceroute`** — Трасування маршруту проходження мережевих пакетів від локального комп'ютера до цільового хоста з вимірюванням затримок кожного вузла.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
traceroute [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-n (числові IP-адреси без DNS), -I (використовувати ICMP ECHO замість UDP), -T (використовувати TCP SYN пакети), -p <порт> (цільовий порт), -m <макс_хопів>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `traceroute` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 traceroute` або аліас `uman traceroute`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ traceroute -n 1.1.1.1  # Трасування мережевих стрибків до DNS Cloudflare без DNS резолвінгу
$ traceroute -T -p 443 google.com  # TCP-трасування маршруту через HTTPS порт для обходу обмежень ICMP
```
