# 📖 cd(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `shell builtin`  
> **Оригінальний виклик**: `man 1 cd`

---

## 🎯 НАЗВА (NAME)
**`cd`** — Зміна поточного робочого каталогу в командній оболонці.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
cd [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`cd - (повернутися назад), cd ~ (домашній каталог), cd .. (рівень вгору)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `cd` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 cd` або аліас `uman cd`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ cd ..  # Піднятися на один каталог вгору
$ cd -  # Повернутися до попередньої папки
```
