# 📖 cp(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 cp`

---

## 🎯 НАЗВА (NAME)
**`cp`** — Копіювання файлів і директорій у файловій системі зі збереженням прав та атрибутів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
cp [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-r (рекурсивно), -u (тільки якщо джерело новіше), -v (детально), -p (зберегти права), -i (запит)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `cp` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 cp` або аліас `uman cp`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ cp -rv ./src/ ./backup_src/  # Рекурсивне копіювання каталогу з виведенням імен файлів
$ cp -u file.txt /backup/  # Копіювати файл лише у разі наявності змін
```
