# 📖 lscpu(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `util-linux`  
> **Оригінальний виклик**: `man 1 lscpu`

---

## 🎯 НАЗВА (NAME)
**`lscpu`** — Збір та форматоване виведення повної апаратної інформації про центральний процесор: архітектура, ядра, потоки, сокети, кеші L1/L2/L3, прапорці інструкцій.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
lscpu [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-e (розширена таблиця по кожному логічному ядру), -p (вивід для парсингу скриптами), -C (деталі про кеш CPU), -J (вивід у форматі JSON)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `lscpu` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 lscpu` або аліас `uman lscpu`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ lscpu  # Повний огляд моделі процесора, частотних меж та підтримуваних інструкцій
$ lscpu -e=CPU,CORE,SOCKET,NODE,MAXMHZ  # Компактна таблиця топології та максимальних частот ядер
```
