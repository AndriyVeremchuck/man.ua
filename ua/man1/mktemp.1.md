# 📖 mktemp(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 mktemp`

---

## 🎯 НАЗВА (NAME)
**`mktemp`** — Безпечне створення унікальних тимчасових файлів або директорій у системному каталозі /tmp з гарантією відсутності колізій імен.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
mktemp [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-d (створити тимчасову директорію), -p <каталог> (базова директорія), -t <шаблон> (шаблон назви з XXXX), -u (тільки згенерувати ім'я)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `mktemp` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 mktemp` або аліас `uman mktemp`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ TMP_DIR=$(mktemp -d /tmp/build_XXXXXX)  # Створення захищеної тимчасової директорії для збірки
$ TMP_FILE=$(mktemp --suffix=.json)  # Створення тимчасового файлу з розширенням .json
```
