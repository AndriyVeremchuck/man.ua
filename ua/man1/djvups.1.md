# 📖 djvups(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `djvulibre`  
> **Оригінальний виклик**: `man 1 djvups`

---

## 🎯 НАЗВА (NAME)
**`djvups`** — Перетворення документів DjVu у мову розмітки сторінок PostScript для прямого виведення на друк або подальшої конвертації.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
djvups [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-page=<діапазон>, -color (зберегти кольори), -gray (відтінки сірого), -copies=<N>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `djvups` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 djvups` або аліас `uman djvups`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ djvups -color input.djvu output.ps  # Конвертація кольорового документа DjVu у файл PostScript
$ djvups -page=1-5 doc.djvu | lpr  # Пряма відправка перших п'яти сторінок DjVu на системний принтер CUPS
```
