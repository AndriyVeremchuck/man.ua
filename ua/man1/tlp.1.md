# 📖 tlp(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `tlp`  
> **Оригінальний виклик**: `man 1 tlp`

---

## 🎯 НАЗВА (NAME)
**`tlp`** — Передова автоматична система керування енергозбереженням для ноутбуків на Linux: оптимізація батареї, процесора, PCIe та радіомодулів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
tlp [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`start (запуск оптимізації), stat (детальний звіт про живлення), bat (режим від батареї), ac (режим від мережі)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `tlp` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 tlp` або аліас `uman tlp`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo tlp-stat -b  # Детальний звіт про стан акумулятора ноутбука: ємність, знос, цикли зарядки
$ sudo tlp start  # Застосування оптимальних налаштувань енергозбереження
```
