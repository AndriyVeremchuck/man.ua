# 📖 join(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 join`

---

## 🎯 НАЗВА (NAME)
**`join`** — Реляційне об'єднання рядків з двох текстових файлів за спільним ключовим полем (аналог SQL INNER / LEFT JOIN у терміналі).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
join [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-1 <поле> (номер ключового поля в 1-му файлі), -2 <поле> (у 2-му файлі), -t <символ> (роздільник колонок), -a <1/2> (включити неспарені рядки)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `join` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 join` або аліас `uman join`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ join -t: -1 1 -2 1 <(sort /etc/passwd) <(sort /etc/shadow)  # Об'єднання даних облікових записів passwd та shadow за іменем користувача
$ join -1 2 -2 1 users.txt orders.txt  # З'єднання таблиць користувачів та їхніх замовлень за спільним ID
```
