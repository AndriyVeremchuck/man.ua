# 📖 lsusb(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `usbutils`  
> **Оригінальний виклик**: `man 1 lsusb`

---

## 🎯 НАЗВА (NAME)
**`lsusb`** — Відображення інформації про всі USB-контролери та підключені пристрої (клавіатури, миші, вебкамери, флешки, аудіоінтерфейси).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
lsusb [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-v (повна специфікація дескрипторів), -t (дерево USB хабів та портів зі швидкостями), -s <bus:dev> (конкретний пристрій), -d <vendor:product>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `lsusb` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 lsusb` або аліас `uman lsusb`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ lsusb -t  # Деревоподібний перегляд USB портів та їхніх швидкостей (480M, 5000M, 10G)
$ lsusb  # Список усіх підключених USB-пристроїв з ідентифікаторами Vendor/Product ID
```
