# 📖 pipx(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `python-pipx`  
> **Оригінальний виклик**: `man 1 pipx`

---

## 🎯 НАЗВА (NAME)
**`pipx`** — Інструмент для встановлення та запуску CLI-додатків Python в індивідуальних ізольованих віртуальних середовищах без засмічення системних бібліотек.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pipx [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`install <пакет>, run <пакет> (одноразовий запуск), list, upgrade-all, uninstall <пакет>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pipx` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pipx` або аліас `uman pipx`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ pipx install black  # Ізольоване встановлення форматера коду Python у систему
$ pipx list  # Перегляд усіх встановлених автономних CLI утиліт
```
