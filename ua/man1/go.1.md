# 📖 go(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `go`  
> **Оригінальний виклик**: `man 1 go`

---

## 🎯 НАЗВА (NAME)
**`go`** — Офіційний інструментарій компіляції, тестування, форматування та керування модулями для високоефективної мови програмування Go від Google.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
go [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`build (компіляція), run <файл.go> (запуск), test ./... (запуск тестів), mod tidy (очищення залежностей), fmt ./... (форматування коду)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `go` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 go` або аліас `uman go`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ go build -ldflags="-s -w" -o my_app .  # Компіляція компактного бінарника Go з видаленням таблиць символів
$ go run main.go  # Миттєва компіляція та запуск скрипту Go
```
