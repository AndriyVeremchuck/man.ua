# 📖 wipefs(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `util-linux`  
> **Оригінальний виклик**: `man 1 wipefs`

---

## 🎯 НАЗВА (NAME)
**`wipefs`** — Безпечне виявлення та видалення сигнатур файлових систем, RAID-масивів та таблиць розділів (GPT/MBR) з блокових пристроїв.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
wipefs [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-a (видалити всі знайдені сигнатури), -n (тестовий перегляд без видалення), -o <зміщення> (видалити за конкретним зміщенням)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `wipefs` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 wipefs` або аліас `uman wipefs`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo wipefs -n /dev/sdb  # Тестовий огляд сигнатур на диску перед форматуванням
$ sudo wipefs -a /dev/sdb  # Повне очищення старих сигнатур файлових систем на накопичувачі
```
