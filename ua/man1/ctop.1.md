# 📖 ctop(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `ctop`  
> **Оригінальний виклик**: `man 1 ctop`

---

## 🎯 НАЗВА (NAME)
**`ctop`** — TUI-моніторинг контейнерів у реальному часі (як top для контейнерів Docker та Podman) із метриками CPU, пам'яті та мережевого I/O.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ctop [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-a (показувати всі контейнери), -r (зворотне сортування), -i (ігнорувати зупинені)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ctop` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ctop` або аліас `uman ctop`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ctop  # Інтерактивний перегляд навантаження кожного окремого контейнера
$ ctop -a  # Перегляд активних та зупинених контейнерів
```
