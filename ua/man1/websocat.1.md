# 📖 websocat(1) — Українська системна документація

> **Пакет**: `websocat`

---

## 🎯 НАЗВА (NAME)
**`websocat`** — Універсальний інструмент командного рядка для тестування, прослуховування та з'єднання WebSocket сокетів (як netcat для WebSockets).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
websocat [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-v (докладний вивід), -s <порт> (режим сервера), -u (UDP замість TCP), --text`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `websocat` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 websocat` або аліас `uman websocat`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ websocat wss://echo.websocket.org  # Інтерактивне підключення до захищеного WebSocket сервера
$ websocat -s 8080  # Запуск локального ехо-сервера WebSocket на порту 8080
```
