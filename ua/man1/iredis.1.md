# 📖 iredis(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `iredis`  
> **Оригінальний виклик**: `man 1 iredis`

---

## 🎯 НАЗВА (NAME)
**`iredis`** — Термінальний клієнт для NoSQL сховища Redis з автодоповненням команд, підсвічуванням синтаксису та підказками аргументів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
iredis [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-h <хост>, -p <порт>, -a <пароль>, -n <номер_бази>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `iredis` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 iredis` або аліас `uman iredis`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ iredis -h 127.0.0.1 -p 6379  # Підключення до сервера Redis з інтерактивними підказками
$ iredis  # Підключення до локального Redis за замовчуванням
```
