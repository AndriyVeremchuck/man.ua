# 📖 iostat(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `sysstat`  
> **Оригінальний виклик**: `man 1 iostat`

---

## 🎯 НАЗВА (NAME)
**`iostat`** — Моніторинг завантаження процесора та детальної статистики вводу/виводу для блокових пристроїв (швидкість читання/запису, затримки).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
iostat [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-x (розширена статистика з часом очікування await), -d (тільки диски), -h (читабельні МБ/с), -p <пристрій>, <інтервал>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `iostat` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 iostat` або аліас `uman iostat`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ iostat -x -h 1 5  # Розширена діагностика дискових затримок та навантаження SSD/HDD щосекунди
$ iostat -p nvme0n1  # Статистика операцій I/O для основного NVMe накопичувача
```
