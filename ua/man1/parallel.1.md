# 📖 parallel(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `parallel`  
> **Оригінальний виклик**: `man 1 parallel`

---

## 🎯 НАЗВА (NAME)
**`parallel`** — GNU Parallel — потужний інструмент для автоматичного паралельного запуску однотипних команд на всіх доступних ядрах процесора.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
parallel [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-j <N> (кількість потоків), --bar (відображення прогрес-бару), --eta (оцінка часу завершення), --dry-run (тестовий запуск)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `parallel` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 parallel` або аліас `uman parallel`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ parallel --bar "convert {} -quality 85 {.}.webp" ::: *.png  # Паралельна конвертація всіх PNG у WebP на всіх ядрах CPU
$ find . -name "*.log" | parallel -j 8 gzip  # Паралельне стиснення знайдених лог-файлів у 8 потоків
```
