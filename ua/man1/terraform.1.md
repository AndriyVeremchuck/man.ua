# 📖 terraform(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `terraform`  
> **Оригінальний виклик**: `man 1 terraform`

---

## 🎯 НАЗВА (NAME)
**`terraform`** — Провідний інструмент інфраструктури як код (IaC) для декларативного опису, створення та керування хмарними ресурсами (AWS, GCP, Azure, Hetzner).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
terraform [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`init (ініціалізація провайдерів), plan (попередній розрахунок змін), apply (застосування інфраструктури), destroy (видалення)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `terraform` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 terraform` або аліас `uman terraform`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ terraform plan  # Аналіз файлів .tf та генерація плану створення ресурсів
$ terraform apply -auto-approve  # Застосування змін та створення хмарної інфраструктури
```
