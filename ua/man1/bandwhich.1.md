# 📖 bandwhich(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `bandwhich`  
> **Оригінальний виклик**: `man 1 bandwhich`

---

## 🎯 НАЗВА (NAME)
**`bandwhich`** — Термінальна TUI-утиліта на Rust для відображення мережевого трафіку за процесами, з'єднаннями та віддаленими IP-адресами в реальному часі.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
bandwhich [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-i <інтерфейс>, --raw (режим без TUI), --show-dns, -d <N> (затримка)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `bandwhich` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 bandwhich` або аліас `uman bandwhich`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo bandwhich  # Інтерактивний перегляд споживання пропускної здатності мережі процесами
$ sudo bandwhich -i wlan0 --show-dns  # Моніторинг Wi-Fi інтерфейсу з резолвінгом доменних імен
```
