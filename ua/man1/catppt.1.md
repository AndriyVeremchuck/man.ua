# 📖 catppt(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `catdoc`  
> **Оригінальний виклик**: `man 1 catppt`

---

## 🎯 НАЗВА (NAME)
**`catppt`** — Витяг тексту зі слайдів бінарних презентацій Microsoft PowerPoint (.ppt) безпосередньо у термінальний потік.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
catppt [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-d <кодування>, <файл.ppt>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `catppt` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 catppt` або аліас `uman catppt`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ catppt presentation.ppt  # Вилучення тексту всіх слайдів презентації PowerPoint
$ catppt presentation.ppt | grep -i "бюджет"  # Пошук інформації всередині презентації PPT
```
