# 📖 sync(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 sync`

---

## 🎯 НАЗВА (NAME)
**`sync`** — Примусове скидання всіх модифікованих буферів файлових систем та кешу оперативної пам'яті на фізичні накопичувачі (SSD, HDD, USB).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
sync [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-d (скинути тільки дані файлів), -f <файл/каталог> (скинути конкретну файлову систему)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `sync` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 sync` або аліас `uman sync`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sync  # Примусовий запис усіх кешованих даних перед вилученням USB-флешки
$ sync -f /home  # Синхронізація кешу виключно для файлової системи /home
```
