# 📖 exit(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `shell builtin`  
> **Оригінальний виклик**: `man 1 exit`

---

## 🎯 НАЗВА (NAME)
**`exit`** — Вихід із поточної оболонки або закриття активного вікна термінала з передачею коду виходу.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
exit [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`exit <код_повернення>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `exit` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 exit` або аліас `uman exit`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ exit  # Закрити поточну сесію термінала
$ exit 0  # Вихід з успішним кодом 0
```
