# 📖 gedit(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `gedit`  
> **Оригінальний виклик**: `man 1 gedit`

---

## 🎯 НАЗВА (NAME)
**`gedit`** — Класичний графічний текстовий редактор із вкладками, підсвічуванням синтаксису та плагінами.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
gedit [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--new-window, -s (перевірка орфографії), -w (чекати закриття)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `gedit` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 gedit` або аліас `uman gedit`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ gedit notes.txt  # Відкрити файл у графічному вікні редактора
```
