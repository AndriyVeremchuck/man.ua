# 📖 nmtui(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `networkmanager`  
> **Оригінальний виклик**: `man 1 nmtui`

---

## 🎯 НАЗВА (NAME)
**`nmtui`** — Зручний псевдографічний TUI-інтерфейс NetworkManager для швидкого налаштування дротових з'єднань, підключення до Wi-Fi та редагування DNS.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
nmtui [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`connect (активація з'єднання), edit (редагування профілів), hostname (зміна імені хоста)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `nmtui` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 nmtui` або аліас `uman nmtui`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ nmtui  # Запуск інтерактивного меню конфігурації мережі
$ nmtui connect  # Швидкий вибір та підключення до мереж Wi-Fi зі списку доступних
```
