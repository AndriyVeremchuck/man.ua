# 📖 cpio(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `cpio`  
> **Оригінальний виклик**: `man 1 cpio`

---

## 🎯 НАЗВА (NAME)
**`cpio`** — Низькорівневий потоковий архіватор для розпакування та створення образів initramfs/initrd ядра Linux.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
cpio [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-i (розпакування), -o (створення), -H <формат>, -v (детально)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `cpio` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 cpio` або аліас `uman cpio`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ls | cpio -ov -H newc > initramfs.cpio  # Створення образу initramfs для ядра
```
