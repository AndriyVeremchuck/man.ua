# 📖 docker-compose(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `docker-compose`  
> **Оригінальний виклик**: `man 1 docker-compose`

---

## 🎯 НАЗВА (NAME)
**`docker-compose`** — Інструмент декларативної оркестрації багатоконтейнерних додатків за допомогою конфігураційних файлів docker-compose.yml.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
docker-compose [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`up -d (запуск усіх сервісів у фоні), down (зупинка та видалення контейнерів), ps (статус сервісів), logs -f (моніторинг логів)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `docker-compose` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 docker-compose` або аліас `uman docker-compose`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ docker-compose up -d  # Миттєвий запуск повного стеку мікросервісів у фоновому режимі
$ docker-compose logs -f app  # Слідкування за логами додатку в реальному часі
```
