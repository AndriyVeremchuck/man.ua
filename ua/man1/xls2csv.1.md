## 🎯 НАЗВА (NAME)
**`xls2csv`** — Вилучення числових та текстових даних із бінарних таблиць Microsoft Excel (.xls) та експорт у табличний формат CSV.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
xls2csv [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-b <роздільник_аркушів>, -c <роздільник_колонок>, -q <лапки>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `xls2csv` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 xls2csv` або аліас `uman xls2csv`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ xls2csv data.xls > data.csv  # Експорт бінарної таблиці Excel у стандартний файл CSV
$ xls2csv -c "," report.xls  # Вивід таблиці з комами як роздільниками стовпчиків
```
