# 📖 top(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `procps-ng`  
> **Оригінальний виклик**: `man 1 top`

---

## 🎯 НАЗВА (NAME)
**`top`** — Класичний динамічний диспетчер системних процесів реального часу.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
top [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-d <інтервал_оновлення>, -u <користувач>, -p <PID>, -b (пакетний режим)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `top` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 top` або аліас `uman top`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ top  # Запуск моніторингу активності процесів та навантаження процесора
```
