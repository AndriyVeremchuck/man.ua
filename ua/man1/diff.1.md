# 📖 diff(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `diffutils`  
> **Оригінальний виклик**: `man 1 diff`

---

## 🎯 НАЗВА (NAME)
**`diff`** — Рядкове порівняння файлів та створення патчів різниці між версіями.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
diff [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-u (unified формат), -r (рекурсивне порівняння каталогів), -y (порівняння у дві колонки side-by-side), -w (ігнорувати пробіли)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `diff` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 diff` або аліас `uman diff`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ diff -u config_old.env config_new.env  # Показати різницю між конфігураціями у стандартному unified diff
```
