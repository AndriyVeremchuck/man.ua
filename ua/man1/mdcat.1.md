# 📖 mdcat(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `mdcat`  
> **Оригінальний виклик**: `man 1 mdcat`

---

## 🎯 НАЗВА (NAME)
**`mdcat`** — Сучасна заміна команди cat для файлів Markdown із нативним відображенням вбудованих зображень (iTerm2, Kitty, Sixel) та клікабельними лінками.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
mdcat [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-p / --paginate, --local, <файл.md>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `mdcat` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 mdcat` або аліас `uman mdcat`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ mdcat README.md  # Виведення Markdown файлу в термінал із форматованими блоками коду
$ curl -s https://example.com/guide.md | mdcat -  # Прямий рендеринг віддаленого Markdown з вебу
```
