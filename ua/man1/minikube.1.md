# 📖 minikube(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `minikube`  
> **Оригінальний виклик**: `man 1 minikube`

---

## 🎯 НАЗВА (NAME)
**`minikube`** — Інструмент швидкого локального розгортання повноцінного однонодового кластера Kubernetes у середовищі Docker, KVM або Podman.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
minikube [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`start [--driver=docker/kvm2], stop, status, dashboard (відкрити веб-панель), ip`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `minikube` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 minikube` або аліас `uman minikube`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ minikube start --driver=docker  # Запуск локального кластера Kubernetes всередині Docker
$ minikube dashboard  # Відкриття офіційного веб-інтерфейсу керування кластером
```
