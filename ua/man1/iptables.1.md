# 📖 iptables(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `iptables`  
> **Оригінальний виклик**: `man 1 iptables`

---

## 🎯 НАЗВА (NAME)
**`iptables`** — Класичний інструмент фільтрації мережевих пакетів, трансляції адрес (NAT) та захисту портів ядра Linux (через підсистему Netfilter).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
iptables [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-L -v -n (список правил без DNS), -A <ланцюжок> (додати правило), -D (видалити правило), -F (скинути правила), -t <таблиця> (filter, nat, mangle)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `iptables` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 iptables` або аліас `uman iptables`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo iptables -L -n -v  # Перегляд усіх активних ланцюжків фільтрації та лічильників пакетів
$ sudo iptables -A INPUT -p tcp --dport 22 -j ACCEPT  # Дозвіл вхідних SSH з'єднань на порт 22
```
