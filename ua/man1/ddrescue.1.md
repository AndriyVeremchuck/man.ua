# 📖 ddrescue(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `ddrescue`  
> **Оригінальний виклик**: `man 1 ddrescue`

---

## 🎯 НАЗВА (NAME)
**`ddrescue`** — Спеціалізована утиліта порятунку даних, що копіює інформацію з пошкоджених накопичувачів із збійними секторами (bad sectors) за алгоритмом картини логу.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ddrescue [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-n (швидкий прохід без затримок на bad-секторах), -r<число> (кількість повторних спроб), -b <розмір_сектора>, <джерело> <образ> <файл_карти>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ddrescue` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ddrescue` або аліас `uman ddrescue`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo ddrescue -d -n /dev/sdb broken_disk.img mapfile.log  # Перший прохід порятунку читабельних блоків із пошкодженого диска
$ sudo ddrescue -d -r 3 /dev/sdb broken_disk.img mapfile.log  # Спроба відновлення важкодоступних збійних секторів
```
