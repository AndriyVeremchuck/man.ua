# 📖 ncat(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `nmap`  
> **Оригінальний виклик**: `man 1 ncat`

---

## 🎯 НАЗВА (NAME)
**`ncat`** — Сучасна реалізація утиліти Netcat від розробників Nmap з підтримкою шифрування SSL/TLS, IPv6, проксі-серверів та перенаправлення портів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ncat [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-l (режим прослуховування сервера), -p <порт> (порт), --ssl (використовувати SSL/TLS шифрування), -v (докладний вивід), -k (тримати сокет відкритим для кількох клієнтів)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ncat` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ncat` або аліас `uman ncat`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ncat -v --ssl example.com 443  # Встановлення захищеного інтерактивного TLS сокет-з'єднання з сервером
$ ncat -l -p 8080 --exec "/bin/cat file.html"  # Створення простого одноразового HTTP сервера для віддачі файлу
```
