# 📖 taskset(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `util-linux`  
> **Оригінальний виклик**: `man 1 taskset`

---

## 🎯 НАЗВА (NAME)
**`taskset`** — Встановлення та перевірка маски спорідненості процесора (CPU affinity) для жорсткої прив'язки виконання процесу до обраних ядер CPU.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
taskset [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-c <список ядер> (наприклад 0,2,4-7), -p <PID> (для існуючого процесу), -a (для всіх потоків процесу)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `taskset` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 taskset` або аліас `uman taskset`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ taskset -c 0-3 ./game_or_heavy_app  # Запуск ресурсомісткого додатку суворо на ядрах 0, 1, 2, 3
$ taskset -c -p 1234  # Перегляд переліку дозволених ядер CPU для процесу з PID 1234
```
