# 📖 smartctl(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `smartmontools`  
> **Оригінальний виклик**: `man 1 smartctl`

---

## 🎯 НАЗВА (NAME)
**`smartctl`** — Моніторинг стану здоров'я, температури та діагностика дисків NVMe, SSD та HDD за показниками S.M.A.R.T.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
smartctl [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-H (короткий статус здоров'я), -a (повний звіт), -x (розширений), -t short <диск>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `smartctl` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 smartctl` або аліас `uman smartctl`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo smartctl -H /dev/nvme0n1  # Швидка перевірка справності NVMe накопичувача
$ sudo smartctl -a /dev/nvme0n1  # Повний звіт S.M.A.R.T. та кількість прочитаних терабайтів
```
