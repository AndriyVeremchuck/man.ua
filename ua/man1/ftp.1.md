# 📖 ftp(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `inetutils`  
> **Оригінальний виклик**: `man 1 ftp`

---

## 🎯 НАЗВА (NAME)
**`ftp`** — Класичний клієнт передачі файлів за стандартним протоколом File Transfer Protocol.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ftp [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-p (пасивний режим), -v (детальний вивід)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ftp` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ftp` або аліас `uman ftp`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ftp ftp.example.com  # Підключитися до FTP-сервера
```
