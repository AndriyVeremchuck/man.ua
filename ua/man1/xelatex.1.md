# 📖 xelatex(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `texlive-core`  
> **Оригінальний виклик**: `man 1 xelatex`

---

## 🎯 НАЗВА (NAME)
**`xelatex`** — Сучасний рушій компіляції LaTeX з нативною підтримкою UTF-8, системних шрифтів OpenType та розширеної мікротипографіки.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
xelatex [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-interaction=nonstopmode, -output-directory=<папка>, <документ.tex>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `xelatex` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 xelatex` або аліас `uman xelatex`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ xelatex document.tex  # Компіляція документа LaTeX українською мовою з системними шрифтами OpenType
$ xelatex -interaction=nonstopmode thesis.tex  # Пакетна компіляція наукової роботи без зупинок на дрібні попередження
```
