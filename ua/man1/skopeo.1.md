# 📖 skopeo(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `skopeo`  
> **Оригінальний виклик**: `man 1 skopeo`

---

## 🎯 НАЗВА (NAME)
**`skopeo`** — Утиліта для інспектування метаданих, копіювання, видалення та підпису образів у реєстрах контейнерів (Docker Hub, Quay, GitHub Packages) без завантаження всього образу.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
skopeo [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`inspect <образ>, copy <джерело> <призначення>, delete <образ>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `skopeo` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 skopeo` або аліас `uman skopeo`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ skopeo inspect docker://docker.io/library/alpine:latest  # Перегляд шарів, архітектури та тегів образу Alpine на Docker Hub
$ skopeo copy docker://docker.io/library/nginx:alpine dir:/tmp/nginx_layers  # Пряме копіювання шарів образу в локальну папку
```
