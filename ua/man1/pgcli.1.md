# 📖 pgcli(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `pgcli`  
> **Оригінальний виклик**: `man 1 pgcli`

---

## 🎯 НАЗВА (NAME)
**`pgcli`** — Розумний CLI-клієнт для PostgreSQL з автодоповненням назв таблиць, колонок, функцій та підсвічуванням синтаксису.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pgcli [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-h <хост>, -p <порт>, -u <користувач>, -d <база_даних>, --auto-vertical-output`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pgcli` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pgcli` або аліас `uman pgcli`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ pgcli -h localhost -u postgres -d my_app  # Запуск термінального клієнта PostgreSQL з розумними автопідказками
$ pgcli postgres://user:pass@localhost:5432/db  # Швидке підключення за рядком DSN
```
