# 📖 split(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 split`

---

## 🎯 НАЗВА (NAME)
**`split`** — Розбиття великих файлів на менші частини за фіксованим розміром (байтами) або кількістю рядків.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
split [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-b <розмір у КБ/МБ/ГБ>, -l <кількість_рядків>, -d (числові суфікси)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `split` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 split` або аліас `uman split`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ split -b 100M huge_backup.tar.gz part_  # Розбити великий файл на частини по 100 МБ
```
