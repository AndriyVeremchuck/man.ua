# 📖 navi(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `navi`  
> **Оригінальний виклик**: `man 1 navi`

---

## 🎯 НАЗВА (NAME)
**`navi`** — Інтерактивна TUI шпаргалка для командного рядка: пошук готових шаблонів команд із автопідстановкою аргументів та параметрів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
navi [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--query "<запит>", --print, repo add <url>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `navi` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 navi` або аліас `uman navi`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ navi  # Запуск інтерактивного TUI пошуку шпаргалок по командах
$ navi --query "docker run"  # Пошук готових шаблонів запуску Docker
```
