# 📖 glances(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `glances`  
> **Оригінальний виклик**: `man 1 glances`

---

## 🎯 НАЗВА (NAME)
**`glances`** — Комплексний системний монітор на Python з підтримкою TUI, веб-інтерфейсу та експорту метрик.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
glances [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-w (запустити веб-сервер), -t <секунди>, --export <формат>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `glances` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 glances` або аліас `uman glances`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ glances  # Запуск інтерактивного консольного дашборду
$ glances -w  # Запуск веб-сервера моніторингу на порту 61208
```
