# 📖 epubcheck(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `epubcheck`  
> **Оригінальний виклик**: `man 1 epubcheck`

---

## 🎯 НАЗВА (NAME)
**`epubcheck`** — Офіційний валідатор специфікації EPUB від W3C/IDPF: перевірка структури XML, навігації, стилів CSS та відповідності стандартам EPUB 2/3.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
epubcheck [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--mode <exp/opf/nav>, --quiet, -out <звіт.json>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `epubcheck` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 epubcheck` або аліас `uman epubcheck`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ epubcheck book.epub  # Повна валідація файлу книги EPUB на наявність помилок структури та розмітки
$ epubcheck -out report.json book.epub  # Збереження детального звіту валідації у форматі JSON
```
