# 📖 python3(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `python`  
> **Оригінальний виклик**: `man 1 python3`

---

## 🎯 НАЗВА (NAME)
**`python3`** — Інтерпретатор потужної високорівневої мови програмування Python 3 з багатою стандартною бібліотекою та динамічною типізацією.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
python3 [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-m <модуль> (запуск модуля: venv, http.server), -c "<код>" (виконання виразу), -u (небуферизований вивід), -i (інтерактивний режим)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `python3` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 python3` або аліас `uman python3`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ python3 -m http.server 8000  # Швидкий запуск локального веб-сервера у поточній директорії
$ python3 -m venv .venv  # Створення ізольованого віртуального середовища Python
```
