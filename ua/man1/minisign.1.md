# 📖 minisign(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `minisign`  
> **Оригінальний виклик**: `man 1 minisign`

---

## 🎯 НАЗВА (NAME)
**`minisign`** — Надпростий та стійкий інструмент цифрового підпису та верифікації файлів за алгоритмом Ed25519 (елегантна альтернатива GPG).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
minisign [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-G (генерація пари ключів), -S (підпис файлу), -V (перевірка підпису), -m <файл>, -p <публічний_ключ>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `minisign` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 minisign` або аліас `uman minisign`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ minisign -Sm package.tar.zst  # Створення цифрового підпису для архіву релізу
$ minisign -Vm package.tar.zst -p minisign.pub  # Швидка перевірка автентичності та цілісності підписаного файлу
```
