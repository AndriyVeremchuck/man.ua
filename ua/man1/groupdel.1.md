# 📖 groupdel(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки

## 🎯 НАЗВА (NAME)
**`groupdel`** — Видалення групи користувачів із системи.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
groupdel [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`<назва_групи>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `groupdel` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 groupdel` або аліас `uman groupdel`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo groupdel temp_group  # Видалити групу temp_group
```
