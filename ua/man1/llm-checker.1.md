# 📖 llm-checker(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `llm-checker (NPM Global)`  
> **Оригінальний виклик**: `man 1 llm-checker`

---

## 🎯 НАЗВА (NAME)
**`llm-checker`** — Діагностична утиліта для тестування доступності AI API-ключів, швидкості відповідей та працездатності MCP-серверів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
llm-checker [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--check-all, --benchmark, --mcp-test`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `llm-checker` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 llm-checker` або аліас `uman llm-checker`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ llm-checker --check-all  # Комплексна перевірка працездатності всіх налаштованих LLM провайдерів
```
