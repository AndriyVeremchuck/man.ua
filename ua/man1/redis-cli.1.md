# 📖 redis-cli(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `redis (~/.local/bin)`  
> **Оригінальний виклик**: `man 1 redis-cli`

---

## 🎯 НАЗВА (NAME)
**`redis-cli`** — Командний інтерфейс клієнта швидкісної нереляційної in-memory бази даних та брокера повідомлень Redis.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
redis-cli [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-h <хост>, -p <порт>, -a <пароль>, ping, monitor`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `redis-cli` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 redis-cli` або аліас `uman redis-cli`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ redis-cli ping  # Перевірка зв'язку з локальним сервером Redis (відповідь PONG)
$ redis-cli monitor  # Перегляд усіх запитів до бази Redis у реальному часі
```
