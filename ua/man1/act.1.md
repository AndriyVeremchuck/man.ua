# 📖 act(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `act`  
> **Оригінальний виклик**: `man 1 act`

---

## 🎯 НАЗВА (NAME)
**`act`** — Утиліта локального запуску робочих процесів GitHub Actions у Docker контейнерах для швидкого тестування пайплайнів CI/CD перед пушем.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
act [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-l (список доступних workflows), -j <назва_job>, --dryrun, -s <СЕКРЕТ=значення>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `act` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 act` або аліас `uman act`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ act -l  # Список усіх GitHub Actions задач у поточному репозиторії
$ act push  # Локальне виконання workflow для події git push у Docker
```
