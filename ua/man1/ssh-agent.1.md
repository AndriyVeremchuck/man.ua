# 📖 ssh-agent(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `openssh`  
> **Оригінальний виклик**: `man 1 ssh-agent`

---

## 🎯 НАЗВА (NAME)
**`ssh-agent`** — Фоновий агент аутентифікації OpenSSH, який безпечно утримує розблоковані приватні ключі в пам'яті для уникнення повторного введення паролів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ssh-agent [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-s (запуск у режимі Bourne shell), -k (завершення агента), -t <секунди> (час життя ключів)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ssh-agent` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ssh-agent` або аліас `uman ssh-agent`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ eval $(ssh-agent -s)  # Ініціалізація та запуск SSH-агента у поточній сесії терміналу
$ ssh-add ~/.ssh/id_ed25519  # Додавання приватного ключа в пам'ять активного SSH-агента
```
