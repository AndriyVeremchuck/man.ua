# 📖 podman(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `podman`  
> **Оригінальний виклик**: `man 1 podman`

---

## 🎯 НАЗВА (NAME)
**`podman`** — Сучасний контейнерний рушій стандарту OCI без фонового root-демона (daemonless & rootless), сумісний за всіма командами з Docker.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
podman [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`ps (контейнери), run (запуск), pod (керування групами подів Kubernetes), generate kube (експорт маніфесту K8s)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `podman` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 podman` або аліас `uman podman`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ podman run -it --rm archlinux:latest /bin/bash  # Безпечний одноразовий запуск контейнера Arch Linux без прав root
$ podman ps --format "table {{.ID}} {{.Image}} {{.Status}}"  # Компактна таблиця активних контейнерів Podman
```
