# 📖 gotop(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `gotop`  
> **Оригінальний виклик**: `man 1 gotop`

---

## 🎯 НАЗВА (NAME)
**`gotop`** — Елегантний та швидкий системний монітор на мові Go з графіками процесора, пам'яті, мережі, температур та підтримкою тем оформлення.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
gotop [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-c / --color <тема>, -r <інтервал>, -m / --minimal`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `gotop` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 gotop` або аліас `uman gotop`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ gotop  # Запуск візуального монітора системних ресурсів
$ gotop -c monokai  # Запуск із колірною палітрою Monokai
```
