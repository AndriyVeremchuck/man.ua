# 📖 df(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 df`

---

## 🎯 НАЗВА (NAME)
**`df`** — Аналіз вільного та зайнятого місця на змонтованих розділах файлових систем.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
df [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-h (людино-зрозумілі розміри), -T (показувати тип ФС), -a (всі файлові системи), -x <тип> (виключити тип ФС)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `df` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 df` або аліас `uman df`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ df -hT  # Показати стан усіх дисків із зазначенням типів файлових систем (Btrfs, Ext4)
```
