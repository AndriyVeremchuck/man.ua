# 📖 mplayer(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `mplayer`  
> **Оригінальний виклик**: `man 1 mplayer`

---

## 🎯 НАЗВА (NAME)
**`mplayer`** — Легендарний консольний мультимедійний плеєр UNIX/Linux для відтворення аудіо та відео файлів, мережевих потоків та дисків.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
mplayer [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-vo <драйвер> (відеовивід), -ao <драйвер> (аудіовивід), -fs (повний екран), -loop <N> (зациклення), -sub <файл> (субтитри)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `mplayer` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 mplayer` або аліас `uman mplayer`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ mplayer -vo caca video.mp4  # Відтворення відео кольоровими ASCII-символами в терміналі
$ mplayer -ao alsa track.mp3  # Відтворення аудіотреку через звуковий драйвер ALSA
```
