# 📖 getfacl(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `acl`  
> **Оригінальний виклик**: `man 1 getfacl`

---

## 🎯 НАЗВА (NAME)
**`getfacl`** — Отримання та перегляд розширених списків контролю доступу (ACL) для файлів та директорій.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
getfacl [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-R (рекурсивно), -e (показати всі маски), -s (пропустити базові права)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `getfacl` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 getfacl` або аліас `uman getfacl`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ getfacl /shared/document.txt  # Переглянути списки доступу файлу
```
