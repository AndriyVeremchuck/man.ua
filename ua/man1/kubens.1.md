# 📖 kubens(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `kubectx`  
> **Оригінальний виклик**: `man 1 kubens`

---

## 🎯 НАЗВА (NAME)
**`kubens`** — Швидке перемикання між просторами імен (namespaces) Kubernetes без необхідності щоразу писати прапорець -n.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
kubens [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`<namespace>, - (попередній простір), -c / --current`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `kubens` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 kubens` або аліас `uman kubens`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ kubens production  # Встановлення простору імен production активним за замовчуванням
$ kubens  # Список усіх доступних просторів імен у кластері
```
