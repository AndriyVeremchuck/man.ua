# 📖 export(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `shell builtin`  
> **Оригінальний виклик**: `man 1 export`

---

## 🎯 НАЗВА (NAME)
**`export`** — Експорт змінних середовища для дочірніх процесів поточної сесії.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
export [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-p (список експортованих), -n (видалити експорт)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `export` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 export` або аліас `uman export`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ export EDITOR=vim  # Встановити редактор за замовчуванням EDITOR=vim
```
