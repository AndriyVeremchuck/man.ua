# 📖 dmidecode(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `dmidecode`  
> **Оригінальний виклик**: `man 1 dmidecode`

---

## 🎯 НАЗВА (NAME)
**`dmidecode`** — Зчитування та декодування низькорівневих таблиць DMI/SMBIOS: версія BIOS, модель материнської плати, характеристики слотів RAM DDR4.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
dmidecode [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-t memory (пам'ять), -t bios (версія BIOS), -t baseboard (материнська плата), -t processor`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `dmidecode` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 dmidecode` або аліас `uman dmidecode`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo dmidecode -t memory  # Показати виробника, частоту та таймінги встановлених модулів пам'яті
$ sudo dmidecode -t bios  # Інформація про поточну прошивку материнської плати
```
