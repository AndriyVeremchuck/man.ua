# 📖 vhs(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `vhs`  
> **Оригінальний виклик**: `man 1 vhs`

---

## 🎯 НАЗВА (NAME)
**`vhs`** — Автоматичний генератор красивих GIF-демонстрацій роботи термінальних утиліт на основі текстового файлу сценарію дій (.tape).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
vhs [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`<файл.tape>, record (інтерактивний запис)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `vhs` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 vhs` або аліас `uman vhs`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ vhs demo.tape  # Генерація анімованого GIF або MP4 ролика за інструкціями у demo.tape
$ vhs new demo.tape  # Створення базового шаблону сценарію запису
```
