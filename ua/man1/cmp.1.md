# 📖 cmp(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `diffutils`  
> **Оригінальний виклик**: `man 1 cmp`

---

## 🎯 НАЗВА (NAME)
**`cmp`** — Побайтове порівняння двох файлів будь-якого типу (текстових або бінарних).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
cmp [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-l (показати байти, що відрізняються), -s (тихий режим, перевірка лише коду повернення)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `cmp` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 cmp` або аліас `uman cmp`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ cmp -l file1.bin file2.bin  # Показати всі позиції байтів, що відрізняються між файлами
```
