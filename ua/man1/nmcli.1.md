# 📖 nmcli(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `networkmanager`  
> **Оригінальний виклик**: `man 1 nmcli`

---

## 🎯 НАЗВА (NAME)
**`nmcli`** — Потужний командний інтерфейс NetworkManager для керування мережевими адаптерами Ethernet, підключенням до Wi-Fi та VPN.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
nmcli [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`dev status, dev wifi list, dev wifi connect <SSID> password <пароль>, con show`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `nmcli` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 nmcli` або аліас `uman nmcli`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ nmcli dev status  # Показати стан усіх мережевих інтерфейсів
$ nmcli dev wifi list  # Сканування та список доступних Wi-Fi мереж
```
