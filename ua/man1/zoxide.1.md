# 📖 zoxide(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `zoxide`  
> **Оригінальний виклик**: `man 1 zoxide`

---

## 🎯 НАЗВА (NAME)
**`zoxide`** — Розумніша альтернатива команді cd на мові Rust. Запам'ятовує найчастіші каталоги та здійснює миттєвий перехід за неповною назвою.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
zoxide [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`z <шаблон> (перейти), zi (інтерактивний вибір через fzf), zoxide query -l (список збережених шляхів), zoxide remove <шлях>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `zoxide` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 zoxide` або аліас `uman zoxide`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ z APP  # Миттєвий перехід до найчастішої папки, що містить "APP"
$ zi  # Інтерактивний пошук та перехід по каталогах за допомогою FZF
```
