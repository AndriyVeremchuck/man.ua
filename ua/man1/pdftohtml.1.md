# 📖 pdftohtml(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `poppler`  
> **Оригінальний виклик**: `man 1 pdftohtml`

---

## 🎯 НАЗВА (NAME)
**`pdftohtml`** — Трансляція PDF-документів у повноцінні веб-сторінки HTML із точним CSS-позиціонуванням елементів та вбудованими шрифтами.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pdftohtml [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-c (комплексний режим з CSS), -s (один суцільний HTML файл), -noframes, -zoom <коефіцієнт>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pdftohtml` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pdftohtml` або аліас `uman pdftohtml`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ pdftohtml -c -s report.pdf report.html  # Конвертація PDF в один автономний HTML файл із точним позиціонуванням блоків
$ pdftohtml -noframes doc.pdf output_web/  # Генерація спрощеного HTML без фреймів
```
