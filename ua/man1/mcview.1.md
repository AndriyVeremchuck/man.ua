# 📖 mcview(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `mc`  
> **Оригінальний виклик**: `man 1 mcview`

---

## 🎯 НАЗВА (NAME)
**`mcview`** — Потужний посторінковий переглядач файлів від Midnight Commander із підтримкою HEX-режиму для бінарних файлів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
mcview [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-h (запуск одразу у шістнадцятковому режимі Hex)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `mcview` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 mcview` або аліас `uman mcview`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ mcview /var/log/pacman.log  # Швидкий перегляд системного логу
$ mcview -h firmware.bin  # Перегляд бінарного файлу у форматі HEX
```
