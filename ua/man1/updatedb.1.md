# 📖 updatedb(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `mlocate / plocate`  
> **Оригінальний виклик**: `man 1 updatedb`

---

## 🎯 НАЗВА (NAME)
**`updatedb`** — Оновлення індексованої бази даних файлової системи для швидкого пошуку командою locate.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
updatedb [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-U <шлях_каталогу>, -v (детально)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `updatedb` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 updatedb` або аліас `uman updatedb`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo updatedb  # Повне оновлення глобального пошукового індексу файлів
```
