# 📖 gdu(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `gdu`  
> **Оригінальний виклик**: `man 1 gdu`

---

## 🎯 НАЗВА (NAME)
**`gdu`** — Ультрашвидкий консольний аналізатор використання дискового простору, написаний на Go, оптимізований для SSD дисків.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
gdu [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-i <шляхи> (ігнорувати), -a (показувати реальний розмір на диску), -c (без кольорів), -n (неінтерактивний режим)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `gdu` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 gdu` або аліас `uman gdu`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ gdu  # Швидке сканування поточної директорії та інтерактивна навігація по важких папках
$ gdu -a /home/dusha  # Аналіз використання диска домашньої директорії
```
