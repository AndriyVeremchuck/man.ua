# 📖 alsamixer(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `alsa-utils`  
> **Оригінальний виклик**: `man 1 alsamixer`

---

## 🎯 НАЗВА (NAME)
**`alsamixer`** — Класичний графічний TUI мікшер на базі ncurses для точного регулювання рівнів гучності, підсилення та каналів фізичних аудіокарт ALSA.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
alsamixer [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-c <номер_карти>, -D <пристрій>, -V <playback/capture/all>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `alsamixer` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 alsamixer` або аліас `uman alsamixer`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ alsamixer  # Відкриття візуального мікшера для налаштування рівнів гучності
$ alsamixer -c 1 -V capture  # Регулювання чутливості мікрофона на другій звуковій карті
```
