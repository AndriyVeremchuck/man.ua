# 📖 deno(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `deno`  
> **Оригінальний виклик**: `man 1 deno`

---

## 🎯 НАЗВА (NAME)
**`deno`** — Сучасне безпечне середовище виконання для JavaScript та TypeScript на базі рушія V8 та Rust із вбудованими інструментами (linter, formatter, bundler).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
deno [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`run [--allow-net/--allow-read] <файл>, task <задача>, fmt (форматування коду), lint (статичний аналіз), compile (збірка в один бінарник)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `deno` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 deno` або аліас `uman deno`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ deno run --allow-net server.ts  # Безпечний запуск сервера на TypeScript з явним дозволом доступу до мережі
$ deno compile --allow-net server.ts  # Компіляція скрипту TypeScript в автономний виконуваний бінарний файл
```
