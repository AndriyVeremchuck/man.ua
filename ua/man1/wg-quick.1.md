# 📖 wg-quick(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `wireguard-tools`  
> **Оригінальний виклик**: `man 1 wg-quick`

---

## 🎯 НАЗВА (NAME)
**`wg-quick`** — Скрипт швидкої ініціалізації, створення інтерфейсу та налаштування маршрутизації VPN WireGuard на основі готових конфігураційних файлів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
wg-quick [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`up <конфігурація>, down <конфігурація>, save <інтерфейс>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `wg-quick` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 wg-quick` або аліас `uman wg-quick`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo wg-quick up wg0  # Підняття WireGuard тунелю за конфігурацією /etc/wireguard/wg0.conf
$ sudo wg-quick down wg0  # Вимкнення VPN та автоматичне відновлення системних маршрутів
```
