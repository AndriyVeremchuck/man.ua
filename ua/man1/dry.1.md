# 📖 dry(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `dry-bin`  
> **Оригінальний виклик**: `man 1 dry`

---

## 🎯 НАЗВА (NAME)
**`dry`** — Інтерактивний менеджер контейнерів Docker для терміналу: керування контейнерами, образами, мережами та логами з клавіатури.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
dry [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-H <docker_host>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `dry` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 dry` або аліас `uman dry`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ dry  # Запуск інтерактивного термінального інтерфейсу керування Docker
$ dry -H unix:///var/run/docker.sock  # Підключення до локального сокету Docker
```
