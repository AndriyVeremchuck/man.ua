# 📖 kill(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Оригінальний виклик**: `man 1 kill`

---

## 🎯 НАЗВА (NAME)
**`kill`** — Надсилання сигналів процесам за їхнім числовим ідентифікатором (PID)

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
kill [-s SIGNAL | -SIGNAL] PID...
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `kill` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 kill` або аліас `uman kill`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ kill -15 1234  # SIGTERM
$ kill -9 1234   # SIGKILL
```
