# 📖 sftp(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `openssh`  
> **Оригінальний виклик**: `man 1 sftp`

---

## 🎯 НАЗВА (NAME)
**`sftp`** — Інтерактивний захищений клієнт передачі файлів за протоколом SSH File Transfer Protocol.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
sftp [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-P <порт>, -i <ключ_автентифікації>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `sftp` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 sftp` або аліас `uman sftp`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sftp user@192.168.1.100  # Підключитися до захищеного файлового SFTP-сервера
```
