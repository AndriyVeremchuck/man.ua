# 📖 nvr(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `python-neovim-remote`  
> **Оригінальний виклик**: `man 1 nvr`

---

## 🎯 НАЗВА (NAME)
**`nvr`** — Утиліта віддаленого керування активними екземплярами Neovim через UNIX-сокети для відкриття файлів у вже запущеному редакторі.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
nvr [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-s / --server <сокет>, --remote <файл>, --remote-tab <файл>, -l (список сокетів)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `nvr` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 nvr` або аліас `uman nvr`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ nvr --remote file.py  # Відкриття файлу у вже запущеному сеансі Neovim замість створення нового процесу
$ nvr --remote-tab config.json  # Відкриття файлу в окремій новій вкладці Neovim
```
