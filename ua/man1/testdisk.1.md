# 📖 testdisk(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `testdisk`  
> **Оригінальний виклик**: `man 1 testdisk`

---

## 🎯 НАЗВА (NAME)
**`testdisk`** — Потужна безкоштовна утиліта відновлення втрачених, випадково видалених розділів дисків (GPT/MBR) та відновлення завантажувальних секторів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
testdisk [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`/log, /debug`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `testdisk` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 testdisk` або аліас `uman testdisk`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo testdisk  # Запуск покрокового майстра відновлення втрачених розділів дисків
$ sudo testdisk /dev/nvme0n1  # Глибокий аналіз та пошук старих заголовків файлових систем на SSD
```
