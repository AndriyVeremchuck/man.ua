# 📖 ipmitool(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `ipmitool`  
> **Оригінальний виклик**: `man 1 ipmitool`

---

## 🎯 НАЗВА (NAME)
**`ipmitool`** — Інструмент керування апаратним інтерфейсом IPMI (Intelligent Platform Management Interface) для серверних материнських плат (живлення, сенсори, BMC).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ipmitool [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`sensor (показники сенсорів), chassis status, power status/on/off/reset, sel list (журнал подій)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ipmitool` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ipmitool` або аліас `uman ipmitool`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo ipmitool sensor  # Зчитування показників сенсорів живлення, вентиляторів та температур сервера
$ sudo ipmitool chassis status  # Перегляд стану живлення серверного шасі
```
