# 📖 odt2txt(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `odt2txt`  
> **Оригінальний виклик**: `man 1 odt2txt`

---

## 🎯 НАЗВА (NAME)
**`odt2txt`** — Миттєве та легке вилучення тексту з файлів OpenDocument (.odt, .ods, .odp, .sxw) безпосередньо у вікно консолі.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
odt2txt [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--width=<ширина_колонки>, --encoding=<кодування>, <файл.odt>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `odt2txt` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 odt2txt` або аліас `uman odt2txt`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ odt2txt document.odt  # Швидкий перегляд тексту документа OpenDocument у терміналі
$ odt2txt document.odt | grep -i "висновок"  # Пошук ключових слів усередині ODT файлу через grep
```
