# 📖 bun(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `bun-bin`  
> **Оригінальний виклик**: `man 1 bun`

---

## 🎯 НАЗВА (NAME)
**`bun`** — Надзвичайно швидкий комплексний інструментарій для JavaScript/TypeScript: повноцінний рантайм, бандлер, тест-ранер та сумісний із npm пакетний менеджер.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
bun [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`run <файл>, install / i, add <пакет>, build <вхід> --outdir <вихід>, test`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `bun` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 bun` або аліас `uman bun`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ bun run server.ts  # Миттєвий нативний запуск TypeScript файлу без попередньої компіляції
$ bun install  # Ультрашвидке паралельне встановлення залежностей проєкту
```
