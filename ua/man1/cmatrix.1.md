# 📖 cmatrix(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `cmatrix`  
> **Оригінальний виклик**: `man 1 cmatrix`

---

## 🎯 НАЗВА (NAME)
**`cmatrix`** — Культова термінальна анімація зеленого цифрового дощу у стилі фільму «Матриця» з можливістю налаштування кольорів та швидкості.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
cmatrix [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-b (жирні символи), -C <колір: cyan/green/blue/red>, -s (режим скрінсейвера), -u <затримка>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `cmatrix` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 cmatrix` або аліас `uman cmatrix`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ cmatrix -b -C cyan  # Запуск ефектної кібер-анімації бірюзового кольору
$ cmatrix -s  # Запуск заставки, що вимикається при натисканні будь-якої клавіші
```
