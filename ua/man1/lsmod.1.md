# 📖 lsmod(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `kmod`  
> **Оригінальний виклик**: `man 1 lsmod`

---

## 🎯 НАЗВА (NAME)
**`lsmod`** — Форматоване виведення списку всіх завантажених у даний момент модулів ядра Linux, їхнього розміру в RAM та списку залежних модулів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
lsmod [OPTIONS] [ARGUMENTS...]
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `lsmod` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 lsmod` або аліас `uman lsmod`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ lsmod | grep -i "nvidia\|amdgpu\|i915"  # Перевірка активних завантажених графічних відеодрайверів
$ lsmod | grep -i "btrfs"  # Перевірка активності модуля файлової системи Btrfs
```
