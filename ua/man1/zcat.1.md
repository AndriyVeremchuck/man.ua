# 📖 zcat(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `gzip`  
> **Оригінальний виклик**: `man 1 zcat`

---

## 🎯 НАЗВА (NAME)
**`zcat`** — Пряме виведення вмісту файлу .gz у консоль без потреби розпаковувати його на диск.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
zcat [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`<файл.gz>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `zcat` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 zcat` або аліас `uman zcat`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ zcat access.log.gz | grep "404"  # Прямий пошук помилок усередині стисненого логу
```
