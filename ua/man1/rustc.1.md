# 📖 rustc(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `rust`  
> **Оригінальний виклик**: `man 1 rustc`

---

## 🎯 НАЗВА (NAME)
**`rustc`** — Офіційний оптимізуючий компілятор мови системного програмування Rust на базі бекенду LLVM із суворою перевіркою безпеки пам'яті (borrow checker).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
rustc [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-O (оптимізація), --edition=2021, -g (налагоджувальні символи), --emit=asm/llvm-ir`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `rustc` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 rustc` або аліас `uman rustc`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ rustc -O main.rs  # Швидка оптимізована компіляція окремого файлу Rust
$ rustc --version --verbose  # Перегляд точної версії компілятора, LLVM та цільової платформи
```
