# 📖 flatpak(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `flatpak`  
> **Оригінальний виклик**: `man 1 flatpak`

---

## 🎯 НАЗВА (NAME)
**`flatpak`** — Універсальна ізольована система розповсюдження десктопних додатків у безпечних пісочницях (Sandbox).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
flatpak [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`list --app (список додатків), install <id>, update, run <id>, uninstall <id>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `flatpak` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 flatpak` або аліас `uman flatpak`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ flatpak list --app  # Показати всі встановлені Flatpak-додатки
$ flatpak update  # Оновити всі встановлені програми Flatpak
```
