# 📖 iftop(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `iftop`  
> **Оригінальний виклик**: `man 1 iftop`

---

## 🎯 НАЗВА (NAME)
**`iftop`** — TUI-моніторинг використання мережевого каналу в реальному часі з відображенням швидкостей для кожної пари з'єднаних IP-хостів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
iftop [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-i <інтерфейс>, -n (не резолвити DNS), -P (показувати номери портів), -N (не резолвити порти у назви служб)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `iftop` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 iftop` або аліас `uman iftop`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo iftop -i eth0 -n  # Перегляд списку з'єднань та споживання трафіку на мережевій карті eth0
$ sudo iftop -i wlan0 -P  # Моніторинг Wi-Fi трафіку з відображенням портів
```
