# 📖 bottom(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `bottom`  
> **Оригінальний виклик**: `man 1 bottom`

---

## 🎯 НАЗВА (NAME)
**`bottom`** — Елегантний графічний TUI монітор системних ресурсів, написаний на Rust, із налаштовуваними віджетами CPU, пам'яті, дискового I/O, мережі та температур.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
bottom [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-b / --basic (базовий компактний режим), -r <мс> (частота оновлення), -m (пам'ять у відсотках), --battery (стан батареї)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `bottom` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 bottom` або аліас `uman bottom`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ btm  # Запуск інтерактивної панелі моніторингу системних ресурсів
$ btm --basic  # Запуск у спрощеному компактному режимі для невеликих вікон
```
