# 📖 atop(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `atop`  
> **Оригінальний виклик**: `man 1 atop`

---

## 🎯 НАЗВА (NAME)
**`atop`** — Розширений системний монітор для глибокого аналізу активності ядер CPU, пам'яті, накопичувачів, мережі та окремих потоків із підсвічуванням перевантажень.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
atop [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-m (пам'ять), -d (диски), -n (мережа), -c (повний командний рядок), -1 (секундне оновлення)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `atop` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 atop` або аліас `uman atop`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ atop  # Запуск детального моніторингу системних ресурсів з колірною індикацією вузьких місць
$ atop -d  # Аналіз дискової активності по кожному процесу та диску
```
