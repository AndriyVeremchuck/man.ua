# 📖 tree(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `tree`  
> **Оригінальний виклик**: `man 1 tree`

---

## 🎯 НАЗВА (NAME)
**`tree`** — Рекурсивне графічне деревоподібне відображення структури директорій та вкладених файлів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
tree [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-L <глибина>, -d (лише папки), -a (приховані), -I <шаблон>, -h (розміри)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `tree` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 tree` або аліас `uman tree`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ tree -L 2 -h  # Відобразити дерево на 2 рівні вглиб із зазначенням розмірів
$ tree -d -L 3  # Показати лише ієрархію каталогів
```
