# 📖 killall(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `psmisc`  
> **Оригінальний виклик**: `man 1 killall`

---

## 🎯 НАЗВА (NAME)
**`killall`** — Надсилання сигналу завершення всім процесам із вказаним точним іменем програми.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
killall [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-i (інтерактивне підтвердження), -u <користувач>, -9 (примусово), -v (детально)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `killall` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 killall` або аліас `uman killall`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ killall -v firefox  # Завершити всі процеси браузера Firefox зі звітом
```
