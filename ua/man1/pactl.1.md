# 📖 pactl(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `libpulse / pipewire-pulse`  
> **Оригінальний виклик**: `man 1 pactl`

---

## 🎯 НАЗВА (NAME)
**`pactl`** — Керування звуковим сервером PipeWire/PulseAudio: гучність, перемикання виходів аудіокарт, мікрофонів та звукових потоків.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pactl [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`info, list short sinks, set-sink-volume @DEFAULT_SINK@ +5%, set-sink-mute @DEFAULT_SINK@ toggle`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pactl` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pactl` або аліас `uman pactl`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ pactl info  # Інформація про активний аудіосервер PipeWire
$ pactl list short sinks  # Список доступних аудіовиходів та динаміків
```
