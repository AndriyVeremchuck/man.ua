# 📖 wpa_cli(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `wpa_supplicant`  
> **Оригінальний виклик**: `man 1 wpa_cli`

---

## 🎯 НАЗВА (NAME)
**`wpa_cli`** — Інтерактивний клієнт демона wpa_supplicant для безпосереднього налаштування ключів шифрування WPA/WPA2/WPA3 та роумінгу Wi-Fi.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
wpa_cli [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`status (поточний статус зв'язку), scan (сканування мереж), scan_results (результати), reassociate`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `wpa_cli` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 wpa_cli` або аліас `uman wpa_cli`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ wpa_cli status  # Перевірка IP-адреси, BSSID, частоти (2.4/5GHz) та швидкості зв'язку Wi-Fi
$ wpa_cli scan_results  # Перегляд списку знайдених Wi-Fi мереж із рівнем сигналу в dBm
```
