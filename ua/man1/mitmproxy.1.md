# 📖 mitmproxy(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `mitmproxy`  
> **Оригінальний виклик**: `man 1 mitmproxy`

---

## 🎯 НАЗВА (NAME)
**`mitmproxy`** — Інтерактивний TUI проксі-сервер для перехоплення, інспектування, модифікації та відтворення HTTP/HTTPS/WebSocket трафіку.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
mitmproxy [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-p <порт> (за замовчуванням 8080), --web (відкрити веб-панель mitmweb), -s <скрипт.py>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `mitmproxy` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 mitmproxy` або аліас `uman mitmproxy`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ mitmproxy  # Запуск інтерактивного термінального перехоплювача HTTP/HTTPS трафіку
$ mitmweb  # Запуск проксі з веб-інтерфейсом керування у браузері
```
