# 📖 edge-tts(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `edge-tts (Python ~/.local/bin)`  
> **Оригінальний виклик**: `man 1 edge-tts`

---

## 🎯 НАЗВА (NAME)
**`edge-tts`** — Високоякісний синтез природного мовлення нейромережами Microsoft Edge TTS з підтримкою українських голосів (Polina, Ostap).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
edge-tts [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--voice <голос>, --text "<текст>", --write-media <файл.mp3>, --list-voices`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `edge-tts` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 edge-tts` або аліас `uman edge-tts`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ edge-tts --voice uk-UA-PolinaNeural --text "Слава Україні!" --write-media out.mp3  # Синтез аудіофайлу українським нейро-голосом Поліни
$ edge-tts --list-voices | grep uk-UA  # Список доступних українських дикторів
```
