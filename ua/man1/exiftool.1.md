# 📖 exiftool(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `perl-image-exiftool`  
> **Оригінальний виклик**: `man 1 exiftool`

---

## 🎯 НАЗВА (NAME)
**`exiftool`** — Еталонна утиліта читання, запису та повного очищення метаданих EXIF, GPS, IPTC, XMP у фотографіях, відео та документах.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
exiftool [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-all= (видалити всі метадані для конфіденційності), -json (вивід у JSON), -r (рекурсивна обробка)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `exiftool` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 exiftool` або аліас `uman exiftool`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ exiftool photo.jpg  # Перегляд повної інформації: модель камери, ISO, витримка, геолокація GPS
$ exiftool -all= -overwrite_original photo.jpg  # Повне анонімне очищення фото від геолокації та метаданих
```
