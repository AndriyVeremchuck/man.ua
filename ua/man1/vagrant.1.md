# 📖 vagrant(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `vagrant`  
> **Оригінальний виклик**: `man 1 vagrant`

---

## 🎯 НАЗВА (NAME)
**`vagrant`** — Інструмент автоматизованого створення, конфігурації та відтворення переносних ізольованих середовищ розробки на базі VirtualBox/KVM.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
vagrant [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`up (запуск VM), ssh (вхід у VM), halt (зупинка), destroy (видалення), status`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `vagrant` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 vagrant` або аліас `uman vagrant`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ vagrant up  # Запуск та провіженінг віртуальної машини згідно з файлом Vagrantfile
$ vagrant ssh  # Миттєве підключення до командної оболонки розгорнутої VM
```
