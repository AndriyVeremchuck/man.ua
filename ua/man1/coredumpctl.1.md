# 📖 coredumpctl(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `systemd`  
> **Оригінальний виклик**: `man 1 coredumpctl`

---

## 🎯 НАЗВА (NAME)
**`coredumpctl`** — Пошук, вилучення та аналіз аварійних дампів пам'яті (core dumps) процесів, що завершилися збоєм (segfault) у системі systemd-coredump.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
coredumpctl [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`list (список усіх аварій), info <PID/програма> (деталі падіння), gdb <PID> (запуск налагодження у GDB), dump <PID> --output <файл>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `coredumpctl` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 coredumpctl` або аліас `uman coredumpctl`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ coredumpctl list  # Перегляд списку останніх аварійних збоїв програм із кодами помилок
$ coredumpctl gdb python3  # Миттєве відкриття дампу впалого процесу Python у відлагоджувачі GDB
```
