# 📖 ps(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Оригінальний виклик**: `man 1 ps`

---

## 🎯 НАЗВА (NAME)
**`ps`** — Звіт про поточні активні процеси користувача та системи

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ps [OPTIONS]
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ps` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ps` або аліас `uman ps`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ps aux | grep python
$ ps -ef --forest
```
