# 📖 gpg(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `gnupg`  
> **Оригінальний виклик**: `man 1 gpg`

---

## 🎯 НАЗВА (NAME)
**`gpg`** — GNU Privacy Guard (GnuPG) — повноцінна реалізація стандарту OpenPGP для шифрування файлів, цифрового підпису коду та керування ключами.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
gpg [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-c (симетричне шифрування паролем), -d (розшифрування), -s (створення цифрового підпису), --verify (перевірка підпису), --list-keys (список публічних ключів)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `gpg` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 gpg` або аліас `uman gpg`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ gpg -c --cipher-algo AES256 secret.txt  # Стійке симетричне шифрування файлу алгоритмом AES-256
$ gpg --verify archlinux-x86_64.iso.sig archlinux-x86_64.iso  # Перевірка автентичності та цілісності ISO-образу
```
