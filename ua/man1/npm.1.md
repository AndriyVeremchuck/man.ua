# 📖 npm(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `npm`  
> **Оригінальний виклик**: `man 1 npm`

---

## 🎯 НАЗВА (NAME)
**`npm`** — Офіційний менеджер пакетів та реєстр модулів для екосистеми Node.js та сучасного фронтенд-вебстеку.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
npm [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`install / i [пакет], run <скрипт> (build, dev, start), init -y (створення package.json), update, audit (перевірка вразливостей)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `npm` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 npm` або аліас `uman npm`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ npm install  # Встановлення всіх залежностей із файлу package.json
$ npm run build  # Запуск скрипту компіляції та оптимізації проєкту
```
