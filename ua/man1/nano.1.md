# 📖 nano(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `nano`  
> **Оригінальний виклик**: `man 1 nano`

---

## 🎯 НАЗВА (NAME)
**`nano`** — Простий та зрозумілий консольний текстовий редактор із підказками гарячих клавіш у нижній панелі.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
nano [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-c (постійно показувати номер рядка та стовпця), -m (підтримка миші), -l (номери рядків), -S (м'який перенос)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `nano` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 nano` або аліас `uman nano`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ nano config.env  # Редагування конфігураційного файлу у консолі
$ nano -l main.py  # Відкрити редактор з нумерацією рядків
```
