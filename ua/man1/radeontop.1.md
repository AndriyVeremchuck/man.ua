# 📖 radeontop(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `radeontop`  
> **Оригінальний виклик**: `man 1 radeontop`

---

## 🎯 НАЗВА (NAME)
**`radeontop`** — TUI-монітор реального завантаження графічних процесорів AMD Radeon: 3D рушій, шейдерні блоки, пам'ять VRAM, відеодекодер та шина PCIe.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
radeontop [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-c / --color, -d <файл> (запис логу), -t <мс> (частота оновлення), -b <номер_карти>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `radeontop` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 radeontop` або аліас `uman radeontop`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ radeontop -c  # Інтерактивний TUI моніторинг завантаження блоків відеокарти AMD Radeon
$ radeontop -d stdout -t 1000  # Вивід показників GPU щосекунди в термінал
```
