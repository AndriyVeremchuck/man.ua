# 📖 groupmod(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `shadow`  
> **Оригінальний виклик**: `man 1 groupmod`

---

## 🎯 НАЗВА (NAME)
**`groupmod`** — Модифікація параметрів групи (зміна назви або GID).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
groupmod [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-n <нова_назва>, -g <новий_GID>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `groupmod` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 groupmod` або аліас `uman groupmod`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo groupmod -n dev_team developers  # Перейменувати групу developers на dev_team
```
