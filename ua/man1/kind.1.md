# 📖 kind(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `kind`  
> **Оригінальний виклик**: `man 1 kind`

---

## 🎯 НАЗВА (NAME)
**`kind`** — Kubernetes in Docker — інструмент для швидкого запуску локальних багатонодових кластерів Kubernetes всередині контейнерів Docker.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
kind [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`create cluster [--name <назва>], delete cluster, get clusters, load docker-image <образ>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `kind` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 kind` або аліас `uman kind`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ kind create cluster --name dev-cluster  # Миттєве розгортання локального кластера Kubernetes для тестування
$ kind delete cluster --name dev-cluster  # Повне видалення тестового кластера
```
