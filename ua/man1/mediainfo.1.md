# 📖 mediainfo(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `mediainfo`  
> **Оригінальний виклик**: `man 1 mediainfo`

---

## 🎯 НАЗВА (NAME)
**`mediainfo`** — Вичерпний технічний аналіз мультимедійних файлів: кодеки відео (HEVC, AV1), аудіодоріжки, субтитри, бітрейт, HDR та колірні профілі.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
mediainfo [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--Output=JSON, --Output=HTML, -f (повний технічний звіт)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `mediainfo` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 mediainfo` або аліас `uman mediainfo`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ mediainfo video.mkv  # Перегляд детальної структури контейнера, бітрейту та кодеків медіафайлу
$ mediainfo --Output=JSON video.mp4  # Отримання структурованих JSON-даних про відео для скриптів
```
