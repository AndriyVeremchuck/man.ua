# 📖 unzip(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `unzip`  
> **Оригінальний виклик**: `man 1 unzip`

---

## 🎯 НАЗВА (NAME)
**`unzip`** — Перегляд вмісту та розпакування файлів із ZIP-архівів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
unzip [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-l (список вмісту без розпакування), -d <цільова_папка>, -q (тихо)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `unzip` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 unzip` або аліас `uman unzip`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ unzip -l project.zip  # Показати список файлів усередині ZIP без розпакування
$ unzip project.zip -d /target/  # Розпакувати ZIP у папку target
```
