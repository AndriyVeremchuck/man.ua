# 📖 lspci(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `pciutils`  
> **Оригінальний виклик**: `man 1 lspci`

---

## 🎯 НАЗВА (NAME)
**`lspci`** — Виведення детального списку всіх пристроїв, підключених до шини PCI та PCI Express (відеокарта, NVMe контролери, Wi-Fi, Ethernet, аудіочипи).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
lspci [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-v / -vv / -vvv (детальний вивід), -k (показати задіяні модулі та драйвери ядра), -nn (показати числові ID вендорів), -t (деревоподібне відображення шини)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `lspci` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 lspci` або аліас `uman lspci`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ lspci -k | grep -A 3 -E "(VGA|3D)"  # Визначення моделі відеокарти та активного драйвера ядра (nvidia / amdgpu)
$ lspci -nnk | grep -i net -A 2  # Перевірка мережевих адаптерів та їхніх драйверів ядра
```
