# 📖 sg(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `ast-grep`  
> **Оригінальний виклик**: `man 1 sg`

---

## 🎯 НАЗВА (NAME)
**`sg`** — Інструмент структурного пошуку та рефакторингу коду на базі синтаксичних дерев Tree-sitter (пошук за логічними шаблонами замість regex).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
sg [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--pattern "<шаблон>", --rewrite "<заміна>", -l <мова>, -i (інтерактивний режим)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `sg` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 sg` або аліас `uman sg`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sg -p "console.log($$$A)"  # Пошук усіх викликів console.log з будь-якими аргументами у проєкті
$ sg -p "fetch($URL)" -r "customFetch($URL)" -i  # Інтерактивний структурний рефакторинг функцій
```
