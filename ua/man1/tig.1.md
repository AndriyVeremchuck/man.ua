# 📖 tig(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `tig`  
> **Оригінальний виклик**: `man 1 tig`

---

## 🎯 НАЗВА (NAME)
**`tig`** — Текстовий ncurses-інтерфейс для Git для інтерактивної навігації по дереву комітів, перегляду посторінкових дифів та швидкого блейму коду.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
tig [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`status (режим перегляду змін), blame <файл>, <гілка>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `tig` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 tig` або аліас `uman tig`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ tig  # Інтерактивний перегляд історії комітів, авторів та графів злиття
$ tig status  # Перегляд та поетапне додавання змінених файлів у git stage
```
