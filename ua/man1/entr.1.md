# 📖 entr(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `entr`  
> **Оригінальний виклик**: `man 1 entr`

---

## 🎯 НАЗВА (NAME)
**`entr`** — Мінімалістична та надійна утиліта Unix для виконання довільних команд при зміні списку файлів, переданих через стандартний ввід.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
entr [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-r (перезапуск довгоживучих процесів), -c (очищення терміналу перед запуском), -s (виконання команди в shell)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `entr` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 entr` або аліас `uman entr`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ls *.py | entr python3 apps-catalog.py  # Автоматичний запуск скрипту при збереженні будь-якого файлу .py
$ find src/ -name "*.rs" | entr -r cargo run  # Перезапуск веб-сервера при модифікації коду Rust
```
