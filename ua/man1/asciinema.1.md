# 📖 asciinema(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `asciinema`  
> **Оригінальний виклик**: `man 1 asciinema`

---

## 🎯 НАЗВА (NAME)
**`asciinema`** — Еталонний інструмент запису та відтворення сесій терміналу у текстовому форматі JSON (asciicast) без втрати якості та розмиття шрифтів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
asciinema [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`rec [файл.cast], play <файл.cast>, upload <файл.cast>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `asciinema` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 asciinema` або аліас `uman asciinema`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ asciinema rec demo.cast  # Запис текстової термінальної сесії у файл
$ asciinema play demo.cast  # Точне відтворення записаної сесії прямо в консолі
```
