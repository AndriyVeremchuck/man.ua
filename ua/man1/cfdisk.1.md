# 📖 cfdisk(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `util-linux`  
> **Оригінальний виклик**: `man 1 cfdisk`

---

## 🎯 НАЗВА (NAME)
**`cfdisk`** — Зручний псевдографічний TUI-редактор таблиць розділів для накопичувачів зі схемами розмітки GPT, MBR, Sun або SGI.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
cfdisk [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`<пристрій> (наприклад /dev/nvme0n1 або /dev/sda), -z (почати з чистою таблицею)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `cfdisk` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 cfdisk` або аліас `uman cfdisk`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo cfdisk /dev/nvme0n1  # Інтерактивне створення, зміна розміру та видалення розділів на SSD
$ sudo cfdisk /dev/sdb  # Розмітка підключеного USB-накопичувача
```
