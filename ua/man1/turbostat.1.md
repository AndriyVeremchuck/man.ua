# 📖 turbostat(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `linux-tools`  
> **Оригінальний виклик**: `man 1 turbostat`

---

## 🎯 НАЗВА (NAME)
**`turbostat`** — Офіційний діагностичний інструмент ядра для вимірювання реальних частот ядер, енергоспоживання в Ватах (PKG/DRAM Power) та C-states на процесорах Intel/AMD.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
turbostat [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--interval <сек>, --show <колонки>, --quiet`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `turbostat` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 turbostat` або аліас `uman turbostat`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo turbostat --interval 1  # Щосекундний моніторинг реальних частот ядер, енергоспоживання та температур
$ sudo turbostat --show PkgWatt,CorWatt,Busy%,Bzy_MHz  # Компактна таблиця споживання потужності та реальних частот ядер
```
