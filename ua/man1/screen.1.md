# 📖 screen(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `screen`  
> **Оригінальний виклик**: `man 1 screen`

---

## 🎯 НАЗВА (NAME)
**`screen`** — Класичний повноекранний мультиплексор віртуальних терміналів GNU Screen для керування кількома консольними сесіями з можливістю відключення.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
screen [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-S <ім'я> (створити сесію з іменем), -r [ім'я] (відновити підключення до сесії), -ls (список активних сесій), -d -r (примусово перехопити сесію)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `screen` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 screen` або аліас `uman screen`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ screen -S compile_job  # Створення іменованої сесії для тривалої компіляції
$ screen -r compile_job  # Повторне підключення до запущеної сесії після розриву з'єднання
```
