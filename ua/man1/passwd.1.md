# 📖 passwd(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `shadow`  
> **Оригінальний виклик**: `man 1 passwd`

---

## 🎯 НАЗВА (NAME)
**`passwd`** — Зміна пароля користувача або керування терміном дії паролів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
passwd [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-S (статус пароля), -l (заблокувати), -u (розблокувати), -d (видалити пароль)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `passwd` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 passwd` або аліас `uman passwd`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ passwd  # Змінити пароль для поточного користувача
$ sudo passwd -S dusha  # Перевірити статус безпеки пароля
```
