---

## 🎯 НАЗВА (NAME)
**`csplit`** — Контекстне розбиття великого текстового файлу на окремі фрагменти на основі шаблонів регулярних виразів або номерів рядків.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
csplit [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-f <префікс> (префікс вихідних файлів), -n <цифр> (кількість цифр у номері), -s (тихий режим без виводу розмірів), -z (видаляти порожні файли)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `csplit` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 csplit` або аліас `uman csplit`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ csplit -f chapter_ book.txt "/^Chapter [0-9]/" "{*}"  # Автоматичне розбиття книги на окремі файли за заголовками розділів
$ csplit -f cert_ certs_bundle.crt "/-----BEGIN CERTIFICATE-----/" "{*}"  # Розбиття бандлу сертифікатів на індивідуальні файли .crt
```
