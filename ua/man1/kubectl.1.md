# 📖 kubectl(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `kubectl`  
> **Оригінальний виклик**: `man 1 kubectl`

---

## 🎯 НАЗВА (NAME)
**`kubectl`** — Офіційний інструмент командного рядка для керування кластерами Kubernetes: розгортання подів, сервісів, ingress та моніторинг ресурсів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
kubectl [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`get <ресурс> (pods, nodes, svc), describe <ресурс> <ім'я>, logs <под>, apply -f <файл.yaml>, exec -it <под> -- <команда>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `kubectl` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 kubectl` або аліас `uman kubectl`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ kubectl get pods -A  # Перегляд усіх активних подів у всіх просторах імен (namespaces)
$ kubectl apply -f deployment.yaml  # Застосування маніфесту розгортання в кластері Kubernetes
```
