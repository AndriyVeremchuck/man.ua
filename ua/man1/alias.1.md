# 📖 alias(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `shell builtin`  
> **Оригінальний виклик**: `man 1 alias`

---

## 🎯 НАЗВА (NAME)
**`alias`** — Створення скорочених псевдонімів команд для прискорення набору та налаштування аргументів за замовчуванням.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
alias [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`alias <ім'я>='<команда>', alias (показати всі)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `alias` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 alias` або аліас `uman alias`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ alias ll='eza -la --icons'  # Створити скорочення ll для виклику eza
$ alias  # Показати всі активні аліаси
```
