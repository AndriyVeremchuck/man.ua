# 📖 sha256sum(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 sha256sum`

---

## 🎯 НАЗВА (NAME)
**`sha256sum`** — Обчислення та верифікація 256-бітних криптографічних контрольних сум за алгоритмом SHA-2 (Secure Hash Algorithm).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
sha256sum [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-c <файл> (автоматична перевірка списку хешів), --status (тихий режим, тільки код повернення), -b (читати у бінарному режимі), --tag (вивід у стилі BSD)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `sha256sum` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 sha256sum` або аліас `uman sha256sum`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sha256sum archive.tar.zst  # Обчислення унікального SHA-256 хешу для архіву проєкту
$ sha256sum -c SHA256SUMS  # Пакетна верифікація файлів з перевірочного списку хешів
```
