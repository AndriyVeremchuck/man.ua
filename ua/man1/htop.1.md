# 📖 htop(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `htop`  
> **Оригінальний виклик**: `man 1 htop`

---

## 🎯 НАЗВА (NAME)
**`htop`** — Інтерактивний кольоровий диспетчер процесів із підтримкою миші, фільтрації та дерева процесів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
htop [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-t (дерево процесів), -u <користувач>, -p <PID>, -d <затримка>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `htop` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 htop` або аліас `uman htop`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ htop -t  # Відображення ієрархічного дерева процесів
$ htop -u dusha  # Фільтрація процесів користувача dusha
```
