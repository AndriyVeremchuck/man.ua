# 📖 gping(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `gping`  
> **Оригінальний виклик**: `man 1 gping`

---

## 🎯 НАЗВА (NAME)
**`gping`** — Пінгувальник із графічним відображенням часових рядків затримки (Ping Graph) прямо в терміналі на базі Rust.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
gping [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-b <N> (розмір буфера), -4 (лише IPv4), -n <сек> (інтервал), --watch (виконання команд замість ping)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `gping` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 gping` або аліас `uman gping`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ gping 1.1.1.1 8.8.8.8 archlinux.org  # Одночасний моніторинг затримки до трьох хостів із живими графіками
$ gping --watch "curl -s https://cachyos.org -o /dev/null -w %{time_total}"  # Графік часу завантаження веб-сайту в реальному часі
```
