# 📖 eza(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `eza`  
> **Оригінальний виклик**: `man 1 eza`

---

## 🎯 НАЗВА (NAME)
**`eza`** — Сучасна заміна ls на Rust із підтримкою іконок, кольорової підсвітки, Git-статусу та дерева каталогів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
eza [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-la (детально + приховані), --icons, --git, --tree, --level <глибина>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `eza` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 eza` або аліас `uman eza`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ eza -la --icons --git  # Повний перегляд вмісту з кольоровими іконками та статусом Git
$ eza --tree --level=2  # Деревоподібний перегляд на 2 рівні вглиб
```
