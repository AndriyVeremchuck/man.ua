# 📖 strace(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `strace`  
> **Оригінальний виклик**: `man 1 strace`

---

## 🎯 НАЗВА (NAME)
**`strace`** — Потужний діагностичний інструмент перехоплення та трасування системних викликів (syscalls) і сигналів між процесом та ядром Linux.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
strace [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-p <PID> (підключитися до процесу), -e <syscall> (фільтр викликів), -c (зведена статистика часу), -f (відстежувати дочірні потоки), -o <файл> (запис логу)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `strace` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 strace` або аліас `uman strace`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ strace -c ls -la  # Підрахунок часу та кількості викликів ядра для команди ls
$ strace -e openat,read,write -p 1234  # Трасування операцій відкриття файлів та I/O активного процесу
```
