# 📖 sar(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `sysstat`  
> **Оригінальний виклик**: `man 1 sar`

---

## 🎯 НАЗВА (NAME)
**`sar`** — System Activity Reporter — інструмент збору, збереження та аналізу історичної статистики активності системи (CPU, RAM, диск, мережа).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
sar [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-u [інтервал] [кількість] (CPU), -r (пам'ять), -b (I/O), -n DEV (мережева статистика), -q (довжина черги процесів)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `sar` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 sar` або аліас `uman sar`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sar -u 1 5  # Вимірювання завантаження CPU щосекунди протягом 5 циклів
$ sar -r 1 3  # Перегляд поточної статистики використання пам'яті та кешу
```
