## 🎯 НАЗВА (NAME)
**`qwen`** — Командний інтерфейс до моделей Qwen 2.5 Coder для інспекції коду, генерації unit-тестів та оптимізації алгоритмів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
qwen [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-i (інтерактивно), --file <файл>, --lang <мова>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `qwen` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 qwen` або аліас `uman qwen`.

$ qwen  # Запуск консольної сесії Qwen Code
