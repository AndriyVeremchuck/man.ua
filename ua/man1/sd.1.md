# 📖 sd(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `sd`  
> **Оригінальний виклик**: `man 1 sd`

---

## 🎯 НАЗВА (NAME)
**`sd`** — Інтуїтивна, зручна та швидка заміна команди sed на Rust із підтримкою регулярних виразів JavaScript/Rust та простою заміною рядків.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
sd [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-s / --string-mode (простий пошук без regex), -f / --flags <прапорці>, <пошук> <заміна> [файли]`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `sd` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 sd` або аліас `uman sd`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sd "http://" "https://" config.json  # Миттєва безпечна заміна рядків у файлі
$ sd '([0-9]{4})-([0-9]{2})' '$2/$1' dates.txt  # Заміна дат за групами регулярних виразів
```
