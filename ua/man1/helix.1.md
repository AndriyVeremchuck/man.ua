# 📖 helix(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `helix`  
> **Оригінальний виклик**: `man 1 helix`

---

## 🎯 НАЗВА (NAME)
**`helix`** — Сучасний модальний текстовий редактор на Rust, натхненний Kakoune/Neovim, із вбудованою підтримкою Tree-sitter, LSP та множинних курсорів без плагінів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
helix [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--health [мова] (діагностика LSP), -g / --grammar <fetch/build>, <файли>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `helix` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 helix` або аліас `uman helix`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ hx .  # Відкриття проєкту в редакторі Helix із вбудованим файловим навігатором
$ hx --health rust  # Перевірка працездатності LSP сервера rust-analyzer у Helix
```
