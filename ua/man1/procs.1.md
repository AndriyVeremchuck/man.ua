# 📖 procs(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `procs`  
> **Оригінальний виклик**: `man 1 procs`

---

## 🎯 НАЗВА (NAME)
**`procs`** — Сучасна заміна стандартної утиліти ps на Rust: кольорове відображення, дерево процесів, інформація про мережеві порти, пам'ять та Docker.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
procs [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--tree (дерево процесів), --sortd <cpu/mem>, --watch (автооновлення), --pager <auto/always/never>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `procs` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 procs` або аліас `uman procs`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ procs --tree  # Візуальне дерево батьківських та дочірніх процесів із використанням пам'яті
$ procs python  # Пошук усіх активних процесів Python із PID, користувачем та портами
```
