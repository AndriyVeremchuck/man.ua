# 📖 visudo(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `sudo`  
> **Оригінальний виклик**: `man 1 visudo`

---

## 🎯 НАЗВА (NAME)
**`visudo`** — Безпечне редагування конфігураційного файлу привілеїв /etc/sudoers із синтаксичною перевіркою перед збереженням.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
visudo [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-c (лише перевірити синтаксис файлу без редагування), -f <файл>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `visudo` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 visudo` або аліас `uman visudo`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo visudo  # Безпечно відредагувати конфігурацію sudoers
$ sudo visudo -c  # Перевірити синтаксичну коректність файлу /etc/sudoers
```
