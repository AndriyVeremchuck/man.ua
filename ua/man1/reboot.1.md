# 📖 reboot(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `systemd`  
> **Оригінальний виклик**: `man 1 reboot`

---

## 🎯 НАЗВА (NAME)
**`reboot`** — Перезавантаження операційної системи.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
reboot [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-f (примусово), --halt`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `reboot` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 reboot` або аліас `uman reboot`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ systemctl reboot  # Безпечне перезавантаження системи через systemd
```
