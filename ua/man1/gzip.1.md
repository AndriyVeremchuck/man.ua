# 📖 gzip(1) — Українська системна документація

> **Пакет**: `gzip`

---

## 🎯 НАЗВА (NAME)
**`gzip`** — Швидке блочне стиснення окремих файлів за алгоритмом Deflate у формат .gz.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
gzip [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-k (зберегти оригінальний файл), -9 (максимальне стиснення), -d (декомпресія), -v (прогрес)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `gzip` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ gzip -k9 access.log  # Стиснути файл логу з максимальним рівнем стиснення
```
