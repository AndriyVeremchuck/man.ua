# 📖 gum(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `gum`  
> **Оригінальний виклик**: `man 1 gum`

---

## 🎯 НАЗВА (NAME)
**`gum`** — Набір стильних та гламурних TUI компонентів для Shell-скриптів від Charm: підтвердження (confirm), меню вибору (choose), спінери, ввід тексту.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
gum [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`confirm "<питання>", choose <варіанти>, input --placeholder="...", spin --title="..." -- <команда>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `gum` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 gum` або аліас `uman gum`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ gum confirm "Бажаєте продовжити збірку?" && echo "Так"  # Інтерактивний гарний діалог підтвердження в терміналі
$ CHOICE=$(gum choose "Розробка" "Тестування" "Продакшн")  # Інтерактивне TUI меню вибору варіантів зі стрілками
```
