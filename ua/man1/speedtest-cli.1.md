# 📖 speedtest-cli(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `speedtest-cli`  
> **Оригінальний виклик**: `man 1 speedtest-cli`

---

## 🎯 НАЗВА (NAME)
**`speedtest-cli`** — Консольний клієнт для швидкого тестування пропускної здатності інтернет-каналу (Ping, Download, Upload) через сервери Speedtest.net.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
speedtest-cli [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--simple (короткий звіт), --share (посилання на графічний результат), --bytes (вивід у МБ/с), --list (список серверів)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `speedtest-cli` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 speedtest-cli` або аліас `uman speedtest-cli`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ speedtest-cli --simple  # Швидка перевірка пінгу та швидкості завантаження інтернету
$ speedtest-cli --share  # Повне тестування з генерацією посилання на зображення результату
```
