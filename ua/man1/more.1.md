# 📖 more(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `util-linux`  
> **Оригінальний виклик**: `man 1 more`

---

## 🎯 НАЗВА (NAME)
**`more`** — Класичний простий посторінковий фільтр для читання тексту у прямому напрямку.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
more [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-d (підказки навігації), -f (рахувати логічні рядки), +<номер_рядка>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `more` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 more` або аліас `uman more`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ more README.md  # Посторінковий перегляд документації
```
