# 📖 psselect(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `psutils`  
> **Оригінальний виклик**: `man 1 psselect`

---

## 🎯 НАЗВА (NAME)
**`psselect`** — Вибір, фільтрація та зміна порядку сторінок у документах PostScript (парні/непарні сторінки, окремі номери).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
psselect [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-p<номери_сторінок>, -e (тільки парні сторінки), -o (тільки непарні сторінки), -r (зворотний порядок)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `psselect` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 psselect` або аліас `uman psselect`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ psselect -p1-10 document.ps extract.ps  # Вилучення перших 10 сторінок із документа PostScript
$ psselect -o document.ps odd_pages.ps  # Виділення всіх непарних сторінок для двостороннього друку
```
