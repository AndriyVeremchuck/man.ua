# 📖 ipython(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `ipython`  
> **Оригінальний виклик**: `man 1 ipython`

---

## 🎯 НАЗВА (NAME)
**`ipython`** — Потужна інтерактивна командна оболонка для Python з підсвічуванням синтаксису, автодоповненням Tab та магічними командами %timeit, %run.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ipython [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--pylab, --matplotlib, -c "<код>", --profile=<профіль>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ipython` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ipython` або аліас `uman ipython`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ipython  # Запуск інтерактивної консолі Python для швидкого тестування коду
$ ipython -c "%timeit sum(range(1000000))"  # Точне бенчмаркінг-тестування швидкодії виразу
```
