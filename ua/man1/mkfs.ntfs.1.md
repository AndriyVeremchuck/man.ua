# 📖 mkfs.ntfs(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `ntfs-3g`  
> **Оригінальний виклик**: `man 1 mkfs.ntfs`

---

## 🎯 НАЗВА (NAME)
**`mkfs.ntfs`** — Створення та форматування розділів у файлову систему Microsoft Windows NTFS із підтримкою ACL та стиснення.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
mkfs.ntfs [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-Q / --fast (швидке форматування без перевірки секторів), -L <мітка>, -f (примусово)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `mkfs.ntfs` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 mkfs.ntfs` або аліас `uman mkfs.ntfs`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo mkfs.ntfs -Q -L "WindowsData" /dev/sdb1  # Швидке форматування розділу у файлову систему NTFS
$ sudo mkfs.ntfs -L "BackupNTFS" /dev/sdc1  # Повне форматування розділу під резервні копії для Windows
```
