# 📖 aplay(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `alsa-utils`  
> **Оригінальний виклик**: `man 1 aplay`

---

## 🎯 НАЗВА (NAME)
**`aplay`** — Консольний програвач аудіо для прямого відтворення звукових файлів WAV та сирих PCM потоків безпосередньо через драйвери ALSA.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
aplay [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-l (список звукових карт), -D <пристрій>, -r <частота>, -f <формат>, -c <канали>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `aplay` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 aplay` або аліас `uman aplay`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ aplay -l  # Перегляд переліку фізичних аудіопристроїв та виходів ALSA
$ aplay notification.wav  # Пряме відтворення звукового сигналу через консоль
```
