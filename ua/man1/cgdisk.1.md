# 📖 cgdisk(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `gptfdisk`  
> **Оригінальний виклик**: `man 1 cgdisk`

---

## 🎯 НАЗВА (NAME)
**`cgdisk`** — Псевдографічний TUI-редактор на базі бібліотеки curses для швидкої, зручної та безпечної розмітки GPT дисків.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
cgdisk [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`<пристрій>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `cgdisk` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 cgdisk` або аліас `uman cgdisk`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo cgdisk /dev/nvme0n1  # Зручна візуальна розмітка розділів GPT на SSD накопичувачі
$ sudo cgdisk /dev/sdb  # Керування розділами на новому жорсткому диску
```
