# 📖 rmmod(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `kmod`  
> **Оригінальний виклик**: `man 1 rmmod`

---

## 🎯 НАЗВА (NAME)
**`rmmod`** — Низькорівневе примусове вивантаження вказаного неактивного модуля з пам'яті ядра Linux без перевірки конфігураційних файлів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
rmmod [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-f (примусове вивантаження), -v (детальний вивід), -s (надсилати помилки у syslog)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `rmmod` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 rmmod` або аліас `uman rmmod`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo rmmod -v pcspkr  # Вивантаження модуля системного динаміка (beeper)
$ sudo rmmod -v uvcvideo  # Вивантаження модуля драйвера USB веб-камери
```
