# 📖 losetup(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `util-linux`  
> **Оригінальний виклик**: `man 1 losetup`

---

## 🎯 НАЗВА (NAME)
**`losetup`** — Налаштування та керування віртуальними блоковими пристроями loop (/dev/loop*), що дозволяють монтувати файли-образи дисків (.iso, .img, .raw).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
losetup [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-a (список усіх підключених loop-пристроїв), -f (знайти перший вільний loop-пристрій), -d <device> (відключити пристрій), -P (автоматично сканувати таблицю розділів)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `losetup` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 losetup` або аліас `uman losetup`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo losetup -Pf archlinux.iso  # Підключення ISO-образу як блокового пристрою з розділами
$ losetup -a  # Перегляд активних підключених віртуальних дисків
```
