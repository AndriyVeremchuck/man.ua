# 📖 glab(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `glab`  
> **Оригінальний виклик**: `man 1 glab`

---

## 🎯 НАЗВА (NAME)
**`glab`** — Офіційний інструмент командного рядка для сервісу GitLab для керування репозиторіями, Issue, Merge Requests та перегляду пайплайнів CI/CD.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
glab [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`mr <list/create/view>, ci <status/view/trace>, issue <list/create>, repo <clone/fork>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `glab` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 glab` або аліас `uman glab`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ glab mr list  # Перегляд списку відкритих Merge Requests у поточному проєкті
$ glab ci status  # Перевірка поточного статусу пайплайну CI/CD у GitLab
```
