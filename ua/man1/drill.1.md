# 📖 drill(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `ldns`  
> **Оригінальний виклик**: `man 1 drill`

---

## 🎯 НАЗВА (NAME)
**`drill`** — Швидкий та сучасний DNS-інструмент для діагностики доменних імен, перевірки DNSSEC ланцюжків та трасування авторитетних серверів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
drill [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-S (перевірка DNSSEC), -T (трасування від кореневих серверів), -p <порт>, @<DNS_сервер>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `drill` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 drill` або аліас `uman drill`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ drill cachyos.org @1.1.1.1  # DNS-запит до сервера Cloudflare
$ drill -S -k root.keys archlinux.org  # Повна криптографічна валідація DNSSEC записів
```
