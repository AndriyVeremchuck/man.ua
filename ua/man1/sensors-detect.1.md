# 📖 sensors-detect(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `lm_sensors`  
> **Оригінальний виклик**: `man 1 sensors-detect`

---

## 🎯 НАЗВА (NAME)
**`sensors-detect`** — Інтерактивний майстер сканування шин I2C та ISA для виявлення апаратних сенсорних чипів моніторингу напруги, кулерів і температур.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
sensors-detect [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--auto (автоматичне сканування без зайвих запитань)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `sensors-detect` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 sensors-detect` або аліас `uman sensors-detect`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo sensors-detect  # Покроковий майстер підключення драйверів сенсорів материнської плати
$ sensors  # Зчитування поточних температур процесора, чипсета та напруги
```
