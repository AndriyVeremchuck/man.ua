# 📖 systemd-cgls(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `systemd`  
> **Оригінальний виклик**: `man 1 systemd-cgls`

---

## 🎯 НАЗВА (NAME)
**`systemd-cgls`** — Рекурсивне деревоподібне відображення структури всіх процесів системи за їхніми контрольними групами (Control Groups v2 / cgroups).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
systemd-cgls [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--all, -u <юніт> (фільтр за сервісом), --no-pager`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `systemd-cgls` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 systemd-cgls` або аліас `uman systemd-cgls`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ systemd-cgls  # Перегляд ієрархії запущених сервісів, сесій користувачів та їх процесів
$ systemd-cgls -u plasma-kwin_wayland.service  # Огляд процесів віконного менеджера KDE KWin
```
