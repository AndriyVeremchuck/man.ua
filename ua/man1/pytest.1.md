# 📖 pytest(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `pytest (Python ~/.local/bin)`  
> **Оригінальний виклик**: `man 1 pytest`

---

## 🎯 НАЗВА (NAME)
**`pytest`** — Зрілий, потужний та зручний фреймворк для написання та виконання модульних (unit) та інтеграційних тестів у Python.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pytest [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-v (детально), -k <фільтр_назви>, -s (вивід print), --tb=short`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pytest` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pytest` або аліас `uman pytest`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ pytest -v  # Запуск усіх тестів у поточному проекті з детальним звітом
$ pytest -k 'test_api'  # Запуск тестів, що містять test_api в назві
```
