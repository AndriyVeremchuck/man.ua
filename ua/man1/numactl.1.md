# 📖 numactl(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `numactl`  
> **Оригінальний виклик**: `man 1 numactl`

---

## 🎯 НАЗВА (NAME)
**`numactl`** — Керування політиками виділення пам'яті та прив'язкою процесів до вузлів NUMA (Non-Uniform Memory Access) на багатопроцесорних платформах.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
numactl [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--hardware (інформація про топологію NUMA), --cpunodebind=<вузли>, --membind=<вузли>, --interleave=<вузли> (чергування пам'яті)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `numactl` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 numactl` або аліас `uman numactl`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ numactl --hardware  # Перегляд доступних NUMA-вузлів, ядер та обсягів пам'яті
$ numactl --interleave=all ./database_server  # Рівномірний розподіл пам'яті між усіма NUMA-нодами
```
