# 📖 npx(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `nodejs / npm`  
> **Оригінальний виклик**: `man 1 npx`

---

## 🎯 НАЗВА (NAME)
**`npx`** — Запуск будь-яких пакетів Node.js та CLI-інструментів безпосередньо з реєстру NPM без попереднього встановлення.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
npx [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-y (автопідтвердження), -p <пакет>, -c '<команда>'`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `npx` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 npx` або аліас `uman npx`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ npx create-vite my-app --template react-ts  # Створення нового проекту Vite React TypeScript
$ npx serve -s dist -l 3000  # Швидкий локальний HTTP-сервер для статичного сайту
```
