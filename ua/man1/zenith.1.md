# 📖 zenith(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `zenith`  
> **Оригінальний виклик**: `man 1 zenith`

---

## 🎯 НАЗВА (NAME)
**`zenith`** — Графічний TUI монітор системних ресурсів на Rust із графіками завантаження CPU, RAM, мережі, дискового I/O та виділеною секцією GPU Nvidia.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
zenith [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-r <мс> (частота оновлення), --disable-gpu, --graphics`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `zenith` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 zenith` або аліас `uman zenith`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ zenith  # Запуск панелі моніторингу системи з графіками навантаження GPU Nvidia
$ zenith -r 500  # Швидке оновлення метрик двічі на секунду
```
