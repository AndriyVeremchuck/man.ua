# 📖 ffmpeg(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `ffmpeg`  
> **Оригінальний виклик**: `man 1 ffmpeg`

---

## 🎯 НАЗВА (NAME)
**`ffmpeg`** — Універсальний перетворювач, транскодер та мультимедійний комбайн для обробки аудіо та відео.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ffmpeg [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-i <вхідний_файл>, -c:v <кодек_відео>, -c:a <кодек_аудіо>, -crf <рівень_якості>, -vn (без відео)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ffmpeg` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ffmpeg` або аліас `uman ffmpeg`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ffmpeg -i input.mp4 -c:v libx265 -crf 24 output.mp4  # Високоефективне стиснення відео кодеком HEVC (H.265)
$ ffmpeg -i video.mp4 -vn -c:a libmp3lame output.mp3  # Вилучення аудіодоріжки у формат MP3
```
