# 📖 timeshift(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `timeshift`  
> **Оригінальний виклик**: `man 1 timeshift`

---

## 🎯 НАЗВА (NAME)
**`timeshift`** — Система створення автоматичних та ручних знімків стану операційної системи (RSYNC / BTRFS) для миттєвого відновлення працездатності Linux.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
timeshift [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--check (створити знімок якщо заплановано), --create --comments "<текст>", --restore, --list (список знімків), --delete`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `timeshift` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 timeshift` або аліас `uman timeshift`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo timeshift --create --comments "Перед оновленням ядра"  # Створення контрольної точки відновлення системи
$ sudo timeshift --list  # Перегляд усіх існуючих знімків системи та зайнятого місця
```
