# 📖 ncmpcpp(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `ncmpcpp`  
> **Оригінальний виклик**: `man 1 ncmpcpp`

---

## 🎯 НАЗВА (NAME)
**`ncmpcpp`** — Потужний текстовий TUI музичний програвач для Music Player Daemon (MPD) із плейлистами, редактором тегів та спектром частот.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ncmpcpp [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-h <хост_mpd>, -p <порт>, -s <екран>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ncmpcpp` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ncmpcpp` або аліас `uman ncmpcpp`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ncmpcpp  # Запуск музичного TUI плеєра для MPD
$ ncmpcpp -s visualizer  # Відкриття візуалізатора спектра музики
```
