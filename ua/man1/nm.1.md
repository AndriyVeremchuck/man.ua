# 📖 nm(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `binutils`  
> **Оригінальний виклик**: `man 1 nm`

---

## 🎯 НАЗВА (NAME)
**`nm`** — Утиліта з пакету GNU Binutils для перегляду та витягування таблиці символів (функцій, змінних, класів) з об'єктних файлів, .a та .so бібліотек.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
nm [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-C (demangle імен C++), -D (тільки динамічні символи), -u (тільки невизначені символи), -g (тільки експортовані глобальні символи), -n (числове сортування за адресою)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `nm` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 nm` або аліас `uman nm`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ nm -D -C /usr/lib/libm.so  # Перегляд читабельних математичних функцій у математичній бібліотеці libm
$ nm -u my_object.o  # Пошук зовнішніх нерозв'язаних символів перед компонуванням
```
