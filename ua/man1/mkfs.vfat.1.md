## 🎯 НАЗВА (NAME)
**`mkfs.vfat`** — Форматування розділів у файлову систему FAT32 (VFAT) для створення завантажувальних EFI System Partition (ESP) та сумісних USB-флешок.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
mkfs.vfat [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-F 32 (режим FAT32), -n <мітка> (назва тому, до 11 символів), -I (дозволити на весь диск)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `mkfs.vfat` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 mkfs.vfat` або аліас `uman mkfs.vfat`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo mkfs.vfat -F 32 -n "BOOT" /dev/nvme0n1p1  # Форматування системного розділу завантаження EFI у FAT32
$ sudo mkfs.vfat -F 32 -n "FLASH" /dev/sdb1  # Форматування флешки для сумісності з будь-якими пристроями
```
