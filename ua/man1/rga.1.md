# 📖 rga(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `ripgrep-all`  
> **Оригінальний виклик**: `man 1 rga`

---

## 🎯 НАЗВА (NAME)
**`rga`** — Розширення ripgrep для пошуку тексту всередині PDF-документів, файлів DOCX, EPUB, електронних книг, архівів ZIP/TAR та відеосубтитрів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
rga [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--rga-adapters=<адаптери>, --rga-cache, -i (ігнорувати регістр), -C <N> (контекстні рядки)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `rga` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 rga` або аліас `uman rga`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ rga "податкова накладна" ~/Документи/  # Пошук тексту всередині всіх PDF та Word файлів у папці
$ rga "Exception" app.zip  # Пошук помилок безпосередньо всередині архіву ZIP
```
