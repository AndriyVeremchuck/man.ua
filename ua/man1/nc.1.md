# 📖 nc(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `openbsd-netcat`  
> **Оригінальний виклик**: `man 1 nc`

---

## 🎯 НАЗВА (NAME)
**`nc`** — Мережевий швейцарський ніж для перевірки портів, передачі сирих потоків та створення простих серверів/клієнтів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
nc [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-z (режим сканування), -v (детально), -w <таймаут>, -l -p <порт> (слухати)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `nc` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 nc` або аліас `uman nc`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ nc -zvw3 google.com 443  # Швидка перевірка доступності порту 443
```
