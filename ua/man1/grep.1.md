# 📖 grep(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Оригінальний виклик**: `man 1 grep`

---

## 🎯 НАЗВА (NAME)
**`grep`** — Пошук рядків за регулярними виразами та шаблонами у файлах

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
grep [OPTIONS] PATTERN [FILE...]
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `grep` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 grep` або аліас `uman grep`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ grep -rn 'TODO' .
$ cat log | grep -i 'error'
```
