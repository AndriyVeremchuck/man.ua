# 📖 grep(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `grep`  
> **Оригінальний виклик**: `man 1 grep`

---

## 🎯 НАЗВА (NAME)
**`grep`** — Пошук рядків, що відповідають регулярному виразу або ключовому слову, у файлах та конвеєрах.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
grep [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-r (рекурсивний пошук у папках), -i (ігнорувати регістр букв), -n (показувати номер рядка), -E (розширений regex), -v (інверсія збігу)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `grep` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 grep` або аліас `uman grep`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ grep -rnI "TODO" ./src/  # Рекурсивний пошук коментарів TODO з номерами рядків
$ grep -v "^#" config.conf  # Вивести конфігурацію без рядків коментарів
```
