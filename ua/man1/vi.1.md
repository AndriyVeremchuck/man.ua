# 📖 vi(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `vi / vim`  
> **Оригінальний виклик**: `man 1 vi`

---

## 🎯 НАЗВА (NAME)
**`vi`** — Стандартний системний текстовий редактор POSIX, наявний у будь-якому дистрибутиві Linux та аварійних середовищах.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
vi [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-R (лише для читання), +<рядок>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `vi` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 vi` або аліас `uman vi`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ vi /etc/fstab  # Редагування таблиці монтування дисків
```
