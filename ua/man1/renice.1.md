# 📖 renice(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `util-linux`  
> **Оригінальний виклик**: `man 1 renice`

---

## 🎯 НАЗВА (NAME)
**`renice`** — Динамічна зміна пріоритету планувальника для вже працюючих процесів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
renice [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-n <новий_пріоритет>, -p <PID>, -u <користувач>, -g <група_процесів>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `renice` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 renice` або аліас `uman renice`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo renice -n -5 -p 1234  # Підвищити пріоритет працюючого процесу з PID 1234
```
