# 📖 dprint(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `dprint`  
> **Оригінальний виклик**: `man 1 dprint`

---

## 🎯 НАЗВА (NAME)
**`dprint`** — Модульний ультрашвидкий форматер вихідного коду на Rust із плагінами для TypeScript, JavaScript, JSON, Markdown, Dockerfile та TOML.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
dprint [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`fmt (форматування файлів), check (перевірка форматування), init (ініціалізація dprint.json)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `dprint` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 dprint` або аліас `uman dprint`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ dprint fmt  # Миттєве паралельне форматування всіх файлів у проєкті
$ dprint check  # Перевірка дотримання стилю коду у пайплайнах CI
```
