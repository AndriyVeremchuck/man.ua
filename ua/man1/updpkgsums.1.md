# 📖 updpkgsums(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `pacman-contrib`  
> **Оригінальний виклик**: `man 1 updpkgsums`

---

## 🎯 НАЗВА (NAME)
**`updpkgsums`** — Автоматичне завантаження вихідних файлів та оновлення масиву контрольних сум (sha256sums) у файлі PKGBUILD.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
updpkgsums [OPTIONS] [ARGUMENTS...]
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `updpkgsums` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 updpkgsums` або аліас `uman updpkgsums`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ updpkgsums  # Оновлення контрольних сум для вихідного коду в поточному PKGBUILD
$ updpkgsums my_package/PKGBUILD  # Генерація хешів для конкретного PKGBUILD файлу
```
