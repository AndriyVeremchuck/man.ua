# 📖 dart(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `Dart SDK (/opt/flutter/bin/dart)`  
> **Оригінальний виклик**: `man 1 dart`

---

## 🎯 НАЗВА (NAME)
**`dart`** — Командний інтерфейс мови Dart для компіляції AOT/JIT, запуску скриптів, керування пакетами pub та форматування коду.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
dart [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`run <скрипт>, format <шлях>, analyze, compile exe <файл.dart>, pub get`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `dart` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 dart` або аліас `uman dart`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ dart format .  # Автоматичне форматування коду Dart за стандартами Effective Dart
$ dart compile exe bin/main.dart  # Компіляція Dart у самодостатній нативний бінарник
```
