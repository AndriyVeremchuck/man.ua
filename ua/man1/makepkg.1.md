# 📖 makepkg(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `pacman`  
> **Оригінальний виклик**: `man 1 makepkg`

---

## 🎯 НАЗВА (NAME)
**`makepkg`** — Офіційна утиліта Arch Linux для компіляції, перевірки залежностей та збірки бінарних пакунків (.pkg.tar.zst) із файлів інструкцій PKGBUILD.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
makepkg [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-s / --syncdeps (автоматично встановити залежності), -i / --install (встановити зібраний пакет), -C / --clean (очистити директорію src), -f / --force (перезаписати пакет)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `makepkg` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 makepkg` або аліас `uman makepkg`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ makepkg -si  # Збірка програми з PKGBUILD та автоматичне встановлення в систему
$ makepkg -f --nocheck  # Примусова збірка без прогону модульних тестів
```
