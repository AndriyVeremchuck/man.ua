# 📖 jq(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `jq`  
> **Оригінальний виклик**: `man 1 jq`

---

## 🎯 НАЗВА (NAME)
**`jq`** — Потужний командний JSON-процесор, парсер та фільтр для обробки і форматування структурованих даних.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
jq [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`. (форматувати JSON), -r (raw вивід рядків без лапок), -c (компактний рядок), -s (читати весь вхід)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `jq` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 jq` або аліас `uman jq`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ echo '{"status":"ok","code":200}' | jq  # Форматувати та підсвітити кольором JSON рядок
```
