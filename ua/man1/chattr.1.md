# 📖 chattr(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `e2fsprogs`  
> **Оригінальний виклик**: `man 1 chattr`

---

## 🎯 НАЗВА (NAME)
**`chattr`** — Зміна спеціальних атрибутів файлів для захисту від випадкового видалення або зміни (+i / +a).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
chattr [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`+i (заборонити будь-які зміни навіть для root), -i (зняти захист), +a (дозволити тільки дописування), -R (рекурсивно)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `chattr` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 chattr` або аліас `uman chattr`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo chattr +i critical_config.conf  # Заблокувати файл від видалення або перезапису
```
