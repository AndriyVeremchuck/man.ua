# 📖 yay(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `yay`  
> **Оригінальний виклик**: `man 1 yay`

---

## 🎯 НАЗВА (NAME)
**`yay`** — Найпопулярніший та найшвидший AUR-хелпер та обгортка для pacman на мові Go.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
yay [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-Syu (повне оновлення з AUR), -S <пакет>, -Ss <пошук>, -Ps (статистика), -Yc (очищення невикористовуваних залежностей)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `yay` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 yay` або аліас `uman yay`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ yay -Syu  # Повне синхронне оновлення офіційних пакунків та програм з AUR
$ yay -Ss google-chrome  # Пошук програми в базі AUR
```
