# 📖 viddy(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `viddy`  
> **Оригінальний виклик**: `man 1 viddy`

---

## 🎯 НАЗВА (NAME)
**`viddy`** — Сучасна заміна утиліти watch на Rust із можливістю перемотування історії попередніх запусків, підсвічуванням різниці та кольоровим терміналом.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
viddy [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-n <секунди> (інтервал), -d (підсвічування диффів), --bell (сигнал при зміні виводу)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `viddy` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 viddy` або аліас `uman viddy`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ viddy -n 1 "nvidia-smi"  # Моніторинг стану відеокарти з можливістю перегляду історії через Time Machine
$ viddy -d "ip a"  # Відстеження змін мережевих адрес з підсвічуванням нових параметрів
```
