# 📖 nvim(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `neovim`  
> **Оригінальний виклик**: `man 1 nvim`

---

## 🎯 НАЗВА (NAME)
**`nvim`** — Високопродуктивний розширюваний модальний текстовий редактор коду на базі Vim з підтримкою Lua та LSP.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
nvim [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`<файл>, +<номер_рядка>, -u <конфіг>, -d (порівняння diff двох файлів)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `nvim` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 nvim` або аліас `uman nvim`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ nvim ~/.config/fish/config.fish  # Відкрити файл конфігурації у редакторі Neovim
```
