# 📖 fallocate(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `util-linux`  
> **Оригінальний виклик**: `man 1 fallocate`

---

## 🎯 НАЗВА (NAME)
**`fallocate`** — Швидке виділення реального дискового простору для файлу на рівні файлової системи без фізичного заповнення нулями (posix_fallocate).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
fallocate [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-l <довжина> (розмір у байтах: 512M, 4G), -n (зарезервувати місце без збільшення довжини), -d (вивільнити нульові блоки / deallocate)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `fallocate` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 fallocate` або аліас `uman fallocate`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ fallocate -l 4G /swapfile  # Миттєве виділення 4 ГБ суцільного простору для файлу підкачки (swap)
$ fallocate -l 100G game_cache.bin  # Попереднє резервування дискового простору для уникнення фрагментації
```
