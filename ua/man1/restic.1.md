# 📖 restic(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `restic`  
> **Оригінальний виклик**: `man 1 restic`

---

## 🎯 НАЗВА (NAME)
**`restic`** — Швидка, безпечна та надійна система резервного копіювання з криптографічним шифруванням даних, дедуплікацією блоків та підтримкою S3/SFTP.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
restic [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`backup <папки> (створення знімка), snapshots (список знімків), restore <id> --target <папка>, check (перевірка репозиторію)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `restic` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 restic` або аліас `uman restic`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ restic -r /media/backup/repo backup ~/Projects  # Створення дедуплікованого шифрованого бекапу проєктів
$ restic -r /media/backup/repo snapshots  # Перегляд історії резервних копій у репозиторії
```
