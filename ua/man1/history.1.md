# 📖 history(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `shell builtin`  
> **Оригінальний виклик**: `man 1 history`

---

## 🎯 НАЗВА (NAME)
**`history`** — Перегляд та пошук у хронологічній історії раніше виконаних команд термінала.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
history [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-c (очистити історію), -d <номер_запису>, -w (записати в файл)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `history` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 history` або аліас `uman history`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ history | grep git | tail -n 15  # Пошук останніх 15 виконаних команд Git
```
