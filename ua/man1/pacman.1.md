# 📖 pacman(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `pacman`  
> **Оригінальний виклик**: `man 1 pacman`

---

## 🎯 НАЗВА (NAME)
**`pacman`** — Офіційний менеджер пакунків Arch Linux / CachyOS для встановлення, повного оновлення та керування залежностями.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pacman [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-Syu (повне оновлення системи), -S <пакет> (встановити), -Rns (повне видалення з залежностями), -Ss (пошук), -Qi (інфо)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pacman` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pacman` або аліас `uman pacman`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo pacman -Syu  # Повне оновлення всіх пакунків та ядра CachyOS
$ pacman -Ss ripgrep  # Пошук пакунка в репозиторіях
```
