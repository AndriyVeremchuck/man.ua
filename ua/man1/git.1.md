# 📖 git(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Оригінальний виклик**: `man 1 git`

---

## 🎯 НАЗВА (NAME)
**`git`** — Розподілена система керування версіями вихідного коду

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
git [--version] [--help] [-C <path>] <command> [<args>]
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `git` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 git` або аліас `uman git`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ git status
$ git commit -m 'Docs update'
$ git push
```
