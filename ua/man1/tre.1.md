# 📖 tre(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `tre-command`  
> **Оригінальний виклик**: `man 1 tre`

---

## 🎯 НАЗВА (NAME)
**`tre`** — Покращена сучасна версія утиліти tree на Rust, що автоматично створює тимчасові цифрові аліаси для кожного показаного файлу.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
tre [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-a (всі файли), -l <глибина>, -e (тільки редаговані), -s (розміри)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `tre` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 tre` або аліас `uman tre`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ tre  # Побудова дерева файлів із числовими ярликами (e.g. e 1 для відкриття файлу)
$ tre -l 2  # Дерево на 2 рівні вкладеності
```
