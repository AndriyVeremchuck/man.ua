# 📖 xxd(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `vim`  
> **Оригінальний виклик**: `man 1 xxd`

---

## 🎯 НАЗВА (NAME)
**`xxd`** — Створення детальних шістнадцяткових (hex) дампів бінарних даних або зворотне перетворення hex-тексту назад у вихідний бінарний файл.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
xxd [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-p (простий безперервний hex дамп), -r (зворотне перетворення з hex у бінарник), -c <N> (кількість байт у рядку), -g <N> (групування байт), -l <N> (обмеження довжини)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `xxd` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 xxd` або аліас `uman xxd`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ xxd -l 64 /bin/ls  # Шістнадцятковий перегляд перших 64 байт бінарника з ASCII-колонкою
$ echo "48656c6c6f" | xxd -r -p  # Зворотне декодування hex-рядка у текст (Hello)
```
