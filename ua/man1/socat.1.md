# 📖 socat(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `socat`  
> **Оригінальний виклик**: `man 1 socat`

---

## 🎯 НАЗВА (NAME)
**`socat`** — Багатофункціональний ретранслятор потоків даних (SOcket CAT) для з'єднання між двома незалежними джерелами: TCP, UDP, сокети UNIX, TTY, файли.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
socat [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-v (виводити передані дані на екран), -d -d (рівень налагодження), TCP-LISTEN:<порт>,fork (створення прослуховувача), UNIX-CONNECT:<шлях>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `socat` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 socat` або аліас `uman socat`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ socat TCP-LISTEN:8080,fork TCP:192.168.1.10:80  # Перенаправлення локального порту 8080 на віддалений веб-сервер
$ socat - UNIX-CONNECT:/var/run/docker.sock  # Інтерактивне підключення до локального UNIX-сокету Docker
```
