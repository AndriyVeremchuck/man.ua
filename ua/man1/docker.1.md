# 📖 docker(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `docker`  
> **Оригінальний виклик**: `man 1 docker`

---

## 🎯 НАЗВА (NAME)
**`docker`** — Провідна індустріальна платформа контейнеризації для створення, розгортання та керування ізольованими додатками в середовищі Linux.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
docker [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`ps (список контейнерів), run (запуск контейнера), exec -it (інтерактивний термінал), build (збірка образу), images (список образів), logs (перегляд логів)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `docker` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 docker` або аліас `uman docker`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ docker ps -a  # Перегляд усіх активних та зупинених контейнерів у системі
$ docker run -d --name nginx-server -p 8080:80 nginx:alpine  # Фоновий запуск веб-сервера Nginx у контейнері
```
