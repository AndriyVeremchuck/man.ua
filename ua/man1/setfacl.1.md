# 📖 setfacl(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `acl`  
> **Оригінальний виклик**: `man 1 setfacl`

---

## 🎯 НАЗВА (NAME)
**`setfacl`** — Встановлення та модифікація розширених списків контролю доступу (POSIX ACL).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
setfacl [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-m (додати/змінити правило), -x (видалити правило), -R (рекурсивно), -b (очистити всі ACL)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `setfacl` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 setfacl` або аліас `uman setfacl`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ setfacl -m u:dusha:rwx /var/www/html  # Надати персональні права читання/запису/виконання користувачу dusha
```
