# 📖 usermod(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `shadow`  
> **Оригінальний виклик**: `man 1 usermod`

---

## 🎯 НАЗВА (NAME)
**`usermod`** — Модифікація параметрів існуючого облікового запису користувача (групи, оболонка, домашній каталог).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
usermod [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-aG <групи> (додати групи без видалення старих), -s <нова_оболонка>, -l <новий_логін>, -L (заблокувати)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `usermod` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 usermod` або аліас `uman usermod`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo usermod -aG wheel,docker dusha  # Додати користувача dusha до груп wheel та docker
```
