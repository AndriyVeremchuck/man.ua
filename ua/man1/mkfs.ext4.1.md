## 🎯 НАЗВА (NAME)
**`mkfs.ext4`** — Створення та форматування розділів у журнальовану файлову систему Linux ext4 із можливістю налаштування розміру інодів та міток.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
mkfs.ext4 [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-L <мітка> (встановлення мітки тому), -m <відсоток> (резерв простору для root, наприклад 1), -F (примусове форматування)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `mkfs.ext4` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 mkfs.ext4` або аліас `uman mkfs.ext4`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo mkfs.ext4 -L "DataDrive" -m 1 /dev/sdb1  # Форматування розділу в ext4 з міткою DataDrive та 1% резерву
$ sudo mkfs.ext4 -O fast_commit /dev/nvme0n1p4  # Форматування з увімкненням опції fast_commit для швидких NVMe
```
