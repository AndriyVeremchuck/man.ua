# 📖 tcpdump(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `tcpdump`  
> **Оригінальний виклик**: `man 1 tcpdump`

---

## 🎯 НАЗВА (NAME)
**`tcpdump`** — Потужний аналізатор мережевих протоколів та перехоплювач сирих мережевих пакетів у реальному часі зі збереженням у формат PCAP.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
tcpdump [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-i <інтерфейс> (вибір мережевої карти, any для всіх), -n (не резолвити IP у хости), -nn (не резолвити порти), -w <файл.pcap> (запис у файл), -r <файл.pcap> (читання файлу)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `tcpdump` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 tcpdump` або аліас `uman tcpdump`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo tcpdump -i any -nn port 80 or port 443  # Перехоплення всього HTTP/HTTPS трафіку на всіх інтерфейсах
$ sudo tcpdump -i eth0 -w capture.pcap -c 1000  # Запис 1000 пакетів у файл для подальшого аналізу у Wireshark
```
