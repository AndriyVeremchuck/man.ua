# 📖 xh(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `xh`  
> **Оригінальний виклик**: `man 1 xh`

---

## 🎯 НАЗВА (NAME)
**`xh`** — Дружній, швидкий та кольоровий інструмент відправки HTTP-запитів на Rust (сучасний швидкий аналог curl та HTTPie).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
xh [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-v / --verbose (заголовки та тіло), --json, --auth <user:pass>, --bearer <token>, -d / --download`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `xh` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 xh` або аліас `uman xh`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ xh get https://httpbin.org/json  # Відправка GET-запиту з красивим кольоровим JSON-виводом
$ xh post https://api.example.com/users name="Dusha" role="admin"  # Швидка відправка JSON payload через аргументи
```
