# 📖 tr(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 tr`

---

## 🎯 НАЗВА (NAME)
**`tr`** — Трансляція, заміна та видалення символів у вхідному потоці даних.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
tr [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-d (видалити зазначені символи), -s (стиснути повторювані символи в один), -c (доповнення набору)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `tr` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 tr` або аліас `uman tr`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ cat text.txt | tr 'a-z' 'A-Z'  # Перетворити всі малі літери у великі
$ cat file.txt | tr -d ''  # Видалити символи повернення каретки Windows CRLF
```
