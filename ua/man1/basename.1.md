# 📖 basename(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 basename`

---

## 🎯 НАЗВА (NAME)
**`basename`** — Вилучення чистого імені файлу або останнього компонента шляху з можливістю видалення суфікса.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
basename [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-s <суфікс>, -a (кілька аргументів), -z`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `basename` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 basename` або аліас `uman basename`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ basename /usr/bin/fish .fish  # Отримати ім'я бінарника 'fish' без розширення
$ basename /etc/systemd/system.conf  # Отримати чисте ім'я файлу
```
