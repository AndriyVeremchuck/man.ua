# 📖 bzz(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `djvulibre`  
> **Оригінальний виклик**: `man 1 bzz`

---

## 🎯 НАЗВА (NAME)
**`bzz`** — Спеціалізований компресор та декомпресор алгоритму BZZ (Burrows-Wheeler Transform + Huffman) для текстових та інформаційних блоків DjVu.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
bzz [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-e <вхідний> <стиснений> (стиснення), -d <стиснений> <розпакований> (декомпресія)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `bzz` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 bzz` або аліас `uman bzz`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ bzz -e ocr_layer.txt ocr_layer.bz  # Стиснення текстового шару алгоритмом BZZ перед вбудовуванням у DjVu
$ bzz -d ocr_layer.bz unpacked.txt  # Розпакування внутрішнього блоку BZZ
```
