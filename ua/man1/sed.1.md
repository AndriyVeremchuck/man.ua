# 📖 sed(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `sed`  
> **Оригінальний виклик**: `man 1 sed`

---

## 🎯 НАЗВА (NAME)
**`sed`** — Потоковий текстовий редактор для автоматичної заміни слів, фільтрації та пакетного перетворення тексту.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
sed [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-i (редагувати файл на місці), -e <скрипт>, -n (придушити автоматичний вивід)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `sed` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 sed` або аліас `uman sed`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sed -i 's/localhost/127.0.0.1/g' config.yaml  # Автоматична заміна 'localhost' на '127.0.0.1' у файлі
```
