# 📖 meson(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `meson`  
> **Оригінальний виклик**: `man 1 meson`

---

## 🎯 НАЗВА (NAME)
**`meson`** — Сучасна, швидка та зручна система автоматизації збірки на Python/Ninja для великих системних проєктів GNOME, Mesa, PipeWire та systemd.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
meson [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`setup <папка_збірки>, compile -C <папка_збірки>, test -C <папка_збірки>, install -C <папка_збірки>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `meson` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 meson` або аліас `uman meson`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ meson setup build --buildtype=release  # Конфігурація оптимізованої релізної збірки проєкту
$ meson compile -C build  # Швидка паралельна компіляція коду
```
