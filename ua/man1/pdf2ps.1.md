# 📖 pdf2ps(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `ghostscript`  
> **Оригінальний виклик**: `man 1 pdf2ps`

---

## 🎯 НАЗВА (NAME)
**`pdf2ps`** — Конвертація документів PDF у мову розмітки сторінок PostScript для сумісності зі старішими друкарськими машинами та RIP.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pdf2ps [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-dLanguageLevel=3, <вхідний.pdf> [вихідний.ps]`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pdf2ps` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pdf2ps` або аліас `uman pdf2ps`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ pdf2ps document.pdf document.ps  # Перетворення документа PDF у формат PostScript
$ pdf2ps -dLanguageLevel=2 doc.pdf doc_ps2.ps  # Генерація PostScript рівня 2 для апаратних принтерів
```
