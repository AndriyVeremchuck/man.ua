# 📖 md5sum(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 md5sum`

---

## 🎯 НАЗВА (NAME)
**`md5sum`** — Швидке обчислення та перевірка 128-бітних контрольних сум алгоритму MD5 для верифікації цілісності завантажених файлів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
md5sum [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-c <файл> (перевірка файлу контрольних сум), -b (бінарний режим), --quiet (виводити тільки помилки), --status (тиха перевірка)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `md5sum` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 md5sum` або аліас `uman md5sum`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ md5sum disk_image.iso  # Обчислення контрольної суми MD5 образу диска
$ md5sum -c md5list.txt  # Перевірка цілісності списку файлів за їхніми контрольними сумами
```
