# 📖 chwd(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `chwd`  
> **Оригінальний виклик**: `man 1 chwd`

---

## 🎯 НАЗВА (NAME)
**`chwd`** — CachyOS Hardware Detection — фірмова утиліта CachyOS для автоматичного розпізнавання обладнання та встановлення оптимізованих графічних драйверів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
chwd [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-l (список підтримуваних профілів драйверів), -a (автоматичне встановлення драйверів), -i <профіль> (встановлення профілю), -r <профіль> (видалення)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `chwd` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 chwd` або аліас `uman chwd`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ chwd -l  # Перегляд доступних профілів драйверів CachyOS (Nvidia, AMD, Intel)
$ sudo chwd -a  # Автоматичне встановлення найновіших оптимізованих відеодрайверів для поточної системи
```
