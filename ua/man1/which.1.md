# 📖 which(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `which`  
> **Оригінальний виклик**: `man 1 which`

---

## 🎯 НАЗВА (NAME)
**`which`** — Визначення точного абсолютного шляху до виконуваного файлу, що запуститься в поточній сесії $PATH.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
which [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-a (показати всі знайдені шляхи в $PATH)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `which` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 which` або аліас `uman which`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ which konsole fish flutter  # Дізнатися точний системний шлях до бінарника
```
