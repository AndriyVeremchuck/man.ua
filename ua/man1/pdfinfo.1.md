# 📖 pdfinfo(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `poppler`  
> **Оригінальний виклик**: `man 1 pdfinfo`

---

## 🎯 НАЗВА (NAME)
**`pdfinfo`** — Миттєве отримання вичерпних метаданих та технічних параметрів PDF: версія, кількість сторінок, розміри в точках та мм, шифрування, автор.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pdfinfo [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-meta (повні XML метадані XMP), -js (наявність JavaScript), -struct (перевірка тегованого PDF)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pdfinfo` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pdfinfo` або аліас `uman pdfinfo`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ pdfinfo document.pdf  # Перегляд загальних метаданих, кількості сторінок та розміру аркушів
$ pdfinfo -meta document.pdf  # Виведення розширених метаданих XMP
```
