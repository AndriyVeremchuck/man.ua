# 📖 scrcpy(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `scrcpy`  
> **Оригінальний виклик**: `man 1 scrcpy`

---

## 🎯 НАЗВА (NAME)
**`scrcpy`** — Високопродуктивне відображення та керування екраном Android-пристроїв через USB/Wi-Fi (ADB) з низькою затримкою.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
scrcpy [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-m <розмір> (обмеження роздільної здатності), -b <бітрейт> (наприклад 8M), --always-on-top, --record <файл.mp4>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `scrcpy` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 scrcpy` або аліас `uman scrcpy`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ scrcpy  # Запуск дзеркалювання підключеного Android-смартфона
$ scrcpy --always-on-top --window-title "Мій Телефон"  # Відображення вікна поверх усіх додатків
$ scrcpy --record screen.mp4  # Запис екрана пристрою безпосередньо у відеофайл
```
