# 📖 yazi(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `yazi`  
> **Оригінальний виклик**: `man 1 yazi`

---

## 🎯 НАЗВА (NAME)
**`yazi`** — Ультрасучасний термінальний файловий менеджер на Rust з неблокуючим асинхронним I/O, плавною прокруткою та підтримкою вбудованого прев'ю картинок.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
yazi [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--cwd-file=<файл>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `yazi` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 yazi` або аліас `uman yazi`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ yazi  # Запуск ультрашвидкого термінального файлового навігатора
$ yazi ~/Зображення  # Перегляд папки картинок із миттєвим рендерингом прев'ю
```
