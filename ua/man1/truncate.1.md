# 📖 truncate(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 truncate`

---

## 🎯 НАЗВА (NAME)
**`truncate`** — Миттєве скорочення, розширення або повне обнулення розміру файлу до вказаного ліміту без зміни його вмісту та відкриття в редакторі.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
truncate [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-s <розмір> (новий розмір: 0, 10M, 2G), -c (не створювати файл, якщо він відсутній), -r <файл> (встановити розмір як у файлу-зразка)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `truncate` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 truncate` або аліас `uman truncate`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ truncate -s 0 large_debug.log  # Миттєве очищення (обнулення) лог-файлу без видалення самого файлу
$ truncate -s 10G virtual_disk.raw  # Створення розрідженого (sparse) файлу віртуального диска розміром 10 ГБ
```
