# 📖 hdparm(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `hdparm`  
> **Оригінальний виклик**: `man 1 hdparm`

---

## 🎯 НАЗВА (NAME)
**`hdparm`** — Конфігурація та тестування швидкодії накопичувачів SATA/IDE HDD та SSD: тест швидкості читання, увімкнення кешування, режим сну.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
hdparm [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-Tt (тест швидкості буферизованого читання), -I (повна ідентифікація параметрів диска), -y (перевести диск у режим сну), -B <1-255> (APM живлення)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `hdparm` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 hdparm` або аліас `uman hdparm`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo hdparm -Tt /dev/sda  # Вимірювання реальної швидкості читання з кешу та диска
$ sudo hdparm -I /dev/sda  # Перегляд апаратних можливостей, серійного номера та прошивки накопичувача
```
