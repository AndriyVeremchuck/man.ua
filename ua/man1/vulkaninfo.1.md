# 📖 vulkaninfo(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `vulkan-tools`  
> **Оригінальний виклик**: `man 1 vulkaninfo`

---

## 🎯 НАЗВА (NAME)
**`vulkaninfo`** — Повна діагностика графічного API Vulkan: список фізичних GPU-пристроїв, версії драйверів, черги рендерингу та підтримувані розширення (Vulkan extensions).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
vulkaninfo [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--summary (короткий зведений звіт), -o <файл.html> (експорт звіту в HTML)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `vulkaninfo` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 vulkaninfo` або аліас `uman vulkaninfo`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ vulkaninfo --summary  # Короткий огляд підтримки Vulkan API та властивостей GPU
$ vulkaninfo | grep -E "deviceName|driverVersion"  # Визначення точної моделі відеокарти та версії драйвера Vulkan
```
