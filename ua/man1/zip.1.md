# 📖 zip(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `zip`  
> **Оригінальний виклик**: `man 1 zip`

---

## 🎯 НАЗВА (NAME)
**`zip`** — Створення кросплатформних ZIP-архівів із підтримкою рекурсивного стиснення та шифрування.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
zip [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-r (рекурсивно для папок), -q (тихий режим), -9 (максимальне стиснення), -e (пароль)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `zip` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 zip` або аліас `uman zip`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ zip -r project.zip ./src/  # Створити zip-архів з усім вмістом папки src
```
