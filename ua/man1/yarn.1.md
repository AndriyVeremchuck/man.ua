# 📖 yarn(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `yarn`  
> **Оригінальний виклик**: `man 1 yarn`

---

## 🎯 НАЗВА (NAME)
**`yarn`** — Швидкий, надійний та безпечний менеджер пакетів для JavaScript екосистеми з кешуванням та детермінованим блокуванням версій yarn.lock.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
yarn [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`install, add <пакет>, build, upgrade`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `yarn` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 yarn` або аліас `uman yarn`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ yarn install  # Встановлення модулів за фіксованими версіями yarn.lock
$ yarn add -D typescript  # Додавання TypeScript у секцію devDependencies
```
