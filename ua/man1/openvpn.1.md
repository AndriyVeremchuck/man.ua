# 📖 openvpn(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `openvpn`  
> **Оригінальний виклик**: `man 1 openvpn`

---

## 🎯 НАЗВА (NAME)
**`openvpn`** — Повнофункціональний кросплатформний клієнт та сервер захищених віртуальних приватних мереж (VPN) на базі протоколів SSL/TLS.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
openvpn [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--config <файл.ovpn>, --daemon, --status <файл> <сек>, --verb <рівень>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `openvpn` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 openvpn` або аліас `uman openvpn`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo openvpn --config client.ovpn  # Підключення до VPN за наданим конфігураційним файлом .ovpn
$ sudo openvpn --config client.ovpn --daemon  # Запуск VPN з'єднання у фоновому режимі демона
```
