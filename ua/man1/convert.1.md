# 📖 convert(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `imagemagick`  
> **Оригінальний виклик**: `man 1 convert`

---

## 🎯 НАЗВА (NAME)
**`convert`** — Потужний інструмент ImageMagick для зміни формату, розміру, кадрування, накладання фільтрів та колірної корекції зображень.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
convert [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-resize <розмір> (1920x1080, 50%), -quality <1-100>, -crop <геометрія>, -strip (видалення метаданих)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `convert` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 convert` або аліас `uman convert`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ convert input.png -resize 50% -quality 85 output.webp  # Зменшення роздільності вдвічі та конвертація у WebP
$ convert image.jpg -strip optimized.jpg  # Очищення зображення від зайвих метаданих для зменшення ваги
```
