# 📖 watchexec(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `watchexec`  
> **Оригінальний виклик**: `man 1 watchexec`

---

## 🎯 НАЗВА (NAME)
**`watchexec`** — Утиліта на Rust для автоматичного перезапуску вказаної команди при виявленні будь-яких змін у файлах або директоріях поточного проєкту.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
watchexec [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-e <розширення: py,rs,js>, -r (перезапускати активний процес), -c (очищати екран), -w <папка>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `watchexec` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 watchexec` або аліас `uman watchexec`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ watchexec -e py,html "python3 apps-catalog.py"  # Автоматична перебудова каталогу при будь-якому редагуванні Python чи HTML файлів
$ watchexec -r "cargo run"  # Перезапуск програми Rust при зміні сирців
```
