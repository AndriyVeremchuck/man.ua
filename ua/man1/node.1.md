# 📖 node(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `nodejs`  
> **Оригінальний виклик**: `man 1 node`

---

## 🎯 НАЗВА (NAME)
**`node`** — Кросплатформне асинхронне середовище виконання коду JavaScript на базі високопродуктивного рушія V8 від Google.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
node [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-e "<код>" (виконання рядка), -v (версія), --watch (автоматичний перезапуск при змінах коду), --inspect (порт налагодження)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `node` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 node` або аліас `uman node`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ node server.js  # Запуск серверного додатку JavaScript
$ node --watch app.js  # Запуск додатку з нативним автоматичним перезапуском при збереженні файлів
```
