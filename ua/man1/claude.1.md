# 📖 claude(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `Claude Code (~/.local/bin/claude)`  
> **Оригінальний виклик**: `man 1 claude`

---

## 🎯 НАЗВА (NAME)
**`claude`** — Автономний агентний AI-інструмент від Anthropic для роботи безпосередньо в терміналі з проектами, тестами та Git.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
claude [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--version, -p "<запит>", --dangerously-skip-permissions`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `claude` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 claude` або аліас `uman claude`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ claude  # Запуск інтерактивного агента Claude Code в поточному каталозі
```
