# 📖 sort(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 sort`

---

## 🎯 НАЗВА (NAME)
**`sort`** — Сортування рядків текстових файлів (за алфавітом, числами, версіями чи розмірами).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
sort [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-n (числове сортування), -r (зворотний порядок), -k <номер_колонки>, -u (вилучати дублікати), -h (людино-зрозумілі розміри)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `sort` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 sort` або аліас `uman sort`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sort -n -k2 data.txt  # Числове сортування файлу за значенням другого стовпця
```
