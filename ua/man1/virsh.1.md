# 📖 virsh(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `libvirt`  
> **Оригінальний виклик**: `man 1 virsh`

---

## 🎯 НАЗВА (NAME)
**`virsh`** — Головний інструмент командного рядка для керування гіпервізором KVM/QEMU, віртуальними машинами, мережами та сховищами libvirt.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
virsh [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`list --all (список усіх VM), start <ім'я> (запуск VM), shutdown (вимкнення), dominfo (деталі про VM), console (консоль VM)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `virsh` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 virsh` або аліас `uman virsh`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ virsh list --all  # Перегляд статусу всіх віртуальних машин KVM/QEMU
$ virsh start win11_vm  # Запуск віртуальної машини Windows 11
```
