# 📖 chmod(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 chmod`

---

## 🎯 НАЗВА (NAME)
**`chmod`** — Зміна прав доступу файлової системи Linux (читання r, запис w, виконання x).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
chmod [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`+x (виконання), 600 (тільки власник), 755 (виконуваний для всіх), -R (рекурсивно)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `chmod` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 chmod` або аліас `uman chmod`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ chmod +x script.sh  # Зробити скрипт виконуваним
$ chmod 600 ~/.ssh/id_ed25519  # Встановити безпечні приватні права на SSH-ключ
```
