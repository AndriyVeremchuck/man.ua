# 📖 useradd(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `shadow`  
> **Оригінальний виклик**: `man 1 useradd`

---

## 🎯 НАЗВА (NAME)
**`useradd`** — Низькорівнева утиліта створення нового облікового запису користувача з прапорцями конфігурації.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
useradd [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-m (створити домашній каталог), -s <оболонка>, -aG <додаткові_групи>, -r (системний акаунт)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `useradd` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 useradd` або аліас `uman useradd`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo useradd -m -s /usr/bin/fish developer  # Створити користувача з домашньою папкою та Fish shell
```
