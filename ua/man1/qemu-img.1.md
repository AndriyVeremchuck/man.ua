---

## 🎯 НАЗВА (NAME)
**`qemu-img`** — Утиліта створення, конвертації, перевірки та зміни розміру образів віртуальних дисків різних форматів: QCOW2, RAW, VMDK, VDI, VHDX.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
qemu-img [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`create -f <формат> <файл> <розмір>, convert -f <вхід> -O <вихід>, info <файл>, resize <файл> <+розмір>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `qemu-img` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 qemu-img` або аліас `uman qemu-img`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ qemu-img create -f qcow2 linux_disk.qcow2 50G  # Створення динамічного розрідженого образу диска QCOW2 на 50 ГБ
$ qemu-img info disk.qcow2  # Перегляд реального розміру на диску та віртуального обсягу образу
```
