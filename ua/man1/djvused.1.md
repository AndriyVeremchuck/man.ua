# 📖 djvused(1) — Українська системна документація

> **Пакет**: `djvulibre`

---

## 🎯 НАЗВА (NAME)
**`djvused`** — Потужний скриптовий редактор та інспектор змісту DjVu: додавання закладок, анотацій, гіперпосилань, текстових шарів та метаданих.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
djvused [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-e "<команда_djvused>", -f <файл_скрипту>, -s (зберегти зміни)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `djvused` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 djvused` або аліас `uman djvused`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ djvused book.djvu -e "print-outline"  # Виведення дерева закладок та змісту (Table of Contents) книги DjVu
$ djvused book.djvu -e "print-meta" -s  # Перегляд та експорт метаданих (автор, назва, дата видання)
```
