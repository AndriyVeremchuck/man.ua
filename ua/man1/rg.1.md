# 📖 rg(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `ripgrep`  
> **Оригінальний виклик**: `man 1 rg`

---

## 🎯 НАЗВА (NAME)
**`rg`** — Ультрашвидкий пошуковий інструмент на Rust з автоматичним ігноруванням .gitignore та бінарних файлів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
rg [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-i (без урахування регістру), -g <глоб_шаблон>, -w (цілі слова), --json`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `rg` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 rg` або аліас `uman rg`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ rg -i "error" /var/log/  # Блискавичний пошук слова 'error' у системних логах
```
