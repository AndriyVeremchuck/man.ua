# 📖 route(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `net-tools`  
> **Оригінальний виклик**: `man 1 route`

---

## 🎯 НАЗВА (NAME)
**`route`** — Перегляд та конфігурація таблиці IP-маршрутизації ядра Linux.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
route [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-n (числові адреси без резолвінгу DNS), -v (детально)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `route` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 route` або аліас `uman route`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ route -n  # Показати поточну таблицю маршрутизації ядра
```
