# 📖 gallery-dl(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `gallery-dl`  
> **Оригінальний виклик**: `man 1 gallery-dl`

---

## 🎯 НАЗВА (NAME)
**`gallery-dl`** — Потужний CLI-інструмент для автоматичного пакетного завантаження фотогалерей та зображень із сотень популярних веб-ресурсів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
gallery-dl [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-d <каталог> (папка збереження), --write-metadata, -u <user> -p <pass>, --filter <умова>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `gallery-dl` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 gallery-dl` або аліас `uman gallery-dl`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ gallery-dl "https://website.com/gallery/12345"  # Пакетне завантаження всіх оригіналів зображень з альбому
$ gallery-dl --write-metadata https://image-post-url  # Завантаження з супутнім збереженням опису та тегів
```
