# 📖 nmap(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `nmap`  
> **Оригінальний виклик**: `man 1 nmap`

---

## 🎯 НАЗВА (NAME)
**`nmap`** — Еталонний інструмент дослідження мереж та аудиту безпеки: сканування відкритих портів, виявлення запущених служб та версій ОС.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
nmap [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-sS (приховане TCP SYN сканування), -sV (визначення версій сервісів), -O (визначення ОС), -p <порти> (діапазон портів, -p- для всіх 65535), -A (комплексний аудит)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `nmap` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 nmap` або аліас `uman nmap`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ nmap -sV -p 22,80,443 192.168.1.1  # Сканування стандартних портів та версій служб на роутері
$ sudo nmap -sn 192.168.1.0/24  # Швидке виявлення всіх активних пристроїв у локальній мережі (Ping sweep)
```
