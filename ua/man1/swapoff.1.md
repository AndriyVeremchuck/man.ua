# 📖 swapoff(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `util-linux`  
> **Оригінальний виклик**: `man 1 swapoff`

---

## 🎯 НАЗВА (NAME)
**`swapoff`** — Безпечне вимкнення та скидання використання розділів або файлів підкачки Swap.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
swapoff [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-a (вимкнути всі активні swap), -v (детально)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `swapoff` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 swapoff` або аліас `uman swapoff`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo swapoff -a && sudo swapon -a  # Скидання та перезапуск swap-підкачки
```
