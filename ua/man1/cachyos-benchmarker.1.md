# 📖 cachyos-benchmarker(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `cachyos-benchmarker`  
> **Оригінальний виклик**: `man 1 cachyos-benchmarker`

---

## 🎯 НАЗВА (NAME)
**`cachyos-benchmarker`** — Фірмовий інструмент CachyOS для проведення стандартизованих бенчмарків швидкодії ядра, процесора, пам'яті та планувальника BORE.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
cachyos-benchmarker [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--help, --all`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `cachyos-benchmarker` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 cachyos-benchmarker` або аліас `uman cachyos-benchmarker`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ cachyos-benchmarker  # Запуск інтерактивного тестування продуктивності системи
$ cachyos-benchmarker --all  # Повний цикл тестування обчислювальної потужності
```
