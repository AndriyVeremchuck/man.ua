# 📖 nmon(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `nmon`  
> **Оригінальний виклик**: `man 1 nmon`

---

## 🎯 НАЗВА (NAME)
**`nmon`** — Комплексний системний монітор Nigel's Monitor для відстеження на одному екрані CPU, пам'яті, мережі, дисків, файлових систем та ядра.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
nmon [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-f (запис даних у файл для побудови звітів), -s <сек>, -c <кількість_знімків>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `nmon` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 nmon` або аліас `uman nmon`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ nmon  # Запуск інтерактивного монітора (натисніть c - процесор, m - пам'ять, d - диски, n - мережа)
$ nmon -f -s 10 -c 60  # Запис профілю навантаження системи протягом 10 хвилин у файл
```
