# 📖 hddtemp(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `hddtemp`  
> **Оригінальний виклик**: `man 1 hddtemp`

---

## 🎯 НАЗВА (NAME)
**`hddtemp`** — Компактна утиліта моніторингу поточної температури жорстких дисків HDD та SSD накопичувачів на основі даних S.M.A.R.T.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
hddtemp [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-u <C/F> (шкала Цельсія або Фаренгейта), -q (тихий вивід), -d (запуск у режимі демона)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `hddtemp` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 hddtemp` або аліас `uman hddtemp`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo hddtemp /dev/sda  # Зчитування поточної температури диска /dev/sda
$ sudo hddtemp /dev/sd?  # Перевірка температур усіх підключених накопичувачів
```
