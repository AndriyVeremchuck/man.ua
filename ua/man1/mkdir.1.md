# 📖 mkdir(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 mkdir`

---

## 🎯 НАЗВА (NAME)
**`mkdir`** — Створення нових каталогів та директорій (включно зі створенням ланцюжків батьківських папок).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
mkdir [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-p (створити батьківські), -v (звітувати про кожну папку), -m <права>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `mkdir` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 mkdir` або аліас `uman mkdir`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ mkdir -p ./projects/my_app/src  # Створити каталог разом з усіма батьківськими підпапками
$ mkdir -v folder1 folder2  # Створення кількох папок одночасно
```
