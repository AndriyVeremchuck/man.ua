# 📖 trip(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `trippy`  
> **Оригінальний виклик**: `man 1 trip`

---

## 🎯 НАЗВА (NAME)
**`trip`** — Передовий TUI діагностичний інструмент мережевого трасування на Rust, що об'єднує функції traceroute, ping та mtr із гнучкою візуалізацією.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
trip [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-p <протокол: icmp, udp, tcp>, -m <макс_хопів>, -u (непривілейований режим), -c <пакетів>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `trip` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 trip` або аліас `uman trip`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ trip google.com  # Інтерактивне TUI трасування мережевих затримок та втрат пакетів до Google
$ trip -p tcp --target-port 443 1.1.1.1  # TCP-трасування маршруту через HTTPS порт
```
