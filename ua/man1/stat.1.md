# 📖 stat(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 stat`

---

## 🎯 НАЗВА (NAME)
**`stat`** — Виведення детальних низькорівневих метаданих про файл або файлову систему (inode, розмір, права, дати).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
stat [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-c <формат>, -f (стан файлової системи), -t (компактний вивід)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `stat` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 stat` або аліас `uman stat`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ stat /etc/passwd  # Повний звіт про розмір, права доступу, inode та час зміни файлу
$ stat -f /  # Показати метадані кореневої файлової системи Btrfs
```
