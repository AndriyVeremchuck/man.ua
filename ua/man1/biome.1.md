# 📖 biome(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `biome`  
> **Оригінальний виклик**: `man 1 biome`

---

## 🎯 НАЗВА (NAME)
**`biome`** — Високопродуктивний єдиний тулчейн для веб-розробки на Rust (наступник Rome): лінтер, форматер та компілятор JavaScript/TypeScript.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
biome [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`format --write <шлях>, lint <шлях>, check --apply <шлях>, ci`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `biome` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 biome` або аліас `uman biome`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ biome check --apply .  # Автоматичне виправлення помилок лінтера та форматування коду проєкту
$ biome format --write src/  # Швидке форматування всіх файлів у папці src
```
