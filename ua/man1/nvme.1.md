# 📖 nvme(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `nvme-cli`  
> **Оригінальний виклик**: `man 1 nvme`

---

## 🎯 НАЗВА (NAME)
**`nvme`** — Офіційна утиліта керування та діагностики накопичувачів NVMe SSD: стан зносу пам'яті, температура, журнал помилок та форматування.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
nvme [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`list (список NVMe дисків), smart-log <пристрій> (перегляд здоров'я SMART), error-log, id-ctrl (інформація про контролер)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `nvme` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 nvme` або аліас `uman nvme`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo nvme list  # Перегляд підключених NVMe накопичувачів, обсягів та серійних номерів
$ sudo nvme smart-log /dev/nvme0  # Перегляд відсотка зносу пам'яті, прочитаних/записаних терабайт (TBW) та температури
```
