# 📖 hermes(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `Hermes AI (~/.local/bin/hermes)`  
> **Оригінальний виклик**: `man 1 hermes`

---

## 🎯 НАЗВА (NAME)
**`hermes`** — Консольний агентний інструмент зв'язку та оркестрації AI-моделей для вирішення складних багатокрокових завдань.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
hermes [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--status, --run, --config <шлях>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `hermes` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 hermes` або аліас `uman hermes`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ hermes  # Запуск термінального помічника Hermes
```
