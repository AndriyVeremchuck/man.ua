---

## 🎯 НАЗВА (NAME)
**`arch-chroot`** — Офіційний скрипт CachyOS/Arch, що автоматично монтує системні псевдофайлові системи (/proc, /sys, /dev, /run) і запускає chroot в цільову ОС.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
arch-chroot [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`<шлях> [команда]`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `arch-chroot` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 arch-chroot` або аліас `uman arch-chroot`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo arch-chroot /mnt  # Безпечний вхід у змонтовану систему для оновлення ядра або перевстановлення завантажувача
$ sudo arch-chroot /mnt pacman -Syu  # Оновлення пакетів у відновлюваній системі
```
