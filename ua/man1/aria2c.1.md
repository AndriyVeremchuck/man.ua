# 📖 aria2c(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `aria2`  
> **Оригінальний виклик**: `man 1 aria2c`

---

## 🎯 НАЗВА (NAME)
**`aria2c`** — Високошвидкісна багатопотокова утиліта завантаження файлів з підтримкою протоколів HTTP, HTTPS, FTP, SFTP, BitTorrent та Metalink.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
aria2c [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-x <N> (макс. з'єднань на сервер), -s <N> (кількість потоків), -j <N> (паралельних завантажень), --seed-time=<хв>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `aria2c` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 aria2c` або аліас `uman aria2c`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ aria2c -x 16 -s 16 https://example.com/large_archive.iso  # Прискорене завантаження великого файлу в 16 паралельних потоків
$ aria2c torrent_file.torrent  # Завантаження роздачі BitTorrent через консоль
```
