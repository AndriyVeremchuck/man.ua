# 📖 qpdf(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `qpdf`  
> **Оригінальний виклик**: `man 1 qpdf`

---

## 🎯 НАЗВА (NAME)
**`qpdf`** — Утиліта для низькорівневої трансформації, лінеаризації (Fast Web View), шифрування та оптимізації внутрішньої структури PDF.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
qpdf [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--linearize (оптимізація для веб-перегляду), --decrypt, --encrypt, --pages <файл> <сторінки> --`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `qpdf` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 qpdf` або аліас `uman qpdf`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ qpdf --linearize heavy_doc.pdf web_doc.pdf  # Оптимізація PDF для миттєвого відкриття першої сторінки у браузері
$ qpdf --decrypt --password=secret locked.pdf unlocked.pdf  # Зняття пароля з PDF документа
```
