# 📖 pandoc(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `pandoc-cli`  
> **Оригінальний виклик**: `man 1 pandoc`

---

## 🎯 НАЗВА (NAME)
**`pandoc`** — Універсальний швейцарський ніж для взаємної конвертації між десятками форматів розмітки: Markdown, DOCX, PDF, HTML, LaTeX, EPUB, ODT.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pandoc [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-f <вхідний_формат>, -t <вихідний_формат>, -o <вихідний_файл>, --toc (зміст), --pdf-engine=<двигун>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pandoc` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pandoc` або аліас `uman pandoc`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ pandoc README.md -o manual.pdf  # Конвертація Markdown документації у PDF файл
$ pandoc document.docx -t markdown -o document.md  # Перетворення документа Microsoft Word у чистий Markdown
```
