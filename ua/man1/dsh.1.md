# 📖 dsh(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `@deepseek-ai/dsh (NPM Global)`  
> **Оригінальний виклик**: `man 1 dsh`

---

## 🎯 НАЗВА (NAME)
**`dsh`** — Швидкий консольний AI-помічник на базі DeepSeek V3/R1 для генерації та виконання термінальних команд і скриптів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
dsh [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--model <deepseek-chat/reasoner>, -e "<завдання>"`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `dsh` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 dsh` або аліас `uman dsh`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ dsh -e "Як знайти всі сокети unix у системі?"  # Миттєва генерація точної команди Linux за описом
```
