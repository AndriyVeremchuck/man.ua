# 📖 modprobe(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `kmod`  
> **Оригінальний виклик**: `man 1 modprobe`

---

## 🎯 НАЗВА (NAME)
**`modprobe`** — Інтелектуальне завантаження та вивантаження драйверів і модулів ядра Linux з автоматичним розв'язанням дерева залежностей.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
modprobe [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-r (вивантажити модуль), -v (докладний вивід), -c (перегляд поточної конфігурації), -l (список модулів за маскою), --dry-run (тестовий запуск)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `modprobe` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 modprobe` або аліас `uman modprobe`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo modprobe -v zram  # Завантаження модуля стисненої підкачки zram у пам'ять ядра
$ sudo modprobe -r nouveau  # Безпечне вивантаження відкритого драйвера Nvidia Nouveau
```
