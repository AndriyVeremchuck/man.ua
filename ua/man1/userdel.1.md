# 📖 userdel(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `shadow`  
> **Оригінальний виклик**: `man 1 userdel`

---

## 🎯 НАЗВА (NAME)
**`userdel`** — Системна утиліта видалення облікового запису користувача з бази /etc/passwd.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
userdel [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-r (видалити домашній каталог та поштову скриньку), -f (примусово)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `userdel` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 userdel` або аліас `uman userdel`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo userdel -r testuser  # Видалити обліковий запис testuser та його каталог
```
