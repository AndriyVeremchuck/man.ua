# 📖 ls(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 ls`

---

## 🎯 НАЗВА (NAME)
**`ls`** — Перегляд списку файлів та директорій із правами доступу, розмірами та датами модифікації.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ls [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-l (довгий список), -a (всі включно з прихованими), -h (розміри у КБ/МБ), --color=auto`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ls` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ls` або аліас `uman ls`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ls -lah  # Детальний список усіх файлів з прихованими у зручному форматі
$ ls -lS  # Сортування файлів за розміром
```
