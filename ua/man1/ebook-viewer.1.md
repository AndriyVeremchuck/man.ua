# 📖 ebook-viewer(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `calibre`  
> **Оригінальний виклик**: `man 1 ebook-viewer`

---

## 🎯 НАЗВА (NAME)
**`ebook-viewer`** — Запуск переглядача електронних книг Calibre для швидкого читання та перевірки макетів EPUB, MOBI, FB2, CBZ, AZW3.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ebook-viewer [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--open-at <позиція>, --detach (запуск у фоні)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ebook-viewer` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ebook-viewer` або аліас `uman ebook-viewer`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ebook-viewer book.epub  # Відкриття книги у графічному рідері Calibre
$ ebook-viewer comic.cbz  # Перегляд коміксів або манги у форматі CBZ
```
