# 📖 bat(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `bat`  
> **Оригінальний виклик**: `man 1 bat`

---

## 🎯 НАЗВА (NAME)
**`bat`** — Сучасний аналог cat на Rust з автоматичним підсвічуванням синтаксису 100+ мов та номерами рядків.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
bat [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-A (показати пробіли), -p (plain текст без рамок), -l <мова>, --theme <тема>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `bat` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 bat` або аліас `uman bat`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ bat apps-catalog.py  # Красивий перегляд вихідного коду з синтаксичною підсвіткою
$ bat -p config.yaml  # Перегляд без бічних рамок
```
