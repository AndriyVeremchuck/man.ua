# 📖 glow(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `glow`  
> **Оригінальний виклик**: `man 1 glow`

---

## 🎯 НАЗВА (NAME)
**`glow`** — Стильний термінальний переглядач Markdown документів на базі Glamour із підтримкою тем оформления, таблиць та підсвічування синтаксису коду.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
glow [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-p / --pager (посторінковий перегляд), -s <light/dark> (стиль теми), -w <ширина>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `glow` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 glow` або аліас `uman glow`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ glow README.md  # Красивий рендеринг файлу Markdown у терміналі
$ glow -p ~/Документи/  # Інтерактивний TUI браузер для перегляду всіх Markdown файлів
```
