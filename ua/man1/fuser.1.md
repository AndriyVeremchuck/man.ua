# 📖 fuser(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `psmisc`  
> **Оригінальний виклик**: `man 1 fuser`

---

## 🎯 НАЗВА (NAME)
**`fuser`** — Швидка ідентифікація та примусове завершення (kill) процесів, які утримують відкритими конкретні файли, сокети або файлові системи.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
fuser [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-v (докладний огляд процесів), -k (надіслати SIGKILL знайденим процесам), -m <точка_монтування> (для файлової системи), -n <протокол> <порт>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `fuser` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 fuser` або аліас `uman fuser`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ fuser -v /var/lib/pacman/db.lck  # Пошук процесу, який заблокував базу даних Pacman
$ sudo fuser -k -m /mnt/backup  # Примусове завершення всіх процесів, що блокують точку монтування /mnt/backup
```
