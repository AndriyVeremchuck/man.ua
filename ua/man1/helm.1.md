# 📖 helm(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `helm`  
> **Оригінальний виклик**: `man 1 helm`

---

## 🎯 НАЗВА (NAME)
**`helm`** — Пакетний менеджер для Kubernetes, що дозволяє упаковувати, версіонувати та розгортати складні багатокомпонентні додатки за допомогою Helm-чартів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
helm [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`install <ім'я> <чарт>, upgrade <ім'я> <чарт>, list (список релізів), repo add <назва> <url>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `helm` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 helm` або аліас `uman helm`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ helm list -A  # Список усіх встановлених Helm-релізів у кластері
$ helm repo update  # Оновлення локального індексу репозиторіїв чартів
```
