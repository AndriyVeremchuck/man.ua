# 📖 env(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 env`

---

## 🎯 НАЗВА (NAME)
**`env`** — Виведення списку всіх змінних середовища або запуск команди у зміненому оточенні.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
env [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-i (запустити з порожнім оточенням), -u <змінна> (вилучити змінну)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `env` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 env` або аліас `uman env`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ env | sort | head -n 25  # Показати список змінних оточення поточної сесії
```
