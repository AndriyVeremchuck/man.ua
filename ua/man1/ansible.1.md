# 📖 ansible(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `ansible`  
> **Оригінальний виклик**: `man 1 ansible`

---

## 🎯 НАЗВА (NAME)
**`ansible`** — Система автоматизації налаштування серверів, розгортання додатків та оркестрації без використання постійних агентів (через SSH).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ansible [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-m <модуль> (ping, shell, copy), -a "<аргументи>", -i <інвентар>, all (всі хости)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ansible` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ansible` або аліас `uman ansible`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ansible all -i hosts.ini -m ping  # Перевірка зв'язку та доступності всіх серверів з файлу інвентаря
$ ansible-playbook -i hosts.ini deploy.yml  # Виконання сценарію Playbook для налаштування системи
```
