# 📖 delta(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `git-delta`  
> **Оригінальний виклик**: `man 1 delta`

---

## 🎯 НАЗВА (NAME)
**`delta`** — Синтаксично підсвічений пейджер для git, diff та grep виводу на Rust. Підтримує side-by-side порівняння, номери рядків та теми оформлення.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
delta [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-s / --side-by-side (пліч-о-пліч), --line-numbers (нумерація), --syntax-theme=<тема>, --navigate`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `delta` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 delta` або аліас `uman delta`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ git diff | delta  # Красиве порівняння змін Git із кольоровим підсвічуванням синтаксису
$ delta file1.py file2.py --side-by-side  # Порівняння двох файлів у паралельних колонках
```
