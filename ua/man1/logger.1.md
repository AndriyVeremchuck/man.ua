# 📖 logger(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `util-linux`  
> **Оригінальний виклик**: `man 1 logger`

---

## 🎯 НАЗВА (NAME)
**`logger`** — Надсилання повідомлень у системний журнал syslog та systemd journal безпосередньо з командного рядка або shell-скриптів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
logger [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-p <priority> (наприклад user.err, local0.info), -t <тег> (тег програми), -s (виводити також у stderr)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `logger` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 logger` або аліас `uman logger`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ logger -t "MY_SCRIPT" -p user.notice "Скрипт резервного копіювання успішно завершено"  # Запис події у системний журнал systemd
$ logger -s -p user.err "Помилка завантаження конфігурації"  # Запис критичної помилки в лог з одночасним виводом на екран
```
