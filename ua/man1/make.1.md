# 📖 make(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `make`  
> **Оригінальний виклик**: `man 1 make`

---

## 🎯 НАЗВА (NAME)
**`make`** — Класичний інструмент автоматизації процесу компіляції та збірки програм за правилами та залежностями, описаними у файлах Makefile.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
make [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-j <потоків> (паралельна компіляція), -f <файл> (вказати Makefile), -B / --always-make (перезібрати все), -C <папка>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `make` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 make` або аліас `uman make`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ make -j$(nproc)  # Компіляція проєкту на всіх доступних ядрах процесора
$ sudo make install  # Встановлення зібраних бінарників та файлів у систему
```
