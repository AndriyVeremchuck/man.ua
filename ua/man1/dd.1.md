# 📖 dd(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `coreutils`  
> **Оригінальний виклик**: `man 1 dd`

---

## 🎯 НАЗВА (NAME)
**`dd`** — Низькорівневе порозрядне копіювання блоків даних, створення резервних копій дисків, запис ISO-образів на USB та стирання секторів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
dd [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`if=<вхідний_файл>, of=<вихідний_файл>, bs=<розмір_блоку: 4M, 1M>, status=progress (відображення прогресу), conv=fsync`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `dd` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 dd` або аліас `uman dd`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo dd if=cachyos.iso of=/dev/sdX bs=4M status=progress conv=fsync  # Прямий посекторний запис завантажувального ISO образу на флешку
$ sudo dd if=/dev/urandom of=/dev/sdX bs=1M status=progress  # Безпечне стирання накопичувача випадковими даними
```
