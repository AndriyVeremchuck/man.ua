# 📖 ssh-copy-id(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `openssh`  
> **Оригінальний виклик**: `man 1 ssh-copy-id`

---

## 🎯 НАЗВА (NAME)
**`ssh-copy-id`** — Автоматичне копіювання та встановлення вашого публічного SSH-ключа на віддалений сервер у файл authorized_keys для безпарольного входу.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ssh-copy-id [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-i <шлях_до_ключа>, -p <порт>, <користувач@хост>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ssh-copy-id` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ssh-copy-id` або аліас `uman ssh-copy-id`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ssh-copy-id user@192.168.1.100  # Встановлення ключа за замовчуванням на віддалений сервер
$ ssh-copy-id -i ~/.ssh/id_ed25519.pub -p 2222 user@server.com  # Копіювання конкретного ключа на нестандартний порт SSH
```
