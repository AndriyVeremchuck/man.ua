# 📖 pacman-key(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `pacman`  
> **Оригінальний виклик**: `man 1 pacman-key`

---

## 🎯 НАЗВА (NAME)
**`pacman-key`** — Утиліта керування криптографічним брелоком ключів GPG менеджера пакетів Pacman: ініціалізація, оновлення ключів розробників Arch/CachyOS.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pacman-key [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--init (ініціалізація брелока), --populate <archlinux/cachyos> (завантаження ключів), --refresh-keys (оновлення ключів із серверів), -l (список ключів)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pacman-key` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pacman-key` або аліас `uman pacman-key`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo pacman-key --refresh-keys  # Оновлення всіх ключів перевірки підписів репозиторіїв
$ sudo pacman-key --populate archlinux cachyos  # Імпорт офіційних довірених ключів розробників Arch та CachyOS
```
