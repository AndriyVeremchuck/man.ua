# 📖 mcedit(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `mc`  
> **Оригінальний виклик**: `man 1 mcedit`

---

## 🎯 НАЗВА (NAME)
**`mcedit`** — Швидкий та зручний консольний текстовий редактор від Midnight Commander із синтаксичною підсвіткою та макросами.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
mcedit [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`+<номер_рядка>, -b (чорно-білий), -c (кольоровий)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `mcedit` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 mcedit` або аліас `uman mcedit`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ mcedit config.yaml  # Відкрити файл конфігурації у редакторі mcedit
$ mcedit +45 /etc/fstab  # Відкрити системний файл одразу на 45-му рядку
```
