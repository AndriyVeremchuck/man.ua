# 📖 curlie(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `curlie`  
> **Оригінальний виклик**: `man 1 curlie`

---

## 🎯 НАЗВА (NAME)
**`curlie`** — Інструмент для HTTP-запитів, що поєднує людський та зручний інтерфейс HTTPie із міццю, продуктивністю та прапорцями curl.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
curlie [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`curlie [METHOD] URL [ITEMS...], -v (докладно), --json, -o <файл>, -H "Header: value"`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `curlie` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 curlie` або аліас `uman curlie`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ curlie get https://httpbin.org/json  # Виконання GET-запиту з автоматичним підсвічуванням JSON
$ curlie post https://httpbin.org/post name=Antigravity role=AI  # Відправка JSON POST-запиту з параметрами ключ=значення
```
