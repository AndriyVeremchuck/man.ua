# 📖 age(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `age`  
> **Оригінальний виклик**: `man 1 age`

---

## 🎯 НАЗВА (NAME)
**`age`** — Сучасний, простий та криптографічно безпечний інструмент шифрування файлів з підтримкою SSH-ключів (заміна застарілого GPG).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
age [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-e / --encrypt, -d / --decrypt, -r <публічний_ключ>, -R <файл_ключів_ssh>, -p (шифрування паролем)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `age` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 age` або аліас `uman age`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ age -p secrets.txt > secrets.txt.age  # Шифрування файлу надійним паролем
$ age -d secrets.txt.age > secrets.txt  # Розшифрування захищеного файлу
```
