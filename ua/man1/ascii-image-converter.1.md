## 🎯 НАЗВА (NAME)
**`ascii-image-converter`** — Швидке перетворення растрових зображень у кольоровий або монохромний ASCII арт із підтримкою колірних тем та шрифтів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ascii-image-converter [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-C / --color (кольоровий вивід), -d <розміри>, -b / --braille (символи Брайля), -f (зберегти у файл)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ascii-image-converter` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ascii-image-converter -C image.png  # Генерація красивого кольорового ASCII арту в терміналі
$ ascii-image-converter -C -b logo.jpg  # Перетворення зображення у символи Брайля високої чіткості
```
