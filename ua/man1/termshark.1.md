# 📖 termshark(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `termshark`  
> **Оригінальний виклик**: `man 1 termshark`

---

## 🎯 НАЗВА (NAME)
**`termshark`** — Повноцінний термінальний інтерфейс TUI для аналізатора мережевих пакетів Wireshark (tshark) із трьохвіконним макетом та фільтрами.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
termshark [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-i <інтерфейс>, -r <файл.pcap>, -Y "<display_filter>", -d (рівень налагодження)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `termshark` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 termshark` або аліас `uman termshark`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo termshark -i eth0  # Інтерактивний перегляд та аналіз мережевого трафіку в реальному часі
$ termshark -r capture.pcap  # Відкриття та фільтрація збереженого дампа пакетів у консолі
```
