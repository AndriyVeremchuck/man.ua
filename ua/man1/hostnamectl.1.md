# 📖 hostnamectl(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `systemd`  
> **Оригінальний виклик**: `man 1 hostnamectl`

---

## 🎯 НАЗВА (NAME)
**`hostnamectl`** — Керування мережевим ім'ям хоста (hostname), перегляд повної інформації про ядро, архітектуру, версію ОС CachyOS та тип віртуалізації.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
hostnamectl [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`status (поточний статус хоста), set-hostname <нове_ім'я>, --static, --transient, --pretty`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `hostnamectl` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 hostnamectl` або аліас `uman hostnamectl`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ hostnamectl status  # Перегляд версії ядра, дистрибутива, моделі материнської плати та шасі
$ sudo hostnamectl set-hostname cachyos-workstation  # Встановлення постійного мережевого імені комп'ютера
```
