# 📖 ss(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `iproute2`  
> **Оригінальний виклик**: `man 1 ss`

---

## 🎯 НАЗВА (NAME)
**`ss`** — Швидкий сучасний аналізатор відкритих TCP/UDP сокетів, з'єднань та прослуховуваних портів.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ss [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-tulpn (прослуховувані порти TCP/UDP з PID), -s (зведена статистика), -t (лише TCP), -u (лише UDP)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ss` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 ss` або аліас `uman ss`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ ss -tulpn  # Список усіх відкритих портів та назв процесів
$ ss -s  # Зведена статистика активних мережевих сокетів
```
