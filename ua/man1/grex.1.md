# 📖 grex(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `grex`  
> **Оригінальний виклик**: `man 1 grex`

---

## 🎯 НАЗВА (NAME)
**`grex`** — Генератор оптимізованих регулярних виразів (Regex) із наданого набору прикладів вхідних рядків.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
grex [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-d (цифрові класи), -w (словесні класи), -s (пробільні символи), -i (ігнорувати регістр)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `grex` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 grex` або аліас `uman grex`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ grex a.jpg b.png c.webp  # Автоматична генерація точного регулярного виразу для переліку файлів
$ grex -d 2023-01-01 2024-12-31  # Генерація regex шаблону для розпізнавання дат
```
