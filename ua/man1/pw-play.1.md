# 📖 pw-play(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `pipewire-utils`  
> **Оригінальний виклик**: `man 1 pw-play`

---

## 🎯 НАЗВА (NAME)
**`pw-play`** — Нативна консольна утиліта прямого відтворення аудіо через PipeWire сервер без зайвої передискретизації (Bit-Perfect Pro-Audio playback).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pw-play [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`--target <node_id> (вихідний пристрій), --volume <0.0-1.0>, --rate <Гц>, --channels <N>, --latency <мс>`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `pw-play` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 pw-play` або аліас `uman pw-play`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ pw-play --volume 0.8 audio.flac  # Пряме відтворення FLAC через PipeWire із гучністю 80%
$ pw-play --latency 64/48000 master.wav  # Відтворення аудіо з наднизькою затримкою Pro-Audio
```
