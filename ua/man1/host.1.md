# 📖 host(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `bind`  
> **Оригінальний виклик**: `man 1 host`

---

## 🎯 НАЗВА (NAME)
**`host`** — Проста та швидка утиліта з пакету bind для виконання DNS-запитів, визначення IP-адрес хостів, MX поштових серверів та зворотного резолвінгу.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
host [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-t <тип> (тип запису: A, AAAA, MX, TXT, CNAME, NS), -a (всі доступні DNS записи), -v (докладний режим)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `host` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 host` або аліас `uman host`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ host -t MX cachyos.org  # Перегляд поштових серверів (MX-записів) для домену cachyos.org
$ host 8.8.8.8  # Зворотний DNS-пошук доменного імені за його IP-адресою (PTR)
```
