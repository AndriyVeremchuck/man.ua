# 📖 strings(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `binutils`  
> **Оригінальний виклик**: `man 1 strings`

---

## 🎯 НАЗВА (NAME)
**`strings`** — Видобування та виведення всіх послідовностей друкованих символів довжиною від 4 знаків з бінарних, об'єктних файлів або пам'яті.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
strings [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-n <довжина> (мін. кількість символів), -t <format> (зміщення у файлі: d/o/x), -e <encoding> (кодування: s/S/b/l), -a (сканувати весь файл)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `strings` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 strings` або аліас `uman strings`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ strings -n 8 /usr/bin/grep | grep -i "version"  # Пошук рядків версії всередині бінарника grep
$ strings -t x firmware.bin | head -n 20  # Виведення текстових констант з шістнадцятковим зміщенням
```
