# 📖 psbook(1) — Українська системна документація

> **Розділ 1**: Виконувані програми та команди оболонки  
> **Пакет**: `psutils`  
> **Оригінальний виклик**: `man 1 psbook`

---

## 🎯 НАЗВА (NAME)
**`psbook`** — Автоматичне перевпорядкування сторінок PostScript для друку брошур та книг зі згинанням навпіл (буклетний спуск смуг).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
psbook [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-s<кількість_сторінок_у_зошиті>, <вхідний.ps> [вихідний.ps]`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `psbook` належить до **Розділу 1** системної документації Linux (*Користувацькі утиліти, командні оболонки, текстові процесори, компілятори*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 1 psbook` або аліас `uman psbook`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ psbook manual.ps booklet.ps  # Спуск смуг для друку брошури зі згинанням по центру
$ psbook -s16 big_book.ps signatures.ps  # Розбиття великої книги на окремі зошити по 16 сторінок
```
