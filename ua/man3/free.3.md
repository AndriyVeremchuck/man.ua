# 📖 free(3) — Українська системна документація

> **Розділ 3**: Бібліотечні виклики C / libc / Wayland API  
> **Пакет**: `glibc`  
> **Оригінальний виклик**: `man 3 free`

---

## 🎯 НАЗВА (NAME)
**`free`** — Звільнення раніше виділеної динамічної пам'яті

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
void free(void *ptr);
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `free` належить до **Розділу 3** системної документації Linux (*Функції glibc, posix, wayland та системних C-бібліотек*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 3 free` або аліас `uman free`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
free(ptr);
```
