# 📖 umount(8) — Українська системна документація

> **Розділ 8**: Команди системного адміністрування (Root)  
> **Пакет**: `util-linux`  
> **Оригінальний виклик**: `man 8 umount`

---

## 🎯 НАЗВА (NAME)
**`umount`** — Безпечне відмонтування накопичувачів та файлових систем.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
umount [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-l (lazy ліниве відмонтування), -f (примусово), -v (детально)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `umount` належить до **Розділу 8** системної документації Linux (*Утиліти керування службами, дисками, демонами, безпекою (systemctl, btrfs)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 8 umount` або аліас `uman umount`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo umount /mnt/usb  # Безпечно відмонтувати USB накопичувач
```
