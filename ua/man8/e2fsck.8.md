# 📖 e2fsck(8) — Українська системна документація

> **Розділ 8**: Команди системного адміністрування (Root)  
> **Пакет**: `e2fsprogs`  
> **Оригінальний виклик**: `man 8 e2fsck`

---

## 🎯 НАЗВА (NAME)
**`e2fsck`** — Спеціалізована перевірка та відновлення цілісності файлових систем Ext2, Ext3 та Ext4.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
e2fsck [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-p (автоматичне безпечне відновлення), -f (примусово), -v (детально)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `e2fsck` належить до **Розділу 8** системної документації Linux (*Утиліти керування службами, дисками, демонами, безпекою (systemctl, btrfs)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 8 e2fsck` або аліас `uman e2fsck`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo e2fsck -pv /dev/sda1  # Безпечна перевірка розділу Ext4
```
