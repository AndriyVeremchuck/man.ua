# 📖 journalctl(8) — Українська системна документація

> **Розділ 8**: Команди системного адміністрування (Root)  
> **Пакет**: `systemd`  
> **Оригінальний виклик**: `man 8 journalctl`

---

## 🎯 НАЗВА (NAME)
**`journalctl`** — Інспекція та фільтрація системних логів з бінарного журналу systemd-journald.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
journalctl [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-xe (помилки з поясненнями), -u <юніт>, -b (з останнього завантаження), -f (наживо), -p err (лише помилки)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `journalctl` належить до **Розділу 8** системної документації Linux (*Утиліти керування службами, дисками, демонами, безпекою (systemctl, btrfs)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 8 journalctl` або аліас `uman journalctl`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ journalctl -xe -p err..alert -b  # Перегляд критичних системних помилок поточного завантаження
$ journalctl -u sddm.service -n 50 -f  # Моніторинг логів дисплейного менеджера наживо
```
