# 📖 btrfs(8) — Українська системна документація

> **Розділ 8**: Команди системного адміністрування (Root)  
> **Оригінальний виклик**: `man 8 btrfs`

---

## 🎯 НАЗВА (NAME)
**`btrfs`** — Утиліта керування файловою системою Btrfs, підтомами та снапшотами

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
btrfs <command> [<args>]
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `btrfs` належить до **Розділу 8** системної документації Linux (*Утиліти керування службами, дисками, демонами, безпекою (systemctl, btrfs)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 8 btrfs` або аліас `uman btrfs`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo btrfs subvolume list /
$ sudo btrfs filesystem df /
```
