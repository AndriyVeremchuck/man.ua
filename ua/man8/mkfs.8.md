# 📖 mkfs(8) — Українська системна документація

> **Розділ 8**: Команди системного адміністрування (Root)  
> **Пакет**: `e2fsprogs / btrfs-progs`  
> **Оригінальний виклик**: `man 8 mkfs`

---

## 🎯 НАЗВА (NAME)
**`mkfs`** — Створення файлових систем на розділах накопичувачів (форматування у Btrfs, Ext4, XFS, VFAT).

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
mkfs [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-t <тип_ФС>, -L <мітка_диска>, -f (примусово)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `mkfs` належить до **Розділу 8** системної документації Linux (*Утиліти керування службами, дисками, демонами, безпекою (systemctl, btrfs)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 8 mkfs` або аліас `uman mkfs`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo mkfs.btrfs -L "DATA" /dev/sdb1  # Створити файлову систему Btrfs із міткою DATA
```
