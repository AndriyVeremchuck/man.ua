# 📖 fsck(8) — Українська системна документація

> **Розділ 8**: Команди системного адміністрування (Root)  
> **Пакет**: `util-linux`  
> **Оригінальний виклик**: `man 8 fsck`

---

## 🎯 НАЗВА (NAME)
**`fsck`** — Перевірка та автоматичне виправлення помилок цілісності файлових систем Linux.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
fsck [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-y (автоматично відповідати так), -f (примусова перевірка), -v (детально)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `fsck` належить до **Розділу 8** системної документації Linux (*Утиліти керування службами, дисками, демонами, безпекою (systemctl, btrfs)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 8 fsck` або аліас `uman fsck`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo fsck -f /dev/sdb1  # Примусова перевірка цілісності розділу
```
