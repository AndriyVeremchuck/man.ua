# 📖 gdisk(8) — Українська системна документація

> **Розділ 8**: Команди системного адміністрування (Root)  
> **Пакет**: `gptfdisk`  
> **Оригінальний виклик**: `man 8 gdisk`

---

## 🎯 НАЗВА (NAME)
**`gdisk`** — Текстовий інтерактивний редактор таблиць розділів стандарту GPT (GUID Partition Table) з потужними функціями відновлення та конвертації з MBR.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
gdisk [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`<пристрій> (наприклад /dev/nvme0n1), -l (список розділів)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `gdisk` належить до **Розділу 8** системної документації Linux (*Утиліти керування службами, дисками, демонами, безпекою (systemctl, btrfs)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 8 gdisk` або аліас `uman gdisk`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo gdisk -l /dev/nvme0n1  # Перегляд детальної розмітки GPT та унікальних UUID розділів
$ sudo gdisk /dev/sda  # Інтерактивне редагування та виправлення GPT таблиці
```
