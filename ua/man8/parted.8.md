# 📖 parted(8) — Українська системна документація

> **Розділ 8**: Команди системного адміністрування (Root)  
> **Пакет**: `parted`  
> **Оригінальний виклик**: `man 8 parted`

---

## 🎯 НАЗВА (NAME)
**`parted`** — Інструмент створення, зміни розміру та керування таблицями розділів GPT на великих дисках.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
parted [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`-l (список усіх дисків та розділів), -s (режим скрипта без запитів)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `parted` належить до **Розділу 8** системної документації Linux (*Утиліти керування службами, дисками, демонами, безпекою (systemctl, btrfs)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 8 parted` або аліас `uman parted`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ sudo parted -l  # Показати детальний звіт про розмітку всіх накопичувачів
```
