# 📖 udevadm(8) — Українська системна документація

> **Розділ 8**: Команди системного адміністрування (Root)  
> **Пакет**: `systemd`  
> **Оригінальний виклик**: `man 8 udevadm`

---

## 🎯 НАЗВА (NAME)
**`udevadm`** — Керування демоном udev, діагностика подій підключення апаратного забезпечення (hotplug) та тестування правил конфігурації пристроїв.

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
udevadm [OPTIONS] [ARGUMENTS...]
```

### ⚡ Ключові прапорці та опції:
`monitor (моніторинг подій підключення), info -a -p <sysfs_path> (всі атрибути пристрою), trigger (примусовий запуск правил), control --reload (перезавантаження правил)`

---

## 📋 ОПИС (DESCRIPTION)
Посібник `udevadm` належить до **Розділу 8** системної документації Linux (*Утиліти керування службами, дисками, демонами, безпекою (systemctl, btrfs)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 8 udevadm` або аліас `uman udevadm`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
$ udevadm monitor --property  # Відстеження підключення USB-носіїв та пристроїв у реальному часі
$ udevadm info -q all -n /dev/nvme0n1  # Перегляд повних системних властивостей та шляхів NVMe SSD
```
