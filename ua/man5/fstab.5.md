# 📖 fstab(5) — Українська системна документація

> **Розділ 5**: Формати конфігураційних файлів (/etc)  
> **Оригінальний виклик**: `man 5 fstab`

---

## 🎯 НАЗВА (NAME)
**`fstab`** — Статична конфігурація точок монтування файлових систем (/etc/fstab)

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
<накопичувач/UUID> <точка_монтування> <тип_ФС> <опції> <dump> <pass>
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `fstab` належить до **Розділу 5** системної документації Linux (*Синтаксис конфігураційних файлів (/etc/passwd, fstab, crontab, systemd)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 5 fstab` або аліас `uman fstab`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
UUID=xxxx-xxxx / btrfs subvol=@,compress=zstd:3 0 0
```
