## 🎯 НАЗВА (NAME)
**`tcp`** — Протокол керування передачею даних TCP (Transmission Control Protocol IPv4/IPv6)

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
TCP Protocol
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `tcp` належить до **Розділу 7** системної документації Linux (*Мережеві протоколи TCP/IP, стандарти POSIX, ієрархія файлової системи hier(7)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 7 tcp` або аліас `uman tcp`.
