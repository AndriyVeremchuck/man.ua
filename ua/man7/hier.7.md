# 📖 hier(7) — Українська системна документація

> **Розділ 7**: Огляди, стандарти, конвенції та протоколи  
> **Оригінальний виклик**: `man 7 hier`

---

## 🎯 НАЗВА (NAME)
**`hier`** — Опис структури та ієрархії стандартної файлової системи Linux/UNIX

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
/, /bin, /etc, /usr, /var, /opt, /dev, /proc, /sys
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `hier` належить до **Розділу 7** системної документації Linux (*Мережеві протоколи TCP/IP, стандарти POSIX, ієрархія файлової системи hier(7)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 7 hier` або аліас `uman hier`.
