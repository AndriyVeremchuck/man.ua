## 🎯 НАЗВА (NAME)
**`ip`** — Міжмережевий протокол IPv4/IPv6 та сокетні опції

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
IP Protocol
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ip` належить до **Розділу 7** системної документації Linux (*Мережеві протоколи TCP/IP, стандарти POSIX, ієрархія файлової системи hier(7)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 7 ip` або аліас `uman ip`.
