# 📖 fork(2) — Українська системна документація

> **Розділ 2**: Системні виклики ядра Linux  
> **Оригінальний виклик**: `man 2 fork`

---

## 🎯 НАЗВА (NAME)
**`fork`** — Створення нового дочірнього процесу шляхом дублювання поточного

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
pid_t fork(void);
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `fork` належить до **Розділу 2** системної документації Linux (*Прямі системні виклики між простором користувача та ядром (syscalls)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 2 fork` або аліас `uman fork`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
pid_t pid = fork();
if (pid == 0) { /* child */ }
```
