# 📖 read(2) — Українська системна документація

> **Розділ 2**: Системні виклики ядра Linux  
> **Оригінальний виклик**: `man 2 read`

---

## 🎯 НАЗВА (NAME)
**`read`** — Зчитування байтів із файлового дескриптора у буфер пам'яті

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ssize_t read(int fd, void *buf, size_t count);
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `read` належить до **Розділу 2** системної документації Linux (*Прямі системні виклики між простором користувача та ядром (syscalls)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 2 read` або аліас `uman read`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
ssize_t n = read(fd, buffer, sizeof(buffer));
```
