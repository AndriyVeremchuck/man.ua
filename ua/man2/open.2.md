# 📖 open(2) — Українська системна документація

> **Розділ 2**: Системні виклики ядра Linux  
> **Пакет**: `system`  
> **Оригінальний виклик**: `man 2 open`

---

## 🎯 НАЗВА (NAME)
**`open`** — Відкриття або створення файлу чи пристрою та отримання файлового дескриптора

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
int open(const char *pathname, int flags, mode_t mode);
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `open` належить до **Розділу 2** системної документації Linux (*Прямі системні виклики між простором користувача та ядром (syscalls)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 2 open` або аліас `uman open`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
int fd = open("file.txt", O_RDONLY);
```
