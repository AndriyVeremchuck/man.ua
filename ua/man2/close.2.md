# 📖 close(2) — Українська системна документація

> **Розділ 2**: Системні виклики ядра Linux  
> **Пакет**: `system`  
> **Оригінальний виклик**: `man 2 close`

---

## 🎯 НАЗВА (NAME)
**`close`** — Закриття файлового дескриптора та звільнення системних ресурсів

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
int close(int fd);
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `close` належить до **Розділу 2** системної документації Linux (*Прямі системні виклики між простором користувача та ядром (syscalls)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 2 close` або аліас `uman close`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
close(fd);
```
