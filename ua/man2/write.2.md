# 📖 write(2) — Українська системна документація

> **Розділ 2**: Системні виклики ядра Linux  
> **Пакет**: `system`  
> **Оригінальний виклик**: `man 2 write`

---

## 🎯 НАЗВА (NAME)
**`write`** — Запис даних із буфера у файловий дескриптор

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
ssize_t write(int fd, const void *buf, size_t count);
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `write` належить до **Розділу 2** системної документації Linux (*Прямі системні виклики між простором користувача та ядром (syscalls)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 2 write` або аліас `uman write`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
write(STDOUT_FILENO, "Hello\n", 6);
```
