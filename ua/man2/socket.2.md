# 📖 socket(2) — Українська системна документація

> **Розділ 2**: Системні виклики ядра Linux  
> **Пакет**: `system`  
> **Оригінальний виклик**: `man 2 socket`

---

## 🎯 НАЗВА (NAME)
**`socket`** — Створення кінцевої точки комунікації для мережевих або локальних сокетів

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
int socket(int domain, int type, int protocol);
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `socket` належить до **Розділу 2** системної документації Linux (*Прямі системні виклики між простором користувача та ядром (syscalls)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 2 socket` або аліас `uman socket`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
int sfd = socket(AF_INET, SOCK_STREAM, 0);
```
