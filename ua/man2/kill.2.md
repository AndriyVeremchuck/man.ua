# 📖 kill(2) — Українська системна документація

> **Розділ 2**: Системні виклики ядра Linux  
> **Пакет**: `system`  
> **Оригінальний виклик**: `man 2 kill`

---

## 🎯 НАЗВА (NAME)
**`kill`** — Надсилання сигналу процесу або групі процесів за PID

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
int kill(pid_t pid, int sig);
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `kill` належить до **Розділу 2** системної документації Linux (*Прямі системні виклики між простором користувача та ядром (syscalls)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 2 kill` або аліас `uman kill`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
kill(pid, SIGTERM);
```
