# 📖 ioctl(2) — Українська системна документація

> **Розділ 2**: Системні виклики ядра Linux  
> **Пакет**: `system`  
> **Оригінальний виклик**: `man 2 ioctl`

---

## 🎯 НАЗВА (NAME)
**`ioctl`** — Керування параметрами пристроїв та апаратних драйверів

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
int ioctl(int fd, unsigned long op, ...);
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `ioctl` належить до **Розділу 2** системної документації Linux (*Прямі системні виклики між простором користувача та ядром (syscalls)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 2 ioctl` або аліас `uman ioctl`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
ioctl(fd, TCGETS, &termios_p);
```
