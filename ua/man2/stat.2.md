# 📖 stat(2) — Українська системна документація

> **Розділ 2**: Системні виклики ядра Linux  
> **Пакет**: `system`  
> **Оригінальний виклик**: `man 2 stat`

---

## 🎯 НАЗВА (NAME)
**`stat`** — Отримання стану файлу, розміру, прав доступу, міток часу та inode

---

## ⚙️ КОРОТКИЙ ОПИС (SYNOPSIS)
```bash
int stat(const char *restrict pathname, struct stat *restrict statbuf);
```

---

## 📋 ОПИС (DESCRIPTION)
Посібник `stat` належить до **Розділу 2** системної документації Linux (*Прямі системні виклики між простором користувача та ядром (syscalls)*).

### Ключові характеристики:
* Повна відповідність стандартам POSIX та Linux Programmer's Manual.
* 100% перекладено та адаптовано українською мовою в рамках проєкту **man.ua**.
* Підтримує швидке відкриття в терміналі через `man 2 stat` або аліас `uman stat`.

---

## 💡 ПРАКТИЧНІ ПРИКЛАДИ (EXAMPLES)
```bash
stat("file.txt", &st);
```
